Automatically fix Checkstyle and PMD violations using AI-powered QuickFix. No more manual fixes, no more context switching. Just one click to resolve code style issues and get back to coding.

Why This Plugin?

When you're reviewing code quality violations, why spend time manually fixing them one by one?

Static analysis tools like Checkstyle and PMD are essential for maintaining code quality, but fixing violations can be tedious and error-prone. You need to understand the rule, find the correct fix, and apply it without breaking the code - and repeat this for every single violation.

Our plugin chooses to automate rather than eliminate: it doesn't replace static analysis tools, change your coding standards, or introduce new rules. It simply uses AI to fix the violations that tools detect, so you can focus on writing code instead of fixing it.

Key Features

  • 🤖 AI-Powered QuickFix: One-click fix for Checkstyle and PMD violations directly in your editor, powered by intelligent AI
  • ⚡ Context-Aware Fixes: Automatically collects surrounding code context for accurate, intelligent fix suggestions that maintain code semantics
  • 🎯 Precise Snippet Replacement: Fixes only the problematic code snippet without touching other parts, ensuring safe and controlled changes
  • 📊 Problems Panel Integration: View and fix all violations in one place with batch operations (Fix Selected / Fix All)
  • 📄 XML Report Support: Import and fix violations from Maven-generated Checkstyle/PMD reports, no need for Checkstyle-IDEA installation
  • 🔄 Maven Build Integration: Automatically parses static analysis reports after Maven builds and injects violations into IDE
  • ✅ Validated Fixes: AI-generated fixes are validated to ensure accuracy and safety before application

Usage

  • Quick Fix: Right-click on a violation in editor → Select "AI Fix" to automatically fix the issue
  • Batch Fix: Open Problems panel → Select multiple violations → Click "Fix Selected" or "Fix All"
  • Import Report: Analyze → Import Static Analysis Report → Select Checkstyle/PMD XML file
  • Automatic: Run Maven build → Plugin automatically parses and injects violations

Design Philosophy

This plugin follows three core principles:

  • Non-Invasive - Doesn't change your coding habits or replace existing tools, just adds AI fix capability
  • Precision - Fixes only what needs to be fixed, with controlled scope and validated results
  • Efficiency - One click to fix what would otherwise take minutes, letting you focus on actual development

Good tools don't add to your workflow, they remove the friction.

Configuration

Configuration path: Settings → Tools → IntelliAI Engine → 🧩 IntelliAI Repairer

  • Enable/disable AI fix feature (enabled by default)
  • Select AI provider (defaults to first verified global provider)
  • Customize system and user prompt templates (advanced settings)
  • Configure fix validation settings

Requirements

  • IntelliJ IDEA 2025.3+: Plugin requires IntelliJ IDEA 2025.3 or higher
  • IntelliAI Engine Plugin: Must install IntelliAI Engine plugin and configure at least one AI provider
  • Static Analysis Tools: Checkstyle and/or PMD (Checkstyle-IDEA plugin is optional but recommended)

为什么选择这个插件？

当你正在查看代码质量违规时，为什么要花时间一个一个手动修复？

Checkstyle 和 PMD 等静态分析工具对维护代码质量至关重要，但修复违规往往既繁琐又容易出错。你需要理解规则、找到正确的修复方法，在不破坏代码的前提下应用它——而且要对每一个违规都重复这个过程。

我们的插件选择自动化而不是消除：它不会替代静态分析工具、改变你的编码标准或引入新规则。它只是用 AI 来修复工具检测到的违规，让你专注于编写代码，而不是修复代码。

核心特性

  • 🤖 AI 驱动的智能修复：在编辑器中一键修复 Checkstyle 和 PMD 违规，由强大的 AI 提供支持
  • ⚡ 上下文感知的精准修复：自动收集周围代码上下文，生成准确、智能的修复建议，保持代码语义不变
  • 🎯 精确的片段替换：只修复有问题的代码片段，不触及其他部分，确保修改安全可控
  • 📊 Problems 面板集成：在一个地方查看并修复所有违规，支持批量操作（修复选中/修复全部）
  • 📄 XML 报告支持：导入并修复 Maven 生成的 Checkstyle/PMD 报告中的违规，无需安装 Checkstyle-IDEA
  • 🔄 Maven 构建集成：Maven 构建后自动解析静态分析报告并将违规注入 IDE
  • ✅ 验证的修复结果：AI 生成的修复在应用前经过验证，确保准确性和安全性

使用方式

  • 快速修复：在编辑器中右键点击违规 → 选择"AI Fix"自动修复问题
  • 批量修复：打开 Problems 面板 → 选择多个违规 → 点击"修复选中"或"修复全部"
  • 导入报告：Analyze → Import Static Analysis Report → 选择 Checkstyle/PMD XML 文件
  • 自动触发：运行 Maven 构建 → 插件自动解析并注入违规

设计理念

这个插件遵循三个核心原则：

  • 非侵入式 - 不改变你的编码习惯或替代现有工具，只是增加 AI 修复能力
  • 精确性 - 只修复需要修复的部分，范围可控且结果经过验证
  • 高效性 - 一键完成原本需要几分钟的修复，让你专注于实际开发

好的工具不会增加你的工作流，而是消除其中的摩擦。
