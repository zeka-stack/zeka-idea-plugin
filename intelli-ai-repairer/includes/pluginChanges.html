2025.3.1200

🎊 本版本是2026年春节前的最后一个版本,提前祝大家春节快乐,万事如意!🧧🎉

本次更新主要聚焦于功能优化与体验提升,包括:

  • ✨ 新增：完整的 Checkstyle 违规 AI 修复功能,基于 Checkstyle-IDEA 扫描结果提供智能 QuickFix
  • ✨ 新增：PMD 违规 AI 修复支持,自动修复 PMD 检测到的代码规范问题
  • ✨ 新增：XML 报告解析功能,支持解析 Maven 插件生成的 Checkstyle/PMD XML 报告,无需安装 Checkstyle-IDEA 也可使用
  • ✨ 新增：Problems 面板集成,在 IDE 的 Problems 面板中统一展示所有违规问题,支持批量修复操作
  • ✨ 新增：手动导入静态分析报告功能(Analyze → Import Static Analysis Report),方便用户导入外部生成的报告
  • ✨ 新增：Maven 构建集成,自动监听 Maven 构建完成事件,解析静态分析报告并注入到 IDE 中
  • ✨ 新增：批量修复功能,支持在 Problems 面板中选择多个问题进行批量修复(Fix Selected/Fix All)
  • ✨ 新增：统一数据模型 `CodeViolation`,支持多种静态分析工具的违规信息表示
  • ✨ 新增：智能上下文收集,自动收集违规代码周围的上下文信息,提供更准确的修复建议
  • ✨ 新增：修复结果验证机制,确保 AI 生成结果的准确性和安全性
  • 🔧 优化：采用"片段替换"策略,精准定位并修复违规代码,确保修复范围可控
  • 🔧 优化：优化 AI 修复流程,从上下文收集、Prompt 构建到结果验证,提供完整的修复流水线

2025.3.1200

🎊 This is the last version before the 2026 Chinese New Year. Wishing everyone a happy Spring Festival and all the best! 🧧🎉

This update focuses on functionality optimization and experience improvements, including:

  • ✨ Added: Complete Checkstyle violation AI fix feature, providing intelligent QuickFix based on Checkstyle-IDEA scan results
  • ✨ Added: PMD violation AI fix support, automatically fixing code style issues detected by PMD
  • ✨ Added: XML report parsing feature, supporting parsing of Checkstyle/PMD XML reports generated by Maven plugins, usable without Checkstyle-IDEA installation
  • ✨ Added: Problems panel integration, displaying all violation issues in IDE's Problems panel with batch fix operations
  • ✨ Added: Manual static analysis report import (Analyze → Import Static Analysis Report) for importing externally generated reports
  • ✨ Added: Maven build integration, automatically listening to Maven build completion events, parsing static analysis reports and injecting them into IDE
  • ✨ Added: Batch fix feature, supporting batch fixing of multiple selected issues in Problems panel (Fix Selected/Fix All)
  • ✨ Added: Unified data model `CodeViolation`, supporting violation information representation from multiple static analysis tools
  • ✨ Added: Intelligent context collection, automatically collecting surrounding context of violation code for more accurate fix suggestions
  • ✨ Added: Fix result validation mechanism, ensuring accuracy and security of AI-generated results
  • 🔧 Optimized: Adopting "snippet replacement" strategy, precisely locating and fixing violation code with controlled fix scope
  • 🔧 Optimized: Optimized AI fix workflow, from context collection and prompt building to result validation, providing a complete fix pipeline
