AI Changelog

使用 AI 自动生成项目变更日志的 IntelliJ IDEA 插件。

功能特性

  • 🚀 AI 生成变更日志：基于 Git 提交记录自动生成变更日志
  • 🤖 多种 AI 提供商支持：支持通义千问、Ollama、OpenAI 等多种 AI 服务
  • ⌨️ 灵活的触发方式：可通过快捷键、右键菜单等多种方式触发
  • 📝 自定义模板：支持自定义变更日志格式和模板
  • 🌍 国际化支持：多语言资源文件

开发环境

  • JDK 17+
  • Gradle 8.0+
  • IntelliJ IDEA 2022.3+

快速开始

  1. 安装插件
  2. 配置 AI 提供商和 API Key
  3. 使用快捷键或右键菜单生成变更日志

使用方式

  • 快捷键：Ctrl+Shift+C (Windows/Linux) 或 Cmd+Shift+C (Mac)
  • 编辑器右键菜单 → Generate Changelog with AI
  • 项目视图右键菜单 → Generate Changelog with AI
  • 快速修复：Option+Enter / Alt+Enter → Generate Changelog with AI

技术栈

  • 基于 IntelliJ Platform SDK 2.1.0
  • 使用 Kotlin DSL 配置构建
  • 集成 JUnit 5 测试框架
  • 支持 Mockito 进行单元测试
