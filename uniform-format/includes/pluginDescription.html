Uniform Format

统一的代码格式化和模板管理插件，提供标准化的代码风格配置、文件模板和 Live Template，帮助开发团队保持代码风格的一致性。

功能特性

  • 📝 文件模板：自动添加统一的文件头部注释，包含公司信息、作者、版本、邮箱、日期等，支持 Java Class、Interface、Enum 等文件类型
  • ⚡ Live Template：快速生成常用代码片段，包括待办事项标记、Javadoc、日志、测试等方法
  • 🎨 代码风格：自动配置统一的代码格式化规则，支持 Java、SQL、JavaScript 等多种语言，可自定义缩进、换行、导入等规则
  • 📊 使用统计：统计模板使用情况，帮助了解团队开发习惯

Live Template 快捷键

在编辑器中输入以下快捷键，按 Tab 键自动展开：

快捷键 功能 示例
todo + Tab 标记待处理 todo-dong4j : (2024.12.19 15:30) [需要实现的功能]
fix + Tab 标记需要修复 fixme-dong4j : (2024.12.19 15:30) [修复这个bug]
cd + Tab 生成 class javadoc 自动生成类注释
li/ld/lw/le + Tab 生成日志语句 log.info() / log.debug() / log.warn() / log.error()
test + Tab 生成测试方法 @Test void test_methodName(){}

核心优势

  • 🚀 零配置：安装后自动配置，无需手动设置
  • 🎯 标准化：统一的代码风格，提升代码质量
  • ⚡ 高效率：快速生成常用代码，提升开发效率
  • 🔧 可定制：支持自定义模板和配置
  • 📊 可追踪：使用统计帮助优化开发流程

使用场景

  • 团队协作开发，需要统一的代码风格规范
  • 频繁编写注释、日志、测试代码，需要提升效率
  • 新成员加入，需要快速适应团队编码习惯
  • 代码审查，需要快速标记待处理或需要修复的代码

配置说明

插件安装后会自动配置代码风格和模板，无需额外设置。如需自定义配置，可进入 File → Settings → Tools → Uniform Format 进行调整。

技术实现

  • 基于 IntelliJ Platform SDK 开发
  • 支持 IntelliJ IDEA 2022.3+
  • 采用 Java 17+ 开发
  • 提供完整的国际化支持
