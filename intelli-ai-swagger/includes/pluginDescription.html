Generate Swagger/OpenAPI annotations using AI directly in your code editor. No more manual annotation writing, no more switching between tools. Just right-click on your controller method and let AI generate complete, accurate API documentation.

Why This Plugin?

When you're writing REST APIs, why spend time writing Swagger annotations manually?

Swagger/OpenAPI is essential for API documentation, but writing annotations is tedious and error-prone. You need to remember all the annotation attributes, ensure consistency across your API, and keep documentation in sync with code changes. One typo or missing attribute, and your API documentation becomes incomplete or misleading.

Our plugin chooses to automate rather than eliminate: it doesn't replace Swagger, change your documentation standards, or introduce new documentation systems. It simply uses AI to generate accurate Swagger annotations based on your code structure, so you can focus on writing business logic instead of documentation boilerplate.

Key Features

  • 🤖 AI-Powered Annotation Generation: Generate complete Swagger annotations for Controller methods, parameters, and responses with one click
  • 🎯 Context-Aware Analysis: Automatically analyzes method signature, parameters, return types, and existing mappings to generate accurate annotations
  • 📦 DTO/Schema Support: Maintain and update DTO/Schema annotations referenced by your API endpoints
  • 🔍 Spring Controller Detection: Automatically identifies Spring Controller methods and understands mapping annotations (@GetMapping, @PostMapping, etc.)
  • ✨ Smart Annotation Writing: Generates well-structured, comprehensive annotations including descriptions, examples, and response codes
  • ⚙️ Reusable Provider Settings: Leverages IntelliAI Engine's unified provider configuration for seamless AI integration
  • 🔔 Quick Actions: Right-click menu integration for instant annotation generation

Usage

  • Open your Spring Controller file in the editor
  • Right-click on a controller method
  • Select "AI Generate Swagger" from the context menu
  • AI analyzes the method and generates complete Swagger annotations
  • Review and adjust annotations if needed

Design Philosophy

This plugin follows three core principles:

  • Non-Invasive - Doesn't change your coding workflow or introduce new documentation systems, just adds AI-powered annotation generation
  • Accuracy - Analyzes actual code structure and existing annotations to generate precise, relevant documentation
  • Efficiency - One-click generation replaces manual typing, reducing documentation effort by 90%

Good tools don't add complexity, they remove tedium.

Configuration

Configuration path: Settings → Tools → IntelliAI Engine → 🧩 IntelliAI Swagger

  • Enable/disable Swagger AI (enabled by default)
  • Select AI provider (defaults to first verified global provider)
  • Customize system and user prompt templates (advanced settings)
  • Configure annotation generation preferences

Requirements

  • IntelliJ IDEA 2025.3+: Plugin requires IntelliJ IDEA 2025.3 or higher
  • IntelliAI Engine Plugin: Must install IntelliAI Engine plugin and configure at least one AI provider
  • Spring Framework: Project must use Spring Framework (MVC/Boot)
  • AI Provider Configuration: Configure and verify at least one AI provider in Settings → Tools → IntelliAI Engine

为什么选择这个插件？

当你编写 REST API 时，为什么要花时间手动编写 Swagger 注解？

Swagger/OpenAPI 对 API 文档至关重要，但编写注解既繁琐又容易出错。你需要记住所有注解属性，确保 API 的一致性，并保持文档与代码变更的同步。一个拼写错误或缺少属性，你的 API 文档就会变得不完整或产生误导。

我们的插件选择自动化而不是替代：它不会替代 Swagger、改变你的文档标准或引入新的文档系统。它只是根据你的代码结构使用 AI 生成准确的 Swagger 注解，让你专注于编写业务逻辑，而不是文档模板代码。

核心特性

  • 🤖 AI 驱动的注解生成：一键生成 Controller 方法、参数和响应的完整 Swagger 注解
  • 🎯 上下文感知分析：自动分析方法签名、参数、返回类型和现有映射，生成准确的注解
  • 📦 DTO/Schema 支持：维护和更新 API 端点引用的 DTO/Schema 注解
  • 🔍 Spring Controller 检测：自动识别 Spring Controller 方法，理解映射注解（@GetMapping、@PostMapping 等）
  • ✨ 智能注解写入：生成结构良好、全面的注解，包括描述、示例和响应码
  • ⚙️ 复用服务商配置：利用 IntelliAI Engine 的统一服务商配置，实现无缝 AI 集成
  • 🔔 快捷操作：右键菜单集成，即刻生成注解

使用方式

  • 在编辑器中打开你的 Spring Controller 文件
  • 在 Controller 方法上右键点击
  • 从上下文菜单中选择"AI 生成 Swagger"
  • AI 分析方法并生成完整的 Swagger 注解
  • 审查并根据需要调整注解

设计理念

这个插件遵循三个核心原则：

  • 非侵入式 - 不改变你的编码工作流或引入新的文档系统，只是增加 AI 驱动的注解生成能力
  • 准确性 - 分析实际代码结构和现有注解，生成精确、相关的文档
  • 高效性 - 一键生成替代手动输入，减少 90% 的文档编写工作量

好的工具不会增加复杂性，而是消除繁琐。
