# 插件开发指南

本文档用于说明 IntelliAI Swagger 的最小可用能力与推荐实践，便于后续迭代开发。

## 能力清单

- 依赖 IntelliAI Engine（AI 服务商、控制台、状态栏聚合）
- 设置页面（含 AI 服务商选择、提示词配置）
- 持久化配置（SettingsState）
- 状态栏扩展点接入
- Swagger 注解生成示例（基于 AI）
- 国际化与图标管理

## 推荐扩展路径

1. 在 Action 中接入 PSI 解析与 Swagger 注解写回逻辑
2. 在设置页中完善生成策略与更新策略配置
3. 为状态栏菜单增加常用生成入口
4. 使用 Engine 控制台输出调试日志与 AI 交互记录
