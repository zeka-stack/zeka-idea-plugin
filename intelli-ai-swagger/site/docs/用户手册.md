# IntelliAI Swagger 用户手册

## 简介

本插件已集成 IntelliAI Engine，用于生成和维护 Swagger/OpenAPI 注解与文档。

## 功能特性

- 🤖 AI 服务商选择（复用 Engine 的 `AIProviderSelectionPanel`）
- ⚙️ 设置页面与持久化配置（`SettingsState`）
- 🧩 状态栏扩展点接入（聚合到 Engine 状态栏）
- 🧪 AI 接口调用示例（非流式）
- 🌍 国际化与图标管理

## 快速开始

1. 配置 IntelliAI Engine
    - 打开 Settings → Tools → IntelliAI Engine
    - 添加并验证 AI 服务商

2. 打开插件设置
    - Settings → Tools → IntelliAI Engine → 🧩 IntelliAI Swagger
    - 选择 AI 服务商与提示词模板

3. 执行示例动作
    - 编辑器右键选择“使用 AI 生成 Swagger”

## 目录结构（关键部分）

```
site/docs/                 # 文档目录
src/main/java/.../swagger/
  action/                  # Swagger Action
  settings/                # 设置与持久化
  statusbar/               # 状态栏扩展点
  util/                    # 工具类
```

## 使用说明

### AI 服务商选择

设置页默认集成 `AIProviderSelectionPanel`：

- 自动读取 Engine 已验证服务商
- 无服务商时展示跳转链接
- 配置变更可自动刷新

### 状态栏

插件通过扩展点注册状态栏菜单，展示：

- AI 服务商切换
- 快捷设置入口

### AI 接口调用（非流式）

示例 Action 使用 `AIService` 调用生成内容，并输出通知与控制台日志。

## 常见问题

- 没有服务商：请先在 IntelliAI Engine 设置中配置并验证
- 无输出：检查是否开启了“详细日志”，并确认服务商配置可用
