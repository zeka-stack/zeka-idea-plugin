AI Common is a core IntelliJ plugin that provides AI capabilities for other plugins. It offers a unified AI service interface, supporting multiple AI providers including OpenAI, QianWen, Ollama, LM Studio, and SiliconFlow.

Key Features:

  • Unified AI Service API for external plugins
  • Multiple AI Provider Support (OpenAI, QianWen, Ollama, LM Studio, SiliconFlow)
  • Global Configuration Management
  • Secure API Key Management
  • Reusable UI Components
  • Status Bar Integration

For Plugin Developers:

Simply depend on this plugin and use the AIService API to add AI capabilities to your plugin. The plugin automatically manages provider configurations, API keys, and model parameters.
