# 终端插件统计集成方案

## 目标

在 Terminal 模块中复用 Engine 提供的统计框架, 记录用户针对终端生成命令的调用行为, 与 Changelog/Javadoc 插件保持一致的 Token 统计、延迟记录和用户操作维度.

## 1. 枚举扩展

参考 `dev.dong4j.zeka.stack.idea.plugin.changelog.statistics.ChangelogStatisticsReporter` 与
`dev.dong4j.zeka.stack.idea.javadoc.statistics.JavadocStatisticsReporter` 的做法, 需要在共享模块中新增以下枚举值:

- `StatisticsPluginId.TERMINAL` 表示 Terminal 插件来源.
- `StatisticsEventType.TERMINAL_COMMAND` 专用于表示一次终端命令生成事件.
- `StatisticsUserAction.TERMINAL_SHORTCUT` 代表在终端中按快捷键（比如 Tab）触发 AI 命令生成.

这些枚举用于构造 `StatisticsEvent` 时指定插件、事件类型与用户行为.

## 2. TerminalStatisticsReporter

新建 `dev.dong4j.zeka.stack.idea.plugin.terminal.statistics.TerminalStatisticsReporter`, 其核心逻辑与 Changelog/Javadoc Reporter 保持一致:

- 通过 `StatisticsServiceInitializer.getService().report(...)` 上报事件.
- 使用 `StatisticsPluginId.TERMINAL`、`StatisticsEventType.TERMINAL_COMMAND` 以及传入的提供商/模型.
- 计算 Token 量：提示词使用 `AIChatRequest.promptTokenEstimate()` (默认 0), 结果文本用与 Changelog 相同的中英文字符比例估算.
- 记录 `latencyMs`、`inputToken` 与 `outputToken` 并附带 `StatisticsUserAction.TERMINAL_SHORTCUT`.

此类将被 `TerminalAiGenerateAction` 调用。

## 3. Action 中的接入点

在 `TerminalAiGenerateAction.actionPerformed()` 中做如下处理:

1. 生成 `AIChatRequest` 后立即记录 `long startTimeMs = System.currentTimeMillis()` 与 `StatisticsUserAction.TERMINAL_SHORTCUT` (参考
   Changelog/Javadoc 模块如何在生成前计算 latency).
2. 非流式调用：在 `handleAiResult` 里打印结果并执行 `applyAiResult`，只有返回 true（命令合法且替换成功）时才触发：

```java
long latencyMs = System.currentTimeMillis() - startTimeMs;
TerminalStatisticsReporter.reportSuccess(project, providerConfig, request, result, latencyMs, userAction);
```

3. 流式调用：在 `AIStreamResponseListener.onComplete()` 里拼接 `fullText` 并执行 `applyAiResult`，成功后同样用当前
   `System.currentTimeMillis()` 计算 latency 并上报。
4. `applyAiResult` 在处理逻辑中返回 boolean, 便于统一判断是否上报.

## 4. 数据链路与验证

- 所有统计事件仍通过 `StatisticsServiceInitializer` 统一上报, 与其他插件共享配置.
- 可以通过开启 `StatisticsSettings`（如 `StatisticsServiceImpl` 日志）模拟触发 `TerminalAiGenerateAction` 并观察 `StatisticsRecord` 是否包含
  `terminal_command`。

## 5. 参考

- Changelog 统计参考：`ChangelogStatisticsReporter` & `ChangelogAiExecutor` 中的 `reportSuccess`.
- Javadoc 统计参考：`JavadocStatisticsReporter` & `SequentialTaskProcessor` 中的调用方式.

该文档与 `intelli-ai-terminal/docs/开发文档.md` 配套, 介绍了如何将终端命令生成的成功事件接入 Engine 的统计能力。
