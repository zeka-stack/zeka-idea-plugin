## 1 背景与目标

### 1.1 问题定义

当用户在终端中按 TAB 键触发 AI 生成命令时，需要向用户提供即时反馈，告知 AI 正在处理请求。这种提示本质上是「向终端临时输出一行状态文本」，而不是
Shell Prompt，也不是日志。

### 1.2 设计原则

- **不打断用户操作**：提示应该自然地出现在终端中，不影响用户输入
- **不污染 Shell Prompt**：不要修改 Shell 的 PS1 环境变量
- **不依赖外部 UI**：不使用 ToolWindow UI 覆盖终端，不使用 Notification / Balloon
- **符合终端习惯**：状态提示应该像终端命令输出一样自然

### 1.3 目标效果

```
# 查找所有包含 TODO 的 Java 文件
[AI] 正在分析请求...
find . -name "*.java" -exec grep -l "TODO" \;
```

## 2 实现原理

### 2.1 核心思路

1. **用户输入**：用户在终端输入触发前缀和需求描述
2. **按 TAB 键**：触发 AI 生成动作
3. **显示提示**：立即向终端写入一行状态提示（如 `[AI] 正在分析请求...`）
4. **AI 处理**：异步调用 AI 服务生成命令
5. **替换命令**：AI 返回后，用生成的命令替换当前输入行

### 2.2 技术要点

- **使用终端 API**：通过 `TerminalView.sendText()` 或 `JBTerminalWidget.sendString()` 向终端写入文本
- **支持双终端**：兼容新版 `TerminalView` 和旧版 `JBTerminalWidget`
- **控制字符处理**：使用 ANSI 转义码添加颜色，使用控制字符清除行

## 3 核心 API

### 3.1 TerminalView API

```java
// 向终端发送文本
terminalView.sendText(String text);
```

### 3.2 JBTerminalWidget API

```java
// 方式 1：使用 sendString（推荐）
jbTerminalWidget.sendString(String text);

// 方式 2：使用 TtyConnector
jbTerminalWidget.getTtyConnector().write(String text);
```

### 3.3 关键差异

| API                             | 终端类型              | 方法名            | 说明        |
|---------------------------------|-------------------|----------------|-----------|
| `TerminalView.sendText()`       | Reworked Terminal | `sendText()`   | 直接向终端发送文本 |
| `JBTerminalWidget.sendString()` | Classic Terminal  | `sendString()` | 发送字符串到终端  |
| `TtyConnector.write()`          | Classic Terminal  | `write()`      | 底层写入方法    |

## 4 基础实现

### 4.1 最简单实现（推荐）

#### 4.1.1 显示状态提示

在 AI 处理开始前，向终端输出一行简单的提示：

```java
/**
 * 显示 AI 处理状态提示
 * <p>向终端输出一行临时状态提示，告知用户 AI 正在处理请求
 *
 * @param terminalView 终端视图实例
 * @param jbWidget     JBTerminalWidget 实例
 */
private static void showAiProcessingHint(@Nullable TerminalView terminalView,
                                         @Nullable JBTerminalWidget jbWidget) {
    String hint = "\n[AI] 正在分析请求...\n";

    if (terminalView != null) {
        terminalView.sendText(hint);
    } else if (jbWidget != null) {
        jbWidget.sendString(hint);
    }
}
```

#### 4.1.2 集成到现有代码

在 `TerminalAiGenerateAction.actionPerformed()` 中，AI 处理开始前显示提示：

```java
@Override
public void actionPerformed(@NotNull AnActionEvent e) {
    // ... 获取输入和验证 ...

    // 显示处理提示
    showAiProcessingHint(terminalView, jbWidget);

    ProgressManager.getInstance().run(new Task.Backgroundable(project, "生成命令", true) {
        @Override
        public void run(@NotNull ProgressIndicator indicator) {
            // ... AI 处理逻辑 ...
            // AI 返回后，用 replaceCurrentLine() 替换当前行
        }
    });
}
```

### 4.2 效果展示

**用户输入：**

```
# 查找所有包含 TODO 的 Java 文件
```

**按 TAB 键后，终端显示：**

```
# 查找所有包含 TODO 的 Java 文件
[AI] 正在分析请求...
```

**AI 返回后，终端显示：**

```
# 查找所有包含 TODO 的 Java 文件
[AI] 正在分析请求...
find . -name "*.java" -exec grep -l "TODO" \;
```

## 5 增强实现

### 5.1 使用 ANSI 颜色（推荐）

使用 ANSI 转义码为状态提示添加颜色，提升视觉效果：

#### 5.1.1 ANSI 颜色代码

| 颜色 | ANSI 代码      | 说明         |
|----|--------------|------------|
| 绿色 | `\u001B[32m` | 用于成功/处理中状态 |
| 黄色 | `\u001B[33m` | 用于警告状态     |
| 红色 | `\u001B[31m` | 用于错误状态     |
| 重置 | `\u001B[0m`  | 重置颜色到默认    |

#### 5.1.2 实现代码

```java
/**
 * 显示带颜色的 AI 处理状态提示
 * <p>使用 ANSI 转义码为状态提示添加绿色，提升视觉效果
 *
 * @param terminalView 终端视图实例
 * @param jbWidget     JBTerminalWidget 实例
 */
private static void showAiProcessingHint(@Nullable TerminalView terminalView,
                                         @Nullable JBTerminalWidget jbWidget) {
    // 使用 ANSI 绿色
    String hint = "\n\u001B[32m[AI]\u001B[0m 正在分析请求...\n";

    if (terminalView != null) {
        terminalView.sendText(hint);
    } else if (jbWidget != null) {
        jbWidget.sendString(hint);
    }
}
```

### 5.2 支持多种状态

根据不同状态显示不同颜色的提示：

```java
/**
 * AI 状态类型

public enum AiStatus {
    /** 处理中 */

    /** 失败 */

    /** 警告 */
    WARNING("\u001B[33m[AI]\u001B[0m 警告：命令可能不安全");

    private final String message;

    AiStatus(String message) {
        this.message = message;
    }

    public String getMessage() {
        return message;
    }

/**
 * 显示 AI 状态提示

private static void showAiStatusHint(@Nullable TerminalView terminalView,
                                     @Nullable JBTerminalWidget jbWidget,

    String hint = "\n" + status.getMessage() + "\n";

    if (terminalView != null) {
        terminalView.sendText(hint);
    } else if (jbWidget != null) {
        jbWidget.sendString(hint);
    }
}
```

## 6 高级实现

### 6.1 临时提示（不留下痕迹）

如果希望提示是临时的，不想永久留在终端历史里，可以使用光标控制字符：

```java
/**
 * 显示临时 AI 处理状态提示（不留下痕迹）
 * <p>使用光标控制字符清除行，提示在 AI 返回后自动清除
 *
 * @param terminalView 终端视图实例
 * @param jbWidget     JBTerminalWidget 实例
 */
private static void showTemporaryAiHint(@Nullable TerminalView terminalView,
                                        @Nullable JBTerminalWidget jbWidget) {
    // \r → 回到行首
    // \u001B[2K → 清空当前行
    String hint = "\n\u001B[32m[AI]\u001B[0m 正在分析请求...\u001B[2K\r";

    if (terminalView != null) {
        terminalView.sendText(hint);
    } else if (jbWidget != null) {
        jbWidget.sendString(hint);
    }
}
```

**⚠️ 注意：** 这种方式虽然更"炫"，但不建议一开始就用。保留一行状态提示更符合终端用户的习惯。

### 6.2 带 Spinner 的动态提示

实现一个简单的 Spinner 动画效果：

```java
/**
 * AI 处理 Spinner 字符序列
 */
private static final String[] SPINNER = {"|", "/", "-", "\\"};

/**
 * 显示带 Spinner 的动态 AI 处理提示
 * <p>定期更新提示中的 Spinner 字符，提供动态反馈
 *
 * @param terminalView 终端视图实例
 * @param jbWidget     JBTerminalWidget 实例
 * @param project      项目实例
 * @return 定时任务，用于取消 Spinner 更新
 */
private static ScheduledFuture<?> showAnimatedAiHint(@Nullable TerminalView terminalView,
                                                      @Nullable JBTerminalWidget jbWidget,
                                                      @NotNull Project project) {
    AtomicInteger spinnerIndex = new AtomicInteger(0);

    ScheduledExecutorService executor = AppExecutorUtil.getAppScheduledExecutorService();
    return executor.scheduleWithFixedDelay(() -> {
        String spinner = SPINNER[spinnerIndex.getAndIncrement() % SPINNER.length];
        String hint = "\n\u001B[32m[AI]\u001B[0m 正在分析请求... " + spinner + "\u001B[2K\r";

        if (terminalView != null) {
            terminalView.sendText(hint);
        } else if (jbWidget != null) {
            jbWidget.sendString(hint);
        }
    }, 0, 200, TimeUnit.MILLISECONDS);
}
```

## 7 完整集成

### 7.1 集成到 TerminalAiGenerateAction

在现有的 `TerminalAiGenerateAction` 中完整集成状态提示：

```java
@Override
public void actionPerformed(@NotNull AnActionEvent e) {
    Project project = e.getProject();
    if (project == null) {
        return;
    }

    // ... 验证和获取输入 ...

    TerminalView terminalView = getTerminalView(e);
    JBTerminalWidget jbWidget = e.getData(JBTerminalWidget.TERMINAL_DATA_KEY);

    // 显示处理开始提示
    showAiProcessingHint(terminalView, jbWidget);

    ProgressManager.getInstance().run(new Task.Backgroundable(
        project,
        TerminalBundle.message("action.terminal.progress"),
        true
    ) {
        @Override
        public void run(@NotNull ProgressIndicator indicator) {
            try {
                // ... AI 处理逻辑 ...

                // 处理成功，替换当前行
                if (terminalView != null) {
                    replaceCurrentLine(terminalView, command, inputInfo.multiLine);
                } else {
                    replaceCurrentLine(jbWidget, command, project, inputInfo.multiLine);
                }

                // 可选：显示成功提示
                showAiStatusHint(terminalView, jbWidget, AiStatus.SUCCESS);

            } catch (AIServiceException ex) {
                // 处理失败，显示错误提示
                showAiStatusHint(terminalView, jbWidget, AiStatus.FAILED);
                NotificationUtil.showError(project, TerminalBundle.message("error.ai.failed", ex.getMessage()));
            }
        }
    });
}
```

### 7.2 完整的辅助方法

```java
/**
 * 显示 AI 处理状态提示
 *
 * @param terminalView 终端视图实例
 * @param jbWidget     JBTerminalWidget 实例
 * @param status       状态类型
 */
private static void showAiStatusHint(@Nullable TerminalView terminalView,
                                     @Nullable JBTerminalWidget jbWidget,
                                     @NotNull AiStatus status) {
    if (terminalView == null && jbWidget == null) {
        return;
    }

    String hint = "\n" + status.getMessage() + "\n";

    if (terminalView != null) {
        terminalView.sendText(hint);
    } else if (jbWidget != null) {
        try {
            if (jbWidget.getTtyConnector() != null && jbWidget.getTtyConnector().isConnected()) {
                jbWidget.getTtyConnector().write(hint);
            } else {
                jbWidget.sendString(hint);
            }
        } catch (IOException ex) {
            log.debug("Failed to send status hint to terminal", ex);
        }
    }
}

/**
 * 显示 AI 处理开始提示（简化方法）
 */
private static void showAiProcessingHint(@Nullable TerminalView terminalView,
                                         @Nullable JBTerminalWidget jbWidget) {
    showAiStatusHint(terminalView, jbWidget, AiStatus.PROCESSING);
}
```

## 8 最佳实践

### 8.1 推荐做法

1. **使用简单提示**：开始时使用最简单的文本提示，稳定后再添加颜色和动画
2. **保持一致性**：提示格式应该保持一致，方便用户识别
3. **及时反馈**：在 AI 处理开始前立即显示提示，不要延迟
4. **优雅降级**：如果终端不支持颜色，应该自动降级到普通文本

### 8.2 避免的做法

#### ❌ 不要修改 Shell Prompt

```java
// ❌ 错误做法
Runtime.getRuntime().exec("export PS1='[AI] $PS1'");
```

**原因：**

- 侵入性极强
- 不同 shell 语法不一致
- 用户会反感

#### ❌ 不要用 ToolWindow UI 覆盖终端

```java
// ❌ 错误做法
ToolWindow toolWindow = ToolWindowManager.getInstance(project).getToolWindow("Terminal");
toolWindow.setContent(...);
```

**原因：**

- Terminal 就应该是 Terminal
- 状态写进终端才"自然"

#### ❌ 不要用 Notification / Balloon

```java
// ❌ 错误做法
NotificationUtil.showInfo(project, "[AI] 正在分析请求...");
```

**原因：**

- 太重，打断操作流
- 不符合终端交互习惯

### 8.3 实现检查清单

- [ ] 支持 `TerminalView` 和 `JBTerminalWidget` 两种终端
- [ ] 在 AI 处理开始前立即显示提示
- [ ] 使用 ANSI 颜色增强视觉效果
- [ ] 处理终端连接失败的情况
- [ ] 提供不同状态的提示（处理中/成功/失败）
- [ ] 添加日志记录，便于调试

## 9 常见问题

### 9.1 提示没有显示

**问题：**状态提示没有出现在终端中

**解决方案：**

1. **检查终端类型**：确认使用的是 `TerminalView` 还是 `JBTerminalWidget`
2. **检查连接状态**：对于 `JBTerminalWidget`，确保 `TtyConnector` 已连接
3. **检查线程**：确保在正确的线程中调用（UI 操作在 EDT，终端写入可以在 BGT）

```java
// 确保在正确的线程中
ApplicationManager.getApplication().invokeLater(() -> {
    if (terminalView != null) {
        terminalView.sendText(hint);
    }
});
```

### 9.2 ANSI 颜色不显示

**问题：**ANSI 转义码没有生效，显示为普通文本

**解决方案：**

1. **检查终端支持**：某些终端可能不支持 ANSI 颜色
2. **添加颜色检测**：可以检测终端类型，动态决定是否使用颜色
3. **优雅降级**：如果不支持颜色，自动降级到普通文本

```java
private static boolean isColorSupported(@Nullable TerminalView terminalView,
                                        @Nullable JBTerminalWidget jbWidget) {
    // 简单检测：大多数现代终端都支持
    // 可以根据实际情况添加更精确的检测
    return true;
}

private static String buildHint(@NotNull AiStatus status, boolean useColor) {
    if (useColor) {
        return status.getMessage();
    } else {
        // 移除 ANSI 转义码
        return status.getMessage().replaceAll("\u001B\\[[0-9;]*m", "");
    }
}
```

### 9.3 提示与命令混淆

**问题：**提示出现在命令输入行，与用户输入混淆

**解决方案：**

1. **使用换行**：在提示前后添加换行符，确保提示在独立行
2. **先清除当前行**：如果需要，可以先清除当前输入行，再显示提示

```java
// 推荐：在提示前后添加换行
String hint = "\n[AI] 正在分析请求...\n";

// 不推荐：提示在同一行
String hint = "[AI] 正在分析请求...";  // ❌
```

### 9.4 多次触发时提示重复

**问题：**用户快速多次按 TAB，导致提示重复显示

**解决方案：**

1. **添加状态检查**：检查是否已经在处理中，避免重复触发
2. **去重处理**：检测并跳过重复的提示

```java
private static final AtomicBoolean isProcessing = new AtomicBoolean(false);

public void actionPerformed(@NotNull AnActionEvent e) {
    if (!isProcessing.compareAndSet(false, true)) {
        // 已经在处理中，忽略本次触发
        return;
    }

    try {
        showAiProcessingHint(terminalView, jbWidget);
        // ... AI 处理 ...
    } finally {
        isProcessing.set(false);
    }
}
```

## 10 实现示例

### 10.1 完整代码示例

```java
public class TerminalAiGenerateAction extends DumbAwareAction {

    private static final AtomicBoolean isProcessing = new AtomicBoolean(false);

    @Override
    public void actionPerformed(@NotNull AnActionEvent e) {
        Project project = e.getProject();
        if (project == null) {
            return;
        }

        // 防止重复触发
        if (!isProcessing.compareAndSet(false, true)) {
            log.debug("AI processing already in progress, skipping");
            return;
        }

        try {
            // ... 验证和获取输入 ...

            TerminalView terminalView = getTerminalView(e);
            JBTerminalWidget jbWidget = e.getData(JBTerminalWidget.TERMINAL_DATA_KEY);

            // 显示处理开始提示
            showAiProcessingHint(terminalView, jbWidget);

            ProgressManager.getInstance().run(new Task.Backgroundable(project, "生成命令", true) {
                @Override
                public void run(@NotNull ProgressIndicator indicator) {
                    try {
                        // ... AI 处理逻辑 ...

                        // 处理成功，替换当前行
                        if (terminalView != null) {
                            replaceCurrentLine(terminalView, command, inputInfo.multiLine);
                        } else {
                            replaceCurrentLine(jbWidget, command, project, inputInfo.multiLine);
                        }

                    } catch (AIServiceException ex) {
                        // 处理失败，显示错误提示
                        showAiStatusHint(terminalView, jbWidget, AiStatus.FAILED);
                        NotificationUtil.showError(project, TerminalBundle.message("error.ai.failed", ex.getMessage()));
                    } finally {
                        isProcessing.set(false);
                    }
                }
            });

        } catch (Exception ex) {
            isProcessing.set(false);
            throw ex;
        }
    }

    /**
     * 显示 AI 处理状态提示
     */
    private static void showAiStatusHint(@Nullable TerminalView terminalView,
                                         @Nullable JBTerminalWidget jbWidget,
                                         @NotNull AiStatus status) {
        if (terminalView == null && jbWidget == null) {
            return;
        }

        String hint = "\n" + status.getMessage() + "\n";

        ApplicationManager.getApplication().invokeLater(() -> {
            if (terminalView != null) {
                terminalView.sendText(hint);
            } else if (jbWidget != null) {
                try {
                    if (jbWidget.getTtyConnector() != null && jbWidget.getTtyConnector().isConnected()) {
                        jbWidget.getTtyConnector().write(hint);
                    } else {
                        jbWidget.sendString(hint);
                    }
                } catch (IOException ex) {
                    log.debug("Failed to send status hint to terminal", ex);
                }
            }
        });
    }

    /**
     * 显示 AI 处理开始提示
     */
    private static void showAiProcessingHint(@Nullable TerminalView terminalView,
                                             @Nullable JBTerminalWidget jbWidget) {
        showAiStatusHint(terminalView, jbWidget, AiStatus.PROCESSING);
    }

    /**
     * AI 状态类型
     */
    private enum AiStatus {
        PROCESSING("\u001B[32m[AI]\u001B[0m 正在分析请求..."),
        SUCCESS("\u001B[32m[AI]\u001B[0m 命令已生成"),
        FAILED("\u001B[31m[AI]\u001B[0m 无法生成命令");

        private final String message;

        AiStatus(String message) {
            this.message = message;
        }

        public String getMessage() {
            return message;
        }
    }
}
```
