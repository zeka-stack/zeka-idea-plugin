## 1 简介

该模板已集成 IntelliAI Engine，提供可运行的最小 AI 插件骨架，适合快速创建具备 AI 能力的子插件。模板内置了完整的 AI 集成能力，包括 AI
服务商选择、设置页面、状态栏扩展点、AI 接口调用等。

## 2 功能特性

- 🤖 **AI 服务商选择**：复用 Engine 的 `AIProviderSelectionPanel`，自动读取已验证的服务商
- ⚙️ **设置页面与持久化配置**：完整的 `SettingsState` 实现，支持系统提示词和示例模板配置
- 🧩 **状态栏扩展点接入**：通过 Engine 的状态栏扩展点注册快捷设置入口
- 🧪 **AI 接口调用示例**：非流式 AI 调用示例，包含错误处理和日志输出
- 🌍 **国际化与图标管理**：内置多语言支持和图标管理类
- 🔄 **插件更新信息入口**：集成 `PluginUpdateInfoProvider`，统一插件更新信息
- 💬 **反馈面板**：集成 `FeedbackPanel`，用于收集用户反馈

## 3 快速开始

### 3.1 配置 IntelliAI Engine

在使用插件之前，需要先配置 IntelliAI Engine：

1. 打开 Settings → Tools → IntelliAI Engine
2. 添加并验证 AI 服务商（如 OpenAI、通义千问、Ollama 等）
3. 确保至少有一个服务商验证成功

### 3.2 打开示例插件设置

1. 打开 Settings → Tools → IntelliAI Engine → 🧩 IntelliAI Terminal
2. 选择 AI 服务商（从已验证的服务商中选择）
3. （可选）勾选"显示高级设置"以配置提示词模板：
    - **系统提示词**：设定 AI 角色和行为准则
    - **示例模板**：用于生成示例内容的提示词模板，使用 `{content}` 作为占位符

### 3.3 执行示例动作

1. 在编辑器中打开任意文件
2. 右键点击文件，选择"使用 AI 生成示例"
3. 插件会在后台调用 AI 服务生成内容
4. 结果会显示在通知中，详细日志会输出到 Engine Console

## 5 使用说明

### 5.1 AI 服务商选择

设置页默认集成 `AIProviderSelectionPanel`：

- **自动读取**：自动读取 Engine 已验证的服务商列表
- **无服务商提示**：如果没有已验证的服务商，会显示跳转链接到 Engine 设置页面
- **自动刷新**：当 Engine 中的服务商配置变更时，下拉列表会自动刷新
- **配置持久化**：选中的服务商配置会保存到插件设置中

### 5.2 设置页面

设置页面位于 `Settings → Tools → IntelliAI Engine → 🧩 IntelliAI Terminal`，包含以下配置项：

#### 5.2.1 基础设置

- **AI 服务商选择**：从已验证的服务商中选择一个作为默认服务商

#### 5.2.2 高级设置（可选）

勾选"显示高级设置"复选框后，可以配置：

- **系统提示词**：用于设定 AI 角色和行为准则的系统提示词
    - 默认值：`你是一位经验丰富的软件开发助手。你的目标是帮助开发者完成各种开发任务。你总是提供清晰、准确、有用的建议和解决方案。`
    - 可以通过"重置"按钮恢复默认值

- **示例模板**：用于生成示例内容的提示词模板
    - 使用 `{content}` 作为占位符，会在运行时替换为实际内容
    - 默认值包含示例格式和要求说明
    - 可以通过"重置"按钮恢复默认值

### 5.3 状态栏

插件通过扩展点注册状态栏菜单，展示：

- **AI 服务商切换**：快速切换当前使用的 AI 服务商
- **快捷设置入口**：快速打开插件设置页面

状态栏入口位于 IDE 底部状态栏，点击 IntelliAI Engine 图标可以看到子插件菜单。

### 5.4 AI 接口调用（非流式）

示例 Action 使用 `AIService` 调用生成内容：

1. **获取服务**：通过 `ApplicationManager.getApplication().getService(AIService.class)` 获取 AI 服务
2. **构建请求**：使用 `AIChatRequest` 构建请求，包含系统提示词和用户提示词
3. **执行调用**：在后台任务中调用 `aiService.generateContent()` 方法
4. **处理结果**：
    - 成功：输出到 Engine Console 并显示通知
    - 失败：记录错误日志并显示错误通知

### 5.5 控制台日志

所有 AI 请求和响应都会输出到 Engine Console：

- **请求日志**：使用 `AIConsoleLoggerUtil.printWithTimestamp()` 记录请求开始
- **响应日志**：使用 `AIConsoleLoggerUtil.printSuccess()` 和 `AIConsoleLoggerUtil.print()` 记录响应内容
- **错误日志**：使用 `AIConsoleLoggerUtil.printError()` 记录错误信息

打开 Engine Console：`View → Tool Windows → IntelliAI Console`

### 5.6 插件更新信息

插件集成了 `PluginUpdateInfoProvider`，可以在 Engine 的更新检查中显示插件更新信息。

### 5.7 反馈面板

设置页面底部集成了 `FeedbackPanel`，用户可以：

- 提交反馈
- 报告问题
- 提出建议

## 6 开发指南

### 6.1 添加新的 Action

1. 在 `action` 包下创建新的 Action 类，继承 `AnAction`
2. 实现 `actionPerformed()` 方法，在其中调用 AI 服务
3. 可选：实现 `update()` 方法控制 Action 的启用状态
4. 在 `plugin.xml` 中注册 Action
5. 添加到相应的菜单组（如 `EditorPopupMenu`）

### 6.2 添加新的设置项

1. 在 `SettingsState` 中添加新的配置字段
2. 在 `TerminalSettingsPanel` 中添加对应的 UI 组件
3. 在 `isModified()` 和 `apply()` 方法中处理新配置项

### 6.3 使用 AI 服务

```java
// 获取 AI 服务
AIService aiService = ApplicationManager.getApplication().getService(AIService.class);

// 构建请求
AIChatRequest request = new AIChatRequest(systemPrompt, userPrompt);

// 调用服务（非流式）
String result = aiService.generateContent(project, request, providerConfig, null);

// 处理结果
AIConsoleLoggerUtil.print(project, result);
NotificationUtil.showInfo(project, "生成成功");
```

### 6.4 使用控制台日志

```java
// 记录带时间戳的日志
AIConsoleLoggerUtil.printWithTimestamp(project, "开始处理");

// 记录成功日志
AIConsoleLoggerUtil.printSuccess(project, "处理完成");

// 记录普通日志
AIConsoleLoggerUtil.print(project, "处理结果：\n" + result);

// 记录错误日志
AIConsoleLoggerUtil.printError(project, "处理失败：" + error);
```

## 7 构建和发布

### 7.1 构建插件

```bash
./gradlew buildPlugin
```

构建产物位于 `build/distributions/` 目录。

### 7.2 发布插件

```bash
./gradlew publishPlugin
```

需要配置以下环境变量：

- `PUBLISH_TOKEN`：JetBrains Marketplace 发布令牌
- `CERTIFICATE_CHAIN`：证书链（可选）
- `PRIVATE_KEY`：私钥（可选）
- `PRIVATE_KEY_PASSWORD`：私钥密码（可选）

### 7.3 本地开发

```bash
# 运行插件（会自动构建和安装 Engine 插件）
./gradlew runIde
```

本地开发时，`buildAiCommonPlugin` 和 `copyAiCommonPlugin` 任务会自动处理 Engine 插件的构建和安装。

## 8 系统要求

- IntelliJ IDEA 2022.3 或更高版本
- Java 17+
- Gradle 8.0+
- IntelliAI Engine 插件（本地开发时自动安装，生产环境需单独安装）

## 9 常见问题

### 9.1 没有服务商

**问题**：设置页面显示"没有可用的服务商"

**解决方案**：

1. 打开 Settings → Tools → IntelliAI Engine
2. 添加并验证至少一个 AI 服务商
3. 返回插件设置页面，服务商列表会自动刷新

### 9.2 无输出

**问题**：执行 Action 后没有看到结果

**解决方案**：

1. 检查是否开启了"详细日志"（在 Engine 设置中）
2. 打开 Engine Console 查看详细日志
3. 确认服务商配置可用且已验证
4. 检查网络连接是否正常

### 9.3 AI 调用失败

**问题**：显示错误通知，提示 AI 调用失败

**解决方案**：

1. 检查服务商的 API Key 是否正确
2. 检查服务商的配置是否有效
3. 查看 Engine Console 中的详细错误信息
4. 确认服务商的 API 配额是否充足

### 9.4 状态栏不显示

**问题**：状态栏中没有看到插件菜单

**解决方案**：

1. 确认已安装 IntelliAI Engine 插件
2. 重启 IDE
3. 检查 `plugin.xml` 中的扩展点注册是否正确
