# IntelliAI Terminal

> **让终端"听懂人话"的 AI 命令行助手**

![](./assets/20260121_S1Bp2c.png)

在 IntelliJ IDEA 的终端里，用自然语言直接生成可执行命令。无需记忆复杂的 shell 语法，无需切换窗口查找文档，只需输入描述，按 TAB 键即可获得正确的命令。

## Why This Plugin?

当你已经在终端里工作时，为什么还要切换到一个独立的 AI CLI 工具？

现有 AI 工具（如 Claude Code、Codex、Gemini CLI）非常强大，但它们适合复杂任务、长时间交互和多步推理。而在真实工程实践中，大多数终端操作其实是：

- **临时的** - 一次性的查询或操作
- **高频的** - 每天重复数十次
- **简单的** - 只是"记不住参数"的问题

为了这一行命令，你不应该：

- ❌ 切换工具窗口
- ❌ 进入 AI 交互模式
- ❌ 重新描述上下文
- ❌ 从输出中提取命令

我们的插件选择**融入，而不是替代**：

- ✅ 不改变你的终端
- ✅ 不重塑你的习惯
- ✅ 不引入新的心智负担

它只在你需要的时候，轻轻帮你补上那一行命令。

### 设计理念

这个插件遵循三个核心原则：

1. **最小认知负担** - 没有新的工作流，没有新的命令系统，只是在原有终端习惯上加一个 TAB 键
2. **单一职责** - 只做一件事：将自然语言转换为可执行的 shell 命令
3. **安全失败** - 即使失败，最坏情况也只是"没有生成命令"，不会产生不可逆影响

> 好的工具，不是让你做得更多，而是让你更少被打断。

## 核心功能

![](./assets/20260121_RP9Tdk.gif)

- **🚀 自然语言生成 Shell 命令** - 在终端输入中文或英文描述，自动生成可直接执行的命令
- **⚡ Tab 一键补全，不打断操作流** - 无需切换窗口，输入 `#` + 描述，按 Tab 即可生成命令
- **🧠 基于当前目录的智能上下文感知** - 自动识别 Git / Docker / Kubernetes / 构建工具，生成更贴合项目的命令
- **🛡 只生成可运行命令，无多余废话** - 不输出解释、不输出 Markdown，生成内容可直接复制或执行
- **📐 复杂命令自动换行，清晰可读** - 长命令自动使用 `\` 拆分，兼顾可读性与可维护性

## 快速开始

### 前置条件

1. **IntelliJ IDEA 2025.3+** - 插件需要 IntelliJ IDEA 2025.3 或更高版本
2. **IntelliAI Engine 插件** - 必须安装 [IntelliAI Engine](https://plugins.jetbrains.com/plugin/29152) 插件
3. **AI 服务商配置** - 在 `Settings → Tools → IntelliAI Engine` 中配置并验证至少一个 AI 服务商

### 使用步骤

1. 打开 Terminal（`Alt + F12` 或 `View → Tool Windows → Terminal`）
2. 输入自然语言描述，以 `#` 开头（如：`# 列出当前目录下所有 Python 文件`）
3. 按 `TAB` 键触发 AI 生成
4. 生成的命令会自动替换当前行，可以直接执行或继续编辑

## 典型使用场景

### 场景 1：日常排查

```
# 查找所有包含 TODO 的 Java 文件
# 按 TAB → find . -type f -name "*.java" -exec grep -l "TODO" {} +
```

### 场景 2：Docker / Kubernetes 项目

在 Docker / K8s 项目目录下：

```
# 查看当前服务状态
# 按 TAB → docker ps 或 kubectl get pods
```

插件会自动选择最合适的命令，而不是泛泛而谈。

### 场景 3：复杂命令，不再手写

```
# 删除 7 天前的日志，命令尽量完整
# 按 TAB → find /var/log -name "*.log" -type f -mtime +7 -delete
```

生成的是结构化、多参数、可维护的命令。

## 配置说明

配置路径：`Settings → Tools → IntelliAI Engine → 🧩 IntelliAI Terminal`

### 基础配置

- **启用 Terminal AI** - 控制是否启用功能（默认已启用）
- **触发前缀** - 只有以该前缀开头的行才会触发 AI 生成（默认 `#`）
- **AI 服务商** - 选择默认使用的 AI 服务商（默认使用全局第一个已验证的服务商）

### 高级配置

勾选"显示高级设置"后，可以自定义：

- **系统提示词** - 设定 AI 角色和行为准则
- **用户提示词模板** - 用于生成终端命令的提示词模板

## 技术实现

### 核心流程

1. **输入提取** - 从终端最后一行提取非空内容，去除 shell 提示符
2. **AI 调用** - 在后台线程调用 AI 服务，不阻塞 UI
3. **结果处理** - 提取有效命令，验证格式，替换当前行

### 技术要点

- **线程安全** - 遵循 IntelliJ Platform 线程模型
- **终端兼容** - 同时支持 `TerminalView` 和 `JBTerminalWidget`
- **错误处理** - 完善的错误处理和用户提示机制

## 常见问题

**Q: 按 TAB 键没有反应？**

A: 检查以下几点：

1. 确认已启用 Terminal AI
2. 确认当前行以触发前缀开头（默认 `#`）
3. 确认已配置并验证至少一个 AI 服务商
4. 查看 Engine Console 是否有错误日志

**Q: 生成的命令不正确？**

A: 可以尝试：
1. 调整系统提示词，更明确地说明需求
2. 优化用户输入，使用更清晰的自然语言描述
3. 在设置页面自定义提示词模板

## 设计哲学

这个插件不是在"功能强弱"上与现有工具竞争，而是选择了不同的设计目标：

- **大而全的 AI 工具** 解决"复杂问题"
- **我们的插件** 解决"你此刻正在做的这一步"

我们不试图取代任何已有的强大工具，而是希望在一个非常具体的时刻，成为最合适的那个工具。

> 我们不做"替你思考一切"的工具，只做"在你已经思考时，帮你快一步"的工具。
