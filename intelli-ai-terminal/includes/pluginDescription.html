IntelliAI Terminal brings AI directly into the IDE Terminal. Generate shell commands from natural language descriptions by pressing TAB, significantly improving terminal efficiency.

GitHub | Issues | Homepage

⚡ Powered by IntelliAI Engine: Seamlessly integrates with IntelliAI Engine to provide unified, pluggable, and high-performance AI capabilities

Why This Plugin?

When working in the terminal, you often need to remember various shell commands or switch windows to look them up. This plugin solves this problem by:

  • Natural Language Input: Simply describe what you want to do in natural language
  • One-Click Generation: Press TAB to instantly generate the corresponding command
  • Context Awareness: IDE provides more context than standalone terminal tools, making AI-generated commands more accurate
  • No Context Switching: Complete all operations within IDEA without leaving your development environment

Core Features

  • 🚀 One-Click Command Generation: Generate shell commands from natural language by pressing TAB
  • 📝 Smart Input Extraction: Automatically extracts user input from the last terminal line, supporting removal of shell prompts ($, >, etc.)
  • 🔄 Automatic Replacement: Generated commands automatically replace the current terminal line, ready to execute or edit
  • ✅ Format Validation: Automatically validates generated command format to ensure valid shell commands
  • 🎯 Prefix Trigger: Support custom trigger prefix (default #), only lines starting with the prefix trigger AI generation
  • 🔌 Dual Terminal Support: Supports both TerminalView and JBTerminalWidget implementations
  • ⚡ Background Execution: AI calls execute in background threads without blocking UI
  • 📊 Streaming Response: Optional streaming response support for real-time command generation
  • 🧠 Context Detection: Optional context detection for smarter command generation (may increase latency)
  • 🎨 Customizable Prompts: Support custom system and user prompt templates for different scenarios

Usage

  • Open Terminal (Alt+F12 or View → Tool Windows → Terminal)
  • Enter natural language description starting with trigger prefix (default #), e.g.: # List all Python files in current directory
  • Press TAB to trigger AI generation
  • Generated command will automatically replace the current line, ready to execute or continue editing

Configuration

Configuration path: Settings → Tools → IntelliAI Engine → 🧩 IntelliAI Terminal

  • Enable/disable Terminal AI (enabled by default)
  • Configure trigger prefix (default #)
  • Select AI provider (defaults to first verified global provider)
  • Customize system and user prompt templates (advanced settings)
  • Enable streaming response (optional)
  • Enable context detection (optional, may increase latency)

Requirements

  • IntelliJ IDEA 2025.3+: Plugin requires IntelliJ IDEA 2025.3 or higher (Terminal API requires 2025.3+)
  • IntelliAI Engine Plugin: Must install IntelliAI Engine plugin and configure at least one AI provider
  • AI Provider Configuration: Configure and verify at least one AI provider in Settings → Tools → IntelliAI Engine

IntelliAI Terminal

将 AI 直接注入到 IDE 的 Terminal 中，通过自然语言描述按 TAB 键即可生成 shell 命令，大幅提升终端使用效率。 与独立终端工具不同，本插件充分利用 IDEA 提供的上下文信息，让 AI 生成的命令更加准确、智能。

为什么选择这个插件？

在终端中工作时，经常需要记住各种 shell 命令，或者切换窗口去查找命令。本插件通过以下方式解决这些问题：

  • 自然语言输入：只需用自然语言描述你想要做什么
  • 一键生成：按 TAB 键即可瞬间生成对应的命令
  • 上下文感知：IDE 提供的上下文比独立终端工具更丰富，让 AI 生成的命令更加准确
  • 无需切换窗口：在 IDEA 中完成所有操作，无需离开开发环境

核心功能

  • 🚀 一键生成命令：在终端输入自然语言描述，按 TAB 键即可生成对应的命令
  • 📝 智能提取：自动从终端最后一行提取输入内容，支持去除 shell 提示符（$、> 等）
  • 🔄 自动替换：生成的命令会自动替换当前终端行，可直接执行或继续编辑
  • ✅ 格式验证：自动验证生成的命令格式，确保输出是有效的 shell 命令
  • 🎯 前缀触发：支持自定义触发前缀（默认 #），只有以该前缀开头的行才会触发 AI 生成
  • 🔌 双终端支持：同时支持 TerminalView 和 JBTerminalWidget 两种终端实现
  • ⚡ 后台执行：AI 调用在后台线程执行，不会阻塞 UI
  • 📊 流式输出：支持可选的流式响应，实时显示命令生成过程
  • 🧠 上下文检测：可选启用上下文检测功能，让生成的命令更加智能（可能增加延迟）
  • 🎨 提示词定制：支持自定义系统提示词和用户提示词模板，满足不同场景需求

使用方式

  • 打开 Terminal（Alt+F12 或 视图 → 工具窗口 → Terminal）
  • 输入自然语言描述，以触发前缀开头（默认 #），例如：# 列出当前目录下所有 Python 文件
  • 按 TAB 键触发 AI 生成
  • AI 生成的命令会自动替换当前行，可以直接执行或继续编辑

配置说明

配置路径：Settings → Tools → IntelliAI Engine → 🧩 IntelliAI Terminal

  • 启用/禁用 Terminal AI（默认已启用）
  • 配置触发前缀（默认 #）
  • 选择 AI 服务商（默认使用全局第一个已验证的服务商）
  • 自定义系统提示词和用户提示词模板（高级设置）
  • 启用流式输出（可选）
  • 启用上下文检测（可选，可能增加延迟）

系统要求

  • IntelliJ IDEA 2025.3+：插件需要 IntelliJ IDEA 2025.3 或更高版本（Terminal API 要求 2025.3+）
  • IntelliAI Engine 插件：必须安装 IntelliAI Engine 插件并配置至少一个 AI 服务商
  • AI 服务商配置：在 Settings → Tools → IntelliAI Engine 中配置并验证至少一个 AI 服务商
