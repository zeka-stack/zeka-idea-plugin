IntelliAI Terminal brings AI directly into the IDE Terminal. Generate safe commands, explain outputs, and accelerate troubleshooting with a unified AI provider setup powered by IntelliAI Engine.


⚡ Powered by IntelliAI Engine: Unified AI provider management, fast response, and consistent UX across the IDE.

Key Features

  • 🤖 AI Terminal Assistant: Generate commands and operational steps from natural language
  • 🧠 Output Explanation: Explain command output and suggest next actions
  • ⚙️ Prompt Templates: Customize system and terminal prompts
  • 📌 Status Bar Quick Settings: Switch AI providers and open settings quickly
  • 💬 Feedback Panel: Built-in feedback entry for continuous improvement

Development Environment

  • JDK 17+
  • Gradle 8.0+
  • IntelliJ IDEA 2022.3+
  • IntelliAI Engine plugin (auto-installed in local dev)

Quick Start

  1. Configure AI providers in Settings → Tools → IntelliAI Engine
  2. Open Terminal and trigger the AI action
  3. Review and run generated commands safely

IntelliAI Terminal 将 AI 注入到 IDE 的 Terminal 中，支持生成安全命令、解释输出并加速问题排查，依赖 IntelliAI Engine 统一管理 AI 服务商。


⚡ 由 IntelliAI Engine 驱动：统一的 AI 服务商配置、稳定的响应能力与一致的使用体验。

核心特性

  • 🤖 AI 终端助手：自然语言生成终端命令和操作步骤
  • 🧠 输出解释：解读终端输出并给出下一步建议
  • ⚙️ 提示词模板：支持系统提示与终端提示模板配置
  • 📌 状态栏快捷设置：快速切换 AI 服务商并打开设置
  • 💬 反馈入口：内置反馈面板

开发环境

  • JDK 17+
  • Gradle 8.0+
  • IntelliJ IDEA 2022.3+
  • IntelliAI Engine 插件（本地开发自动安装）

快速开始

  1. 在 Settings → Tools → IntelliAI Engine 中配置 AI 服务商
  2. 打开 Terminal 并触发 AI 动作
  3. 确认输出后安全执行命令
