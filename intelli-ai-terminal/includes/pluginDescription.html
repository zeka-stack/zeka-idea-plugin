Generate executable shell commands directly in the IntelliJ IDEA terminal using natural language. No need to memorize complex shell syntax or switch windows to look up documentation. Simply type a description and press TAB to get the right command.

Why This Plugin?

When you're already working in the terminal, why switch to a separate AI CLI tool?

Existing AI tools (such as Claude Code, Codex, Gemini CLI) are powerful, but they're designed for complex tasks, long interactions, and multi-step reasoning. In real engineering practice, most terminal operations are actually temporary, frequent, one-off simple queries or operations.

For this one command, you shouldn't have to switch tool windows, enter AI interaction mode, or re-describe context. Our plugin chooses to integrate rather than replace: it doesn't change your terminal, reshape your habits, or introduce new cognitive load. It only helps you fill in that one command when you need it.

Key Features

  • 🚀 Natural Language → Executable Shell Commands: Type descriptions in Chinese or English, automatically generate executable commands
  • ⚡ Tab-Based Inline Completion: No window switching needed, type # + description, press Tab to generate commands
  • 🧠 Context-Aware Command Generation: Automatically detects Git / Docker / Kubernetes / build tools, generates more project-appropriate commands
  • 🛡 Only Outputs Runnable Commands: No explanations, no Markdown, generated content can be directly copied or executed
  • 📐 Readable Long Commands: Long commands are automatically formatted using \ for better readability and maintainability

Usage

  • Open Terminal (Alt+F12 or View → Tool Windows → Terminal)
  • Type a natural language description starting with trigger prefix (default #), e.g.: # List all Python files in current directory
  • Press TAB to trigger AI generation
  • Generated command will automatically replace the current line, ready to execute or continue editing

Design Philosophy

This plugin follows three core principles:

  • Minimal Cognitive Load - No new workflow, no new command system, just add a TAB key to existing terminal habits
  • Single Responsibility - Do one thing only: convert natural language to executable shell commands
  • Fail Safe - Even if it fails, the worst case is just "no command generated", no irreversible impact

Good tools don't make you do more, they make you less interrupted.

  • Configure trigger prefix (default #)
  • Select AI provider (defaults to first verified global provider)
  • Customize system and user prompt templates (advanced settings)

在 IntelliJ IDEA 的终端里，用自然语言直接生成可执行命令。无需记忆复杂的 shell 语法，无需切换窗口查找文档，只需输入描述，按 TAB 键即可获得正确的命令。

为什么选择这个插件？

当你已经在终端里工作时，为什么还要切换到一个独立的 AI CLI 工具？

现有 AI 工具（如 Claude Code、Codex、Gemini CLI）非常强大，但它们适合复杂任务、长时间交互和多步推理。而在真实工程实践中，大多数终端操作其实是临时的、高频的、一次性的简单查询或操作。

为了这一行命令，你不应该切换工具窗口、进入 AI 交互模式、重新描述上下文。我们的插件选择融入，而不是替代：不改变你的终端，不重塑你的习惯，不引入新的心智负担。它只在你需要的时候，轻轻帮你补上那一行命令。

核心特性

  • 🚀 自然语言生成 Shell 命令：在终端输入中文或英文描述，自动生成可直接执行的命令
  • ⚡ Tab 一键补全，不打断操作流：无需切换窗口，输入 # + 描述，按 Tab 即可生成命令
  • 🧠 基于当前目录的智能上下文感知：自动识别 Git / Docker / Kubernetes / 构建工具，生成更贴合项目的命令
  • 🛡 只生成可运行命令，无多余废话：不输出解释、不输出 Markdown，生成内容可直接复制或执行
  • 📐 复杂命令自动换行，清晰可读：长命令自动使用 \ 拆分，兼顾可读性与可维护性

使用方式

  • 打开 Terminal（Alt+F12 或 视图 → 工具窗口 → Terminal）
  • 输入自然语言描述，以触发前缀开头（默认 #），例如：# 列出当前目录下所有 Python 文件
  • 按 TAB 键触发 AI 生成
  • 生成的命令会自动替换当前行，可以直接执行或继续编辑

设计理念

这个插件遵循三个核心原则：

  • 最小认知负担 - 没有新的工作流，没有新的命令系统，只是在原有终端习惯上加一个 TAB 键
  • 单一职责 - 只做一件事：将自然语言转换为可执行的 shell 命令
  • 安全失败 - 即使失败，最坏情况也只是"没有生成命令"，不会产生不可逆影响

好的工具，不是让你做得更多，而是让你更少被打断。
