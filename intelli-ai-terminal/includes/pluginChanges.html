2025.3.1200

🎊 本版本是2026年春节前的最后一个版本，提前祝大家春节快乐，万事如意！🧧🎉

  • ✨ 新增：TAB 键触发 AI 生成命令功能，在终端输入自然语言描述按 TAB 即可生成命令
  • ✨ 新增：智能输入提取功能，自动从终端最后一行提取内容并去除 shell 提示符
  • ✨ 新增：自动替换功能，生成的命令自动替换当前终端行，可直接执行或继续编辑
  • ✨ 新增：命令格式验证功能，确保生成的输出是有效的 shell 命令
  • ✨ 新增：前缀触发机制，支持自定义触发前缀（默认 #），只有以该前缀开头的行才会触发 AI 生成
  • ✨ 新增：双终端支持，同时支持 TerminalView 和 JBTerminalWidget 两种终端实现
  • ✨ 新增：流式输出支持，可选的流式响应功能，实时显示命令生成过程
  • ✨ 新增：上下文检测功能，可选启用上下文检测让生成的命令更加智能（可能增加延迟）
  • ✨ 新增：自定义提示词模板，支持自定义系统提示词和用户提示词模板
  • ✨ 新增：设置页面集成，集成到 IntelliAI Engine 设置页面下，统一管理配置
  • ✨ 新增：状态栏快捷菜单，提供状态栏快捷菜单，快速切换服务商和打开设置
  • ✨ 新增：更新检查集成，集成插件更新信息提供者，统一管理更新
  • ✨ 新增：后台执行机制，AI 调用在后台线程执行，不会阻塞 UI
  • ✨ 新增：日志输出功能，所有 AI 请求和响应都会输出到 Engine Console，便于调试

2025.3.1200

🎊 This is the last version before the 2026 Chinese New Year. Wishing everyone a happy Spring Festival and all the best! 🧧🎉

  • ✨ Added: TAB key trigger for AI command generation, press TAB after entering natural language description in terminal
  • ✨ Added: Smart input extraction, automatically extracts content from the last terminal line and removes shell prompts
  • ✨ Added: Automatic replacement, generated commands automatically replace the current terminal line, ready to execute or edit
  • ✨ Added: Command format validation, ensures generated output is valid shell commands
  • ✨ Added: Prefix trigger mechanism, supports custom trigger prefix (default #), only lines starting with the prefix trigger AI generation
  • ✨ Added: Dual terminal support, supports both TerminalView and JBTerminalWidget implementations
  • ✨ Added: Streaming response support, optional streaming response feature for real-time command generation
  • ✨ Added: Context detection feature, optional context detection for smarter command generation (may increase latency)
  • ✨ Added: Customizable prompt templates, supports custom system and user prompt templates
  • ✨ Added: Settings page integration, integrated into IntelliAI Engine settings page for unified configuration management
  • ✨ Added: Status bar quick menu, provides status bar quick menu for fast provider switching and settings access
  • ✨ Added: Update check integration, integrated plugin update info provider for unified update management
  • ✨ Added: Background execution mechanism, AI calls execute in background threads without blocking UI
  • ✨ Added: Logging output feature, all AI requests and responses are logged to Engine Console for debugging
