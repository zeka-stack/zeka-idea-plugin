IntelliAI Nacos

一个强大的 IntelliJ IDEA 插件，用于在 IDE 中直接管理和操作 Nacos 配置中心。

功能特性

  • 🔧 配置管理：可视化的配置管理界面，支持配置的拉取、发布、对比、删除等操作
  • 🌳 树形展示：按 Namespace/Group/DataId 三级分组展示所有配置
  • 📝 多 Tab 编辑：支持同时编辑多个配置，提高工作效率
  • 🔄 配置对比：使用 IntelliJ Diff 工具对比本地配置和 Nacos 配置
  • ⚡ 快速发布：支持右键菜单和 Intention Action 快速发布配置
  • 🔍 智能搜索：支持在配置树中搜索配置
  • 🔐 安全认证：支持 Nacos 认证机制，密码安全存储

主要功能

  • Tool Window：提供可视化的配置管理界面
  • 配置操作：拉取、发布、对比、删除配置
  • 批量发布：支持批量发布多个配置文件到 Nacos
  • 自动完成：Namespace、Group、DataId 的智能自动完成
  • 配置对比：使用 IntelliJ Diff 工具显示配置差异

使用场景

  • 在 IDE 中直接查看和管理 Nacos 配置
  • 快速发布本地配置文件到 Nacos
  • 对比本地配置和 Nacos 配置的差异
  • 批量管理多个环境的配置

系统要求

  • IntelliJ IDEA 2022.3 或更高版本
  • Java 17+
  • Nacos 2.x 服务器
