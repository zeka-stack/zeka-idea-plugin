IntelliJ IDEA Plugin Template

这是一个 IntelliJ IDEA 插件开发模板，提供了快速创建新插件的基础框架和最佳实践。

模板特性

  • 🚀 快速开始：提供完整的项目结构和配置，开箱即用
  • 📦 依赖管理：预配置常用依赖，包括 Lombok、JUnit、Mockito 等
  • 🔧 开发工具：集成 Google Java Format、测试框架和插件验证工具
  • 🌍 国际化：内置多语言支持，提供中文和英文资源文件
  • 📝 文档完善：提供详细的使用文档和开发指南

开发环境

  • JDK 17+
  • Gradle 8.0+
  • IntelliJ IDEA 2022.3+

快速开始

  1. 克隆模板项目
  2. 修改 gradle.properties 中的插件信息
  3. 运行 ./gradlew runIde 启动沙箱环境
  4. 开始开发你的插件功能

包含功能

  • Action（操作）示例
  • Settings（设置）示例
  • Tool Window（工具窗口）示例
  • Intention（快速修复）示例
  • 完整的单元测试示例

技术栈

  • 基于 IntelliJ Platform SDK 2.1.0
  • 使用 Kotlin DSL 配置构建
  • 集成 JUnit 5 测试框架
  • 支持 Mockito 进行单元测试
