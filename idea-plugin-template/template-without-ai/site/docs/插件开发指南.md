# 插件开发指南

本文档用于说明该模板的最小可用能力与推荐实践，便于快速启动插件开发。

## 能力清单

- ⚡ 轻量级设计（无额外依赖）
- 🎯 Action 示例（右键菜单触发）
- 🌍 国际化支持（中英文资源文件）
- 🔔 通知工具（NotificationUtil）
- 🎨 图标管理（ExampleIcons）
- 📦 依赖管理（Lombok、JUnit、Mockito 等）
- 📝 插件信息常量（PluginContents）

## 推荐扩展路径

1. **替换示例 Action 为你的业务逻辑**
    - 保持 `actionPerformed()` 和 `update()` 方法结构
    - 根据项目需求实现具体功能

2. **添加更多 Action**
    - 在 `action` 包下创建新的 Action 类
    - 在 `plugin.xml` 中注册并添加到相应菜单组

3. **扩展工具类**
    - 在 `util` 包下添加新的工具类
    - 保持工具类的静态方法设计

4. **添加设置页面（如需要）**
    - 创建 `SettingsState` 实现配置持久化
    - 创建 `SettingsConfigurable` 和 `SettingsPanel` 实现设置 UI
    - 在 `plugin.xml` 中注册 `projectConfigurable`

5. **添加更多图标**
    - 在 `src/main/resources/dev/.../icons/` 目录添加 SVG 图标
    - 在 `ExampleIcons` 类中添加图标常量

6. **扩展国际化资源**
    - 在资源文件中添加新的键值对
    - 使用 `ExampleBundle.message()` 获取消息

7. **统一使用插件信息常量**
    - 从 `PluginContents` 读取插件 ID/名称，避免硬编码

## 开发最佳实践

### 1. 线程安全

遵循 IntelliJ Platform 的线程模型：

- UI 操作必须在 EDT（Event Dispatch Thread）中执行
- 使用 `ApplicationManager.getApplication().invokeLater()` 在 EDT 中执行 UI 更新
- 写操作必须使用 `runWriteAction()` 包装
- 后台任务使用 `new Thread()` 或 `CompletableFuture`

### 2. 资源管理

- 图标文件使用 SVG 格式，放置在 `src/main/resources/dev/.../icons/` 目录
- 国际化资源文件放置在 `src/main/resources/messages/` 目录
- 使用 `ExampleIcons` 和 `ExampleBundle` 统一管理资源

### 3. 代码规范

- 使用 Google Java Format 格式化代码
- 遵循 IntelliJ Platform 编码规范
- 为公共类和方法添加 Javadoc 注释

### 4. 测试

- 为关键功能编写单元测试
- 使用 JUnit 5 和 Mockito 进行测试
- 测试代码放置在 `src/test/java/` 目录

### 5. 配置管理

- 插件信息统一维护在 `gradle.properties`
- 插件 ID/名称统一维护在 `PluginContents`
- 避免在代码中硬编码配置值

## 常见开发场景

### 场景 1：添加新的右键菜单 Action

1. 创建 Action 类：

```java
public class MyAction extends AnAction {
    public MyAction() {
        super(ExampleBundle.message("action.my.title"),
              ExampleBundle.message("action.my.description"),
              ExampleIcons.EXAMPLE_16);
    }

    @Override
    public void actionPerformed(@NotNull AnActionEvent e) {
        Project project = e.getProject();
        if (project == null) return;

        // 实现你的业务逻辑
        NotificationUtil.showInfo(project, "操作完成");
    }

    @Override
    public void update(@NotNull AnActionEvent e) {
        Project project = e.getProject();
        e.getPresentation().setEnabled(project != null);
    }
}
```

2. 在 `plugin.xml` 中注册：

```xml
<action id="dev.dong4j.zeka.stack.idea.plugin.example.action.MyAction"
        class="dev.dong4j.zeka.stack.idea.plugin.example.action.MyAction">
    <add-to-group group-id="EditorPopupMenu" anchor="last"/>
</action>
```

### 场景 2：添加新的工具类

在 `util` 包下创建工具类：

```java
public final class MyUtil {
    private MyUtil() {
        // 工具类，禁止实例化
    }

    public static void doSomething(Project project) {
        // 实现工具方法
    }
}
```

### 场景 3：添加新的国际化消息

1. 在 `messages/ExampleBundle.properties` 中添加：

```properties
action.my.title=My Action
action.my.description=Execute my action
```

2. 在 `messages/ExampleBundle_zh_CN.properties` 中添加：

```properties
action.my.title=我的操作
action.my.description=执行我的操作
```

3. 使用：

```java
String title = ExampleBundle.message("action.my.title");
```

## 构建和调试

### 本地开发

```bash
# 运行插件（启动沙箱环境）
./gradlew runIde

# 构建插件
./gradlew buildPlugin

# 运行测试
./gradlew test
```

### 调试技巧

1. 使用断点调试：在代码中设置断点，运行 `./gradlew runIde` 进行调试
2. 查看日志：在 `Help → Show Log in Explorer` 查看插件日志
3. 使用通知：使用 `NotificationUtil` 显示调试信息

## 发布准备

1. **更新版本号**：在 `gradle.properties` 中更新 `pluginVersion`
2. **更新更新记录**：在 `includes/pluginChanges.html` 中添加更新内容
3. **更新文档**：确保文档与功能一致
4. **测试**：确保所有功能正常工作
5. **构建**：执行 `./gradlew buildPlugin` 生成插件包
