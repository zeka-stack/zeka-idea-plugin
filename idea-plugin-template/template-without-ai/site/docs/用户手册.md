# 插件模板用户手册（不带 AI）

## 简介

该模板提供轻量级的 IntelliJ IDEA 插件开发骨架，适合快速创建工具类插件，无需 AI 集成。

## 功能特性

- ⚡ **轻量级设计**：无额外依赖，插件体积小，启动速度快
- 🎯 **Action 示例**：完整的 Action 实现示例
- 🌍 **国际化支持**：内置多语言资源文件
- 🔔 **通知工具**：统一的 NotificationUtil 工具类
- 🎨 **图标管理**：图标管理类统一管理插件图标资源
- 📦 **依赖管理**：预配置常用依赖，包括 Lombok、JUnit、Mockito 等

## 快速开始

1. **复制模板并修改插件信息**
    - 修改 `gradle.properties` 中的插件信息
    - 修改包名和类名
    - 更新 `plugin.xml` 中的类引用和插件 ID

2. **运行插件验证环境**
    - 执行 `./gradlew runIde` 启动沙箱环境

3. **替换示例 Action 为你的业务逻辑**
    - 保持项目结构，专注于功能实现

## 目录结构（关键部分）

```
site/docs/                 # 文档目录
src/main/java/.../example/
  action/                  # 示例 Action
  util/                    # 工具类
  icons/                   # 图标管理类
```

## 使用说明

### Action 示例

模板提供了一个简化的 Action 示例，通过右键菜单触发：

1. 在编辑器中右键点击文件
2. 选择 "Example Action"
3. 插件会执行相应的操作并显示通知

### 图标管理

使用 `ExampleIcons` 类管理插件图标：

```java
import icons.ExampleIcons;

// 使用图标
Icon icon = ExampleIcons.EXAMPLE_16;
```

图标文件应放置在 `src/main/resources/dev/.../icons/` 目录下。

### 国际化

使用 `ExampleBundle` 类获取国际化消息：

```java
import dev.dong4j.zeka.stack.idea.plugin.example.util.ExampleBundle;

String message = ExampleBundle.message("action.example.title");
```

资源文件位置：

- `src/main/resources/messages/ExampleBundle.properties`（英文）
- `src/main/resources/messages/ExampleBundle_zh_CN.properties`（中文）

### 通知工具

使用 `NotificationUtil` 类显示通知：

```java
import dev.dong4j.zeka.stack.idea.plugin.example.util.NotificationUtil;

NotificationUtil.showInfo(project, "操作成功");
NotificationUtil.showError(project, "操作失败");
NotificationUtil.showWarning(project, "警告信息");
```

### 插件信息常量

使用 `PluginContents` 类统一管理插件信息：

```java
import dev.dong4j.zeka.stack.idea.plugin.example.PluginContents;

String pluginId = PluginContents.PLUGIN_ID;
String pluginName = PluginContents.PLUGIN_NAME;
```

## 开发指南

### 添加新的 Action

1. 在 `action` 包下创建新的 Action 类，继承 `AnAction`
2. 实现 `actionPerformed()` 方法
3. 可选：实现 `update()` 方法控制 Action 的启用状态
4. 在 `plugin.xml` 中注册 Action
5. 添加到相应的菜单组（如 `EditorPopupMenu`）

### 添加新的图标

1. 将图标文件（SVG 格式）放置在 `src/main/resources/dev/.../icons/` 目录
2. 在 `ExampleIcons` 类中添加图标常量
3. 使用 `load()` 方法加载图标

### 添加国际化消息

1. 在 `messages/ExampleBundle.properties` 中添加英文消息
2. 在 `messages/ExampleBundle_zh_CN.properties` 中添加中文消息
3. 使用 `ExampleBundle.message()` 获取消息

### 添加设置页面（可选）

如果需要设置页面，可以参考以下步骤：

1. 创建 `SettingsState` 类（实现 `PersistentStateComponent`）
2. 创建 `SettingsConfigurable` 类（实现 `SearchableConfigurable`）
3. 创建 `SettingsPanel` 类（UI 面板）
4. 在 `plugin.xml` 中注册 `projectConfigurable`

## 构建和发布

### 构建插件

```bash
./gradlew buildPlugin
```

构建产物位于 `build/distributions/` 目录。

### 发布插件

```bash
./gradlew publishPlugin
```

需要配置以下环境变量：

- `PUBLISH_TOKEN`：JetBrains Marketplace 发布令牌
- `CERTIFICATE_CHAIN`：证书链（可选）
- `PRIVATE_KEY`：私钥（可选）
- `PRIVATE_KEY_PASSWORD`：私钥密码（可选）

### 部署

使用 `deploy.sh` 脚本进行部署：

```bash
./deploy.sh              # 完整部署
./deploy.sh -l           # 仅部署 landing.html
./deploy.sh -z           # 仅上传 ZIP
./deploy.sh -d           # 仅部署文档
```

## 系统要求

- IntelliJ IDEA 2022.3 或更高版本
- Java 17+
- Gradle 8.0+

## 常见问题

- **Action 不显示**：检查 `plugin.xml` 中的 Action 注册和菜单组配置
- **图标不显示**：确认图标文件路径和 `ExampleIcons` 中的路径一致
- **国际化消息不显示**：检查资源文件路径和键名是否正确
- **通知不显示**：确认已在 `plugin.xml` 中注册 `notificationGroup`
