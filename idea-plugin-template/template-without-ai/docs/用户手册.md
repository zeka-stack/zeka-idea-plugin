# IntelliJ IDEA Plugin Template 用户手册

## 简介

这是一个 IntelliJ IDEA 插件开发模板，提供了快速创建新插件的基础框架和最佳实践。

## 功能特性

- 🚀 **快速开始**：提供完整的项目结构和配置，开箱即用
- 📦 **依赖管理**：预配置常用依赖，包括 Lombok、JUnit、Mockito 等
- 🔧 **开发工具**：集成 Google Java Format、测试框架和插件验证工具
- 🌍 **国际化**：内置多语言支持，提供中文和英文资源文件
- 🎨 **图标管理**：提供图标管理类，统一管理插件图标资源

## 快速开始

### 1. 克隆模板项目

```bash
git clone <repository-url>
cd template-without-ai
```

### 2. 修改插件信息

编辑 `gradle.properties` 文件，修改以下信息：

```properties
pluginGroup=dev.dong4j.zeka.stack
pluginName=Your Plugin Name
pluginVersion=1.0.0
```

### 3. 运行插件

```bash
./gradlew runIde
```

这将启动一个包含插件的 IntelliJ IDEA 沙箱环境。

## 使用说明

### Action 示例

模板提供了一个简化的 Action 示例，通过右键菜单触发：

1. 在编辑器中右键点击文件
2. 选择 "Example Action"
3. 插件会执行相应的操作并显示通知

### 图标管理

使用 `ExampleIcons` 类管理插件图标：

```java
import dev.dong4j.zeka.stack.idea.plugin.example.icons.ExampleIcons;

// 使用图标
Icon icon = ExampleIcons.EXAMPLE_16;
```

图标文件应放置在 `src/main/resources/dev/.../icons/` 目录下。

### 国际化

使用 `ExampleBundle` 类获取国际化消息：

```java
import dev.dong4j.zeka.stack.idea.plugin.example.util.ExampleBundle;

String message = ExampleBundle.message("action.example.title");
```

### 通知

使用 `NotificationUtil` 类显示通知：

```java
import dev.dong4j.zeka.stack.idea.plugin.example.util.NotificationUtil;

NotificationUtil.showInfo(project, "操作成功");
NotificationUtil.showError(project, "操作失败");
```

## 开发指南

### 添加新的 Action

1. 在 `action` 包下创建新的 Action 类
2. 在 `plugin.xml` 中注册 Action
3. 添加到相应的菜单组

### 添加新的图标

1. 将图标文件放置在 `src/main/resources/dev/.../icons/` 目录
2. 在 `ExampleIcons` 类中添加图标常量
3. 使用 `load()` 方法加载图标

### 添加国际化消息

1. 在 `messages.properties` 中添加英文消息
2. 在 `messages_zh_CN.properties` 中添加中文消息
3. 使用 `ExampleBundle.message()` 获取消息

## 构建和发布

### 构建插件

```bash
./gradlew buildPlugin
```

构建产物位于 `build/distributions/` 目录。

### 发布插件

```bash
./gradlew publishPlugin
```

需要配置以下环境变量：

- `PUBLISH_TOKEN`：JetBrains Marketplace 发布令牌
- `CERTIFICATE_CHAIN`：证书链（可选）
- `PRIVATE_KEY`：私钥（可选）
- `PRIVATE_KEY_PASSWORD`：私钥密码（可选）

### 部署

使用 `deploy.sh` 脚本进行部署：

```bash
./deploy.sh              # 完整部署
./deploy.sh -l           # 仅部署 landing.html
./deploy.sh -z           # 仅上传 ZIP
./deploy.sh -d           # 仅部署文档
```
