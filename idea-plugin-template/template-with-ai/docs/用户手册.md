# IntelliJ IDEA Plugin Template (With AI) 用户手册

## 简介

这是一个集成 IntelliAI Engine 的 IntelliJ IDEA 插件开发模板，提供了快速创建 AI 功能插件的基础框架和最佳实践。

## 功能特性

- 🚀 **快速开始**：提供完整的项目结构和配置，开箱即用
- 🤖 **AI 集成**：集成 IntelliAI Engine，支持多种 AI 服务提供商
- ⚙️ **设置管理**：提供完整的设置页面，支持 AI 提供商选择和提示词模板管理
- 📦 **依赖管理**：预配置常用依赖，包括 Lombok、JUnit、Mockito 等
- 🔧 **开发工具**：集成 Google Java Format、测试框架和插件验证工具
- 🌍 **国际化**：内置多语言支持，提供中文和英文资源文件
- 🎨 **图标管理**：提供图标管理类，统一管理插件图标资源

## 快速开始

### 1. 克隆模板项目

```bash
git clone <repository-url>
cd template-with-ai
```

### 2. 修改插件信息

编辑 `gradle.properties` 文件，修改以下信息：

```properties
pluginGroup=dev.dong4j.zeka.stack.idea.plugin.example
pluginName=Your Plugin Name
pluginVersion=1.0.0
```

### 3. 运行插件

```bash
./gradlew runIde
```

这将启动一个包含插件的 IntelliJ IDEA 沙箱环境，并自动安装 IntelliAI Engine 插件。

### 4. 配置 AI 提供商

1. 打开 Settings → Tools → IntelliAI Engine
2. 添加并配置 AI 服务提供商（如 OpenAI、Anthropic 等）
3. 测试提供商连接
4. 返回 Settings → Tools → Example Plugin
5. 选择要使用的 AI 提供商

## 使用说明

### Action 示例

模板提供了一个简化的 Action 示例，通过右键菜单触发：

1. 在编辑器中右键点击文件
2. 选择 "Example Action"
3. 插件会执行相应的操作并显示通知

### 设置页面

插件提供了完整的设置页面，包含以下功能：

#### AI 提供商选择

- 从已验证的 AI 提供商列表中选择默认提供商
- 如果没有可用的提供商，会显示提示信息和跳转链接
- 点击链接可以快速打开 IntelliAI Engine 设置页面

#### 提示词模板管理

- 系统提示词：设定 AI 角色和行为准则
- 示例模板：用于生成示例内容的提示词模板
- 支持使用占位符（如 `{content}`）
- 可以重置为默认值

### 图标管理

使用 `ExampleIcons` 类管理插件图标：

```java
import dev.dong4j.zeka.stack.idea.plugin.example.icons.ExampleIcons;

// 使用图标
Icon icon = ExampleIcons.EXAMPLE_16;
```

图标文件应放置在 `src/main/resources/icons/` 目录下。

### 国际化

使用 `ExampleBundle` 类获取国际化消息：

```java
import dev.dong4j.zeka.stack.idea.plugin.example.util.ExampleBundle;

String message = ExampleBundle.message("action.example.title");
```

### 通知

使用 `NotificationUtil` 类显示通知：

```java
import dev.dong4j.zeka.stack.idea.plugin.example.util.NotificationUtil;

NotificationUtil.showInfo(project, "操作成功");
NotificationUtil.showError(project, "操作失败");
```

## 开发指南

### 添加新的 Action

1. 在 `action` 包下创建新的 Action 类
2. 在 `plugin.xml` 中注册 Action
3. 添加到相应的菜单组

### 使用 AI 服务

```java
import dev.dong4j.zeka.stack.idea.plugin.common.service.AIService;
import dev.dong4j.zeka.stack.idea.plugin.example.settings.SettingsState;

// 获取配置的 AI 提供商
SettingsState settings = SettingsState.getInstance();
AIProviderConfig providerConfig = settings.providerConfig;

// 使用 AI 服务
AIService aiService = AIService.getInstance();
String response = aiService.generate(providerConfig, systemPrompt, userPrompt);
```

### 添加新的图标

1. 将图标文件放置在 `src/main/resources/icons/` 目录
2. 在 `ExampleIcons` 类中添加图标常量
3. 使用 `load()` 方法加载图标

### 添加国际化消息

1. 在 `messages.properties` 中添加英文消息
2. 在 `messages_zh_CN.properties` 中添加中文消息
3. 使用 `ExampleBundle.message()` 获取消息

## 构建和发布

### 构建插件

```bash
./gradlew buildPlugin
```

构建产物位于 `build/distributions/` 目录。

### 发布插件

```bash
./gradlew publishPlugin
```

需要配置以下环境变量：

- `PUBLISH_TOKEN`：JetBrains Marketplace 发布令牌
- `CERTIFICATE_CHAIN`：证书链（可选）
- `PRIVATE_KEY`：私钥（可选）
- `PRIVATE_KEY_PASSWORD`：私钥密码（可选）

**注意**：发布到市场后，需要在 `build.gradle.kts` 中取消注释 `plugin("dev.dong4j.zeka.stack.idea.plugin.common.ai")` 行，并移除
`copyAiCommonPlugin` 任务。

### 部署

使用 `deploy.sh` 脚本进行部署：

```bash
./deploy.sh              # 完整部署
./deploy.sh -l           # 仅部署 landing.html
./deploy.sh -z           # 仅上传 ZIP
./deploy.sh -d           # 仅部署文档
```

## 系统要求

- IntelliJ IDEA 2022.3 或更高版本
- Java 17+
- Gradle 8.0+
- IntelliAI Engine 插件（本地开发时自动安装）
