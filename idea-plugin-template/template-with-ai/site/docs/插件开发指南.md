# 插件开发指南

本文档用于说明该模板的最小可用能力与推荐实践，便于快速启动子插件开发。

## 能力清单

- 依赖 IntelliAI Engine（AI 服务商、控制台、状态栏聚合）
- 设置页面（含 AI 服务商选择、提示词配置）
- 持久化配置（SettingsState）
- 状态栏扩展点接入
- AI 接口调用示例（非流式）
- 国际化与图标示例
- 插件更新信息入口（PluginUpdateInfoProvider）
- 反馈面板（FeedbackPanel）
- 插件信息常量（PluginContents）

## 推荐扩展路径

1. 在 Action 中替换示例提示词与业务逻辑
2. 在设置页中增加业务参数与开关
3. 为状态栏菜单增加业务快捷入口
4. 使用 Engine 控制台输出调试日志
5. 配置 PluginUpdateInfoProvider 并接入更新信息
6. 使用 FeedbackPanel 收集用户反馈
7. 统一从 PluginContents 读取插件 ID/名称
