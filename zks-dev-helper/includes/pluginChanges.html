2025.3.1

  • 🎉 初始版本发布
  • ✨ 支持文件模板自动配置
  • ✨ 支持 Live Template 快速生成代码片段
  • ✨ 支持代码风格自动配置
  • ✨ 支持使用统计功能
  • 🔧 提供设置面板配置

主要功能

  • 文件模板：自动添加统一的文件头部注释，包含公司信息、作者、版本等
  • Live Template：支持快速生成常用代码片段，包括 todo、fixme、javadoc、日志、测试等
  • 代码风格：自动配置统一的代码格式化规则，支持多种语言
  • 使用统计：统计模板使用情况，帮助了解团队开发习惯

Live Template 列表

  • todo + Tab：标记待处理的地方
  • fix + Tab：标记需要修复的地方
  • cd + Tab：生成 class javadoc
  • li/ld/lw/le + Tab：快速生成日志语句
  • test + Tab：快速生成单元测试方法

系统要求

  • IntelliJ IDEA 2022.3 或更高版本
  • Java 17+
