# 代码样式功能说明

## 概述

代码样式功能是 ZKS Dev Helper 插件的一个核心功能模块，提供统一的代码格式化和模板管理能力，帮助开发团队保持代码风格的一致性。

## 功能特性

### 📝 文件模板

自动添加统一的文件头部注释，包含公司信息、作者、版本、邮箱、日期等，支持 Java Class、Interface、Enum 等文件类型。

**模板示例：**

```java
/**
 * <p>Company: Zeka Stack</p>
 * <p>Description: ${description} </p>
 *
 * @author ${USER}
 * @version 1.0.0
 * @email "mailto:${USER}@gmail.com"
 * @date ${YEAR}.${MONTH}.${DAY} ${HOUR}:${MINUTE}
 * @since 1.0.0
 */
```

### ⚡ Live Template

快速生成常用代码片段，提升开发效率。

| 快捷键          | 功能         | 示例                                            |
|--------------|------------|-----------------------------------------------|
| `todo` + Tab | 标记待处理      | `todo-dong4j : (2024.12.19 15:30) [需要实现的功能]`  |
| `fix` + Tab  | 标记需要修复     | `fixme-dong4j : (2024.12.19 15:30) [修复这个bug]` |
| `cd` + Tab   | 生成 javadoc | 自动生成类注释                                       |
| `li` + Tab   | 生成日志       | `log.info()`                                  |
| `ld` + Tab   | 生成调试日志     | `log.debug()`                                 |
| `lw` + Tab   | 生成警告日志     | `log.warn()`                                  |
| `le` + Tab   | 生成错误日志     | `log.error("{}", exception)`                  |
| `test` + Tab | 生成测试方法     | `@Test void test_methodName(){}`              |

**Live Template 分组：** Zeka Stack

### 🎨 代码风格

自动配置统一的代码格式化规则，支持 Java、SQL、JavaScript 等多种语言。

**默认配置：**

- **缩进**：使用 Tab 字符
- **行宽**：140 字符
- **导入**：按包名分组
- **注释**：保持格式

**代码风格方案名称：** `zeka-stack-code-style`

### 📊 使用统计

统计模板使用情况，帮助了解团队开发习惯。

## 使用方法

### 文件模板

插件安装后会自动配置文件模板，创建新文件时会自动添加统一的头部注释。无需额外配置，开箱即用。

### Live Template

1. 在编辑器中输入快捷键（如 `todo`）
2. 按 `Tab` 键自动展开
3. 根据提示填写变量值

### 代码风格

插件会在项目启动时自动应用统一的代码风格配置。如果项目已存在其他代码风格方案，插件会创建名为 `zeka-stack-code-style` 的方案并设置为默认方案。

## 配置说明

### 设置面板

进入 `File` → `Settings` → `Tools` → `ZKS Dev Helper` 可以配置代码样式功能：

- ✅ **启用文件模板**：自动添加统一的文件头部注释
- ✅ **启用 Live Template**：快速生成常用代码片段
- ✅ **启用代码风格配置**：自动配置统一的代码格式化规则
- ✅ **启用使用统计**：统计模板使用情况

### 自定义配置

可以通过修改插件源码来自定义：

- **文件模板内容**：修改 `UniformFileTemplatesHandler.HEADER` 常量
- **Live Template 规则**：编辑 `src/main/resources/liveTemplates/zeka-stack-live-template.xml`
- **代码风格设置**：编辑 `src/main/resources/zeka-stack-code-style.xml`

## 技术实现

### 核心组件

- **UniformCodeStyleHandler**：代码样式处理器，在项目启动时执行配置
- **UniformCodeStyleSchemeProvider**：代码风格方案提供者，负责导入和应用代码风格
- **UniformFileTemplatesHandler**：文件模板处理器，自动配置文件头部模板
- **UniformLiveTemplateProvider**：Live Template 提供者，注册模板文件
- **UniformLiveTemplateContext**：Live Template 上下文，定义模板适用范围

### 工作流程

1. **项目启动时**：
    - `UniformCodeStyleHandler` 检查配置，如果启用则调用 `UniformCodeStyleSchemeProvider` 应用代码风格
    - `UniformFileTemplatesHandler` 检查并配置文件模板

2. **用户使用 Live Template 时**：
    - IDE 根据上下文匹配模板
    - 展开模板并替换变量

3. **创建新文件时**：
    - IDE 自动应用配置的文件模板
    - 生成包含统一头部注释的文件

## 故障排除

### 常见问题

1. **Live Template 不工作**
    - 检查 `File` → `Settings` → `Editor` → `Live Templates` 中是否有 "Zeka Stack" 分组
    - 确保模板已启用
    - 检查插件设置中是否启用了 Live Template 功能

2. **文件模板没有应用**
    - 检查 `File` → `Settings` → `Editor` → `File and Code Templates` 中的模板设置
    - 确保插件设置中启用了文件模板功能
    - 检查模板是否包含 "Zeka.Stack" 标识

3. **代码风格没有应用**
    - 检查 `File` → `Settings` → `Editor` → `Code Style` 中的设置
    - 确保插件设置中启用了代码风格功能
    - 查看代码风格方案列表中是否有 `zeka-stack-code-style` 方案

4. **代码风格方案已存在但不生效**
    - 手动在 `File` → `Settings` → `Editor` → `Code Style` 中选择 `zeka-stack-code-style` 方案
    - 或删除现有方案后重启项目，让插件重新创建

### 日志查看

如果遇到问题，可以查看 IDEA 的日志文件：

- Windows: `%USERPROFILE%\.IntelliJIdea2022.3\system\log\idea.log`
- macOS: `~/Library/Logs/JetBrains/IntelliJIdea2022.3/idea.log`
- Linux: `~/.cache/JetBrains/IntelliJIdea2022.3/log/idea.log`

在日志中搜索以下关键词：

- `Code style` - 代码风格相关日志
- `File template` - 文件模板相关日志
- `Live template` - Live Template 相关日志

## 开发指南

### 扩展代码样式功能

如果需要扩展代码样式功能，可以：

1. **添加新的 Live Template**：
    - 编辑 `src/main/resources/liveTemplates/zeka-stack-live-template.xml`
    - 添加新的 `<template>` 节点

2. **修改文件模板**：
    - 修改 `UniformFileTemplatesHandler.HEADER` 常量
    - 或修改 `UniformFileTemplatesHandler.runActivity()` 方法中的模板逻辑

3. **调整代码风格规则**：
    - 编辑 `src/main/resources/zeka-stack-code-style.xml`
    - 使用 IntelliJ IDEA 的代码风格设置界面导出配置后替换

### 国际化支持

代码样式功能的国际化资源位于：

- `src/main/resources/messages/messages.properties` - 英文资源
- `src/main/resources/messages/messages_zh_CN.properties` - 中文资源

所有资源键都使用 `codestyle.` 前缀，例如：

- `settings.codestyle.enable.file.templates.label`
- `notification.codestyle.enabled`
