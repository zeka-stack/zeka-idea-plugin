# ZKS Dev Helper 插件使用说明

## 概述

ZKS Dev Helper 是一个 IntelliJ IDEA 插件，专为 Zeka Stack 框架开发提供辅助功能。目前提供统一的代码样式配置功能，帮助开发团队保持代码风格的一致性。后续将持续添加更多开发辅助特性，如
MyBatis 自动提示、Proxyer 组件接口自动识别等。

## 功能特性

### 🎨 代码样式（当前版本）

提供统一的代码格式化和模板管理能力，帮助开发团队保持代码风格的一致性。

**核心功能：**

- 📝 **文件模板**：自动添加统一的文件头部注释
- ⚡ **Live Template**：快速生成常用代码片段（todo、fix、cd、日志、测试等）
- 🎨 **代码风格**：自动配置统一的代码格式化规则
- 📊 **使用统计**：统计模板使用情况

**详细说明：** 请查看 [代码样式功能说明](./site/docs/代码样式功能说明.md)

### 🚀 计划中的功能

- **MyBatis 自动提示**：智能识别 MyBatis Mapper 接口，提供 SQL 语句自动补全和验证
- **Proxyer 组件接口自动识别**：自动识别 Proxyer 组件接口，提供接口调用提示和验证
- **更多开发辅助功能**：持续为 Zeka Stack 框架开发提供更多便利功能

## 安装方式

### 方式一：本地安装

1. 下载插件 JAR 文件：`zks-dev-helper-1.0.0.zip`
2. 打开 IntelliJ IDEA
3. 进入 `File` → `Settings` → `Plugins`
4. 点击齿轮图标 → `Install Plugin from Disk`
5. 选择下载的 ZIP 文件
6. 重启 IDEA

### 方式二：从 Marketplace 安装（如果已发布）

1. 打开 IntelliJ IDEA
2. 进入 `File` → `Settings` → `Plugins`
3. 搜索 "ZKS Dev Helper" 或 "Zeka Stack Dev Helper"
4. 点击 `Install` 安装

## 使用方法

### 代码样式功能

代码样式功能提供统一的代码格式化和模板管理能力。详细使用方法请参考：

📖 **[代码样式功能说明](./site/docs/代码样式功能说明.md)**

**快速开始：**

1. **文件模板**：插件安装后自动配置，创建新文件时自动添加统一头部注释
2. **Live Template**：在编辑器中输入快捷键（如 `todo`、`fix`、`cd` 等），按 `Tab` 键展开
3. **代码风格**：插件会在项目启动时自动应用统一的代码格式化规则

## 配置说明

### 设置面板

进入 `File` → `Settings` → `Tools` → `ZKS Dev Helper` 可以配置各功能模块的启用状态。

**代码样式模块配置：**

- ✅ 启用文件模板
- ✅ 启用 Live Template
- ✅ 启用代码风格配置
- ✅ 启用使用统计

详细配置说明请参考 [代码样式功能说明](./site/docs/代码样式功能说明.md#配置说明)

## 故障排除

### 常见问题

1. **插件安装后没有生效**
    - 确保重启了 IntelliJ IDEA
    - 检查插件是否在 `File` → `Settings` → `Plugins` 中显示为已启用

2. **Live Template 不工作**
    - 检查 `File` → `Settings` → `Editor` → `Live Templates` 中是否有 "Zeka Stack" 分组
    - 确保模板已启用
    - 详细故障排除请参考 [代码样式功能说明](./site/docs/代码样式功能说明.md#故障排除)

3. **文件模板没有应用**
    - 检查 `File` → `Settings` → `Editor` → `File and Code Templates` 中的模板设置
    - 确保插件设置中启用了文件模板功能

4. **代码风格没有应用**
    - 检查 `File` → `Settings` → `Editor` → `Code Style` 中的设置
    - 确保插件设置中启用了代码风格功能

### 日志查看

如果遇到问题，可以查看 IDEA 的日志文件：

- Windows: `%USERPROFILE%\.IntelliJIdea2022.3\system\log\idea.log`
- macOS: `~/Library/Logs/JetBrains/IntelliJIdea2022.3/idea.log`
- Linux: `~/.cache/JetBrains/IntelliJIdea2022.3/log/idea.log`
