# 代码样式在线更新功能实现方案

## 1. 功能概述

实现代码样式配置文件的在线更新功能，允许用户通过设置页面配置下载地址，并在项目启动时自动检查并下载最新版本的代码样式配置文件，无需更新插件即可更新代码样式。

## 2. 需求分析

### 2.1 核心需求

1. **设置页面功能**
    - 添加代码样式在线更新配置面板
    - 提供"自动更新"复选框
    - 提供"下载地址"输入框
    - 勾选"自动更新"后，下载地址输入框可用
    - 提供手动下载按钮（可选）

2. **下载功能**
    - 后台线程下载代码样式文件
    - 显示下载进度条
    - 保存文件到 `~/.zeka-stack/plugin/helper` 目录（兼容 Windows/macOS/Linux）
    - 文件命名格式：`zeka-stack-codestyle-{version}.xml`（如：`zeka-stack-codestyle-1.0.0.xml`）

3. **版本管理**
    - 从文件名中提取版本号
    - 比较本地版本与远程版本
    - 如果版本不一致，自动下载并更新

4. **动态更新**
    - 下载完成后，动态更新 IDEA 的代码样式配置
    - 写入到 IDEA 的代码配置中的名称始终是 `zeka-stack-codestyle`（不包含版本号）

5. **启动检查**
    - 项目启动时检查"自动更新"配置是否启用
    - 如果启用，在后台检查并下载最新版本

## 3. 技术方案

### 3.2 目录结构

文件命名规则：

- 下载的文件：`zeka-stack-codestyle-{version}.xml`
- 例如：`zeka-stack-codestyle-1.0.0.xml`

### 3.3 版本检测机制

1. **从文件名提取版本号**
    - 文件名格式：`zeka-stack-codestyle-{version}.xml`
    - 使用正则表达式提取版本号：`zeka-stack-codestyle-(\d+\.\d+\.\d+)\.xml`

2. **版本比较**
    - 比较本地文件版本与远程文件版本
    - 如果远程版本更新，则下载新文件

3. **获取远程版本**
    - 方案1：从下载地址的响应头中获取文件名（如果服务器支持）
    - 方案2：从下载地址 URL 中解析版本号（如果 URL 包含版本信息）
    - 方案3：下载文件后从文件名提取版本号（推荐）

**重要**：在设置面板中，需要监听复选框和输入框的变化事件，实时触发下载：

```java
/**
 * 代码样式在线更新配置面板
 */
private JPanel createCodeStyleUpdatePanel() {
    JBCheckBox autoUpdateCheckBox = new JBCheckBox("自动更新代码样式");
    JBTextField downloadUrlField = new JBTextField();
    JButton downloadButton = new JButton("手动下载");
    JProgressBar progressBar = new JProgressBar();
    JBLabel statusLabel = new JBLabel("");

    // 自动更新复选框控制下载地址输入框的可用性
    autoUpdateCheckBox.addActionListener(e -> {
        boolean enabled = autoUpdateCheckBox.isSelected();
        downloadUrlField.setEnabled(enabled);
        downloadButton.setEnabled(enabled);

        // 如果勾选了自动更新且下载地址已配置，立即触发下载
        if (enabled && !downloadUrlField.getText().trim().isEmpty()) {
            triggerCodeStyleDownload(downloadUrlField.getText().trim(), progressBar, statusLabel);
        }
    });

    // 下载地址输入框内容变化时，如果已勾选自动更新，立即触发下载
    downloadUrlField.getDocument().addDocumentListener(new DocumentListener() {
        @Override
        public void insertUpdate(DocumentEvent e) {
            checkAndTriggerDownload();
        }

        @Override
        public void removeUpdate(DocumentEvent e) {
            checkAndTriggerDownload();
        }

        @Override
        public void changedUpdate(DocumentEvent e) {
            checkAndTriggerDownload();
        }

        private void checkAndTriggerDownload() {
            if (autoUpdateCheckBox.isSelected() &&
                !downloadUrlField.getText().trim().isEmpty()) {
                triggerCodeStyleDownload(downloadUrlField.getText().trim(), progressBar, statusLabel);
            }
        }
    });

    // 手动下载按钮
    downloadButton.addActionListener(e -> {
        String url = downloadUrlField.getText().trim();
        if (url.isEmpty()) {
            statusLabel.setText("请先输入下载地址");
            return;
        }
        triggerCodeStyleDownload(url, progressBar, statusLabel);
    });

    return FormBuilder.createFormBuilder()
        .addComponent(autoUpdateCheckBox)
        .addLabeledComponent(new JBLabel("下载地址:"), downloadUrlField)
        .addComponent(downloadButton)
        .addComponent(progressBar)
        .addComponent(statusLabel)
        .getPanel();
}

/**
 * 触发代码样式下载
 */
private void triggerCodeStyleDownload(String downloadUrl, JProgressBar progressBar, JBLabel statusLabel) {
    // 重置状态
    progressBar.setVisible(true);
    progressBar.setIndeterminate(true);
    statusLabel.setText("正在检查更新...");

    // 后台下载
    ApplicationManager.getApplication().executeOnPooledThread(() -> {
        try {
            // 执行下载逻辑
            // ...

            // 更新 UI（必须在 EDT 中）
            ApplicationManager.getApplication().invokeLater(() -> {
                progressBar.setVisible(false);
                statusLabel.setText("下载成功");
            });
        } catch (Exception e) {
            ApplicationManager.getApplication().invokeLater(() -> {
                progressBar.setVisible(false);
                statusLabel.setText("下载失败: " + e.getMessage());
            });
        }
    });
}
```

### 4.4 代码样式提供者修改

**文件**: `UniformCodeStyleSchemeProvider.java`

修改 `provideUniformCodeStyleScheme()` 方法，优先从本地下载的文件加载：

```java
public static void provideUniformCodeStyleScheme(Project project) {
    try {
        // 1. 优先检查本地下载的文件
        Path localFile = CodeStyleDownloadManager.getLocalCodeStyleFile();
        if (localFile != null && Files.exists(localFile)) {
            VirtualFile vFile = VfsUtil.findFileByPath(localFile.toString());
            if (vFile != null) {
                importScheme(project, vFile);
                log.info("Code style loaded from local file: {}", localFile);
                return;
            }
        }

        // 2. 回退到插件内置的资源文件
        URL resource = UniformCodeStyleSchemeProvider.class.getClassLoader()
            .getResource(CODE_STYLE_FILE);
        if (resource != null) {
            VirtualFile vFile = VfsUtil.findFileByURL(resource);
            if (vFile != null) {
                importScheme(project, vFile);
                log.info("Code style loaded from plugin resource");
                return;
            }
        }

        log.error("Code style file not found");
    } catch (Exception e) {
        log.error("Failed to provide uniform code style scheme", e);
    }
}
```

### 4.5 启动处理器修改

**文件**: `UniformCodeStyleHandler.java`

修改 `execute()` 方法，添加自动更新检查：

```java
@Override
public @Nullable Object execute(@NotNull Project project, @NotNull Continuation<? super Unit> continuation) {
    try {
        if (hasRun.compareAndSet(false, true) && !ApplicationManager.getApplication().isUnitTestMode()) {
            UniformFormatSettingsState settings = UniformFormatSettingsState.getInstance();
            if (!settings.isEnableCodeStyle()) {
                log.info("Code style disabled, skipping configuration");
                return Unit.INSTANCE;
            }

            // 检查自动更新配置
            CodeStyleUpdateSettings updateSettings = settings.getCodeStyleUpdateSettings();
            if (updateSettings != null && updateSettings.isAutoUpdate()) {
                // 后台检查并更新
                ApplicationManager.getApplication().executeOnPooledThread(() -> {
                    try {
                        CodeStyleDownloadManager.checkAndUpdate(project, updateSettings);
                    } catch (Exception e) {
                        log.error("Failed to check and update code style", e);
                    }
                });
            }

            // 提供统一代码风格方案（会优先使用本地下载的文件）
            UniformCodeStyleSchemeProvider.provideUniformCodeStyleScheme(project);
        }
    } catch (Exception e) {
        log.error("Failed to configure uniform code style for project: {}", project.getName(), e);
    }
    return Unit.INSTANCE;
}
```
