# 控制台日志集成说明

本文档说明 IntelliAI Engine 的统一控制台日志能力，以及子插件如何接入与使用。

## 目标

- 所有子插件输出统一到 Engine 控制台（IntelliAI Engine Console）
- 输出风格一致，支持时间戳、级别颜色、超链接与流式输出
- 受全局“详细日志”开关控制，避免干扰正常使用

## 组件概览

- 控制台服务：`dev.dong4j.zeka.stack.idea.plugin.common.console.AIConsoleView`
- 统一日志接口：`dev.dong4j.zeka.stack.idea.plugin.common.ai.AIConsoleLogger`
- 推荐工具类：`dev.dong4j.zeka.stack.idea.plugin.common.util.AIConsoleLoggerUtil`

控制台工具窗口 ID：`IntelliAI Engine Console`

## 接入方式（推荐）

子插件应通过 `AIConsoleLoggerUtil` 输出日志，而不是直接操作 ConsoleView：

```java
AIConsoleLoggerUtil.print(project, "开始生成...");
AIConsoleLoggerUtil.printWithTimestamp(project, "=== 请求开始 ===");
AIConsoleLoggerUtil.printSuccess(project, "生成成功");
AIConsoleLoggerUtil.printWarning(project, "输入为空，跳过");
AIConsoleLoggerUtil.printError(project, "生成失败: " + e.getMessage());
```

### 超链接输出

```java
AIConsoleLoggerUtil.printHyperlink(project, "点击跳转到代码", file, line);
AIConsoleLoggerUtil.printHyperlinkWithTimestamp(project, "定位错误", file, line);
```

### 流式输出

```java
AIConsoleLoggerUtil.printStreamPlain(project, chunk);
AIConsoleLoggerUtil.completeStreamPlain(project);
```

说明：

- `printStream` / `completeStream`：会输出欢迎信息并自动换行
- `printStreamPlain` / `completeStreamPlain`：不输出欢迎信息，按原样追加

## 关键行为说明

### 1. 自动显示 ToolWindow

任何日志输出都会自动拉起 “IntelliAI Engine Console” 工具窗口，
方便用户第一时间查看。

### 2. 受全局“详细日志”控制

`AIConsoleLoggerUtil` 内部会读取 `AIProviderSettings.verboseLogging`：

- 未开启时：所有日志静默忽略
- 开启后：所有日志输出到控制台

建议子插件在需要调试/排障的信息上输出日志，
日常使用不强制开启。

### 3. 线程安全

`AIConsoleView` 内部在 EDT 中执行 UI 输出，
外部调用无需关心线程切换。

## 常见集成方式

### 1. 业务流程日志

```java
AIConsoleLoggerUtil.printWithTimestamp(project, "=== 开始生成内容 ===");
AIConsoleLoggerUtil.print(project, "模型: qwen-max");
AIConsoleLoggerUtil.printSuccess(project, "生成完成");
```

### 2. 与 AI 请求结合

```java
try {
    AIConsoleLoggerUtil.printWithTimestamp(project, "=== 开始请求 ===");
    // 请求逻辑
    AIConsoleLoggerUtil.printSuccess(project, "请求成功");
} catch (Exception e) {
    AIConsoleLoggerUtil.printError(project, "请求失败: " + e.getMessage());
}
```

### 3. 流式输出日志

```java
AIConsoleLoggerUtil.printStreamPlain(project, chunk);
if (done) {
    AIConsoleLoggerUtil.completeStreamPlain(project);
}
```

## 集成示例（Engine 内置 Provider）

Engine 在 `AICompatibleProvider` 中统一输出调试日志与流式输出：

```java
AIConsoleLoggerUtil.printWithTimestamp(project, "=== 开始生成内容 ===");
AIConsoleLoggerUtil.print(project, String.format("模型信息: 供应商=%s | 模型=%s", provider, model));

// 流式输出（不拼接前后缀）
AIConsoleLoggerUtil.printStreamPlain(project, chunk);

// 完成流式输出
AIConsoleLoggerUtil.completeStreamPlain(project);
```

该方式也适用于子插件：直接复用 `AIConsoleLoggerUtil`，无需访问 `ConsoleView` 或 ToolWindow。

## 注意事项

1. 不要直接操作 `ConsoleView` 或 `ToolWindow`
    - 统一通过 `AIConsoleLoggerUtil` 输出
2. 日志内容应避免泄露敏感信息（API Key / Token）
3. 超链接输出的行号从 0 开始
4. 流式输出不应拼接多余前后缀，直接追加模型输出即可

## 最小集成清单

- [ ] 通过 `AIConsoleLoggerUtil` 输出日志
- [ ] 日志输出仅用于调试/排障
- [ ] 流式输出使用 `printStreamPlain` + `completeStreamPlain`
- [ ] 避免敏感信息输出
