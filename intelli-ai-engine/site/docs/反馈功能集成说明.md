# 反馈功能集成说明

## 功能说明

`FeedbackPanel` 是 IntelliAI Engine 提供的统一反馈入口组件，用于在插件设置页中嵌入反馈区块，
帮助用户快速提交问题、建议或使用反馈。

核心能力：

- 统一的反馈入口 UI
- 支持插件维度的标识与签名
- 可固定放置在设置页底部

## 集成说明

### 1. 引入 FeedbackPanel

在设置面板中创建 `FeedbackPanel`：

```java
import dev.dong4j.zeka.stack.idea.plugin.common.ui.FeedbackPanel;
import dev.dong4j.zeka.stack.idea.plugin.example.PluginContents;

FeedbackPanel feedbackPanel = new FeedbackPanel(
    null, // 应用级设置时使用 null
    PluginContents.PLUGIN_ID,
    PluginContents.PLUGIN_NAME,
    "zeka-stack-example-plugin" // 插件签名 key
);
```

### 2. 挂载到设置面板

一般放在设置面板底部，并使用垂直填充保持固定位置：

```java
mainPanel = FormBuilder.createFormBuilder()
    .addComponent(aiProviderSelectionPanel.getPanel())
    .addSeparator(10)
    .addComponentFillVertically(new JPanel(), 0)
    .addComponent(feedbackPanel.getContent())
    .getPanel();
```

## 集成示例

以 IntelliAI Javadoc 插件为例：

- 位置：`intelli-ai-javadoc/src/main/java/dev/dong4j/zeka/stack/idea/plugin/settings/ui/JavadocSettingsPanel.java`
- 关键片段：

```java
feedbackPanel = new FeedbackPanel(
    null,
    PluginContents.PLUGIN_ID,
    PluginContents.PLUGIN_NAME,
    "zeka-stack-javadoc-plugin"
);

mainPanel = FormBuilder.createFormBuilder()
    .addComponentFillVertically(new JPanel(), 0)
    .addComponent(feedbackPanel.getContent())
    .getPanel();
```
