# IntelliAI Engine 用户手册

## 概述

IntelliAI Engine 是一个 IntelliJ IDEA 插件，为开发者提供统一的 AI 服务接入能力。它支持多个主流 AI 服务提供商，包括 OpenAI、通义千问、硅基流动、Ollama、LM
Studio 和 ModelScope 等，允许第三方插件轻松集成 AI 功能。

## 核心特性

- **多提供商支持**: 支持 6 种主流 AI 服务提供商
- **统一接口**: 简化的 API 设计，降低集成复杂度
- **配置管理**: 可视化配置界面，支持多种参数调优
- **扩展性**: 提供扩展点，支持自定义日志和状态栏组件
- **性能优化**: 支持重试机制、超时控制和详细日志记录

## 快速开始

### 1. 安装插件

IntelliAI Engine 通常作为依赖插件自动安装。如果您需要手动安装：

1. 下载最新的插件包文件
2. 在 IntelliJ IDEA 中：`File` → `Settings` → `Plugins`
3. 点击 `⚙️` → `Install Plugin from Disk...`
4. 选择下载的插件包文件并安装

### 2. 配置 AI 提供商

#### 基本配置步骤

1. 打开设置：`File` → `Settings` → `Tools` → `IntelliAI Engine`
2. 点击 `+` 添加新的 AI 提供商配置
3. 选择提供商类型并填写必要信息
4. 测试连接并保存配置

#### 支持的提供商

| 提供商            | 是否需要 API Key | 基础 URL 可编辑 | 支持模型示例                                   |
|----------------|--------------|------------|------------------------------------------|
| **OpenAI API** | ✅ 是          | ✅ 是        | gpt-3.5-turbo, gpt-4o-mini               |
| **通义千问**       | ✅ 是          | ❌ 否        | qwen3-32b, qwen3-14b, qwen3-8b           |
| **硅基流动**       | ✅ 是          | ❌ 否        | Qwen/Qwen3-8B, Qwen/Qwen2.5-14B-Instruct |
| **Ollama**     | ❌ 否          | ✅ 是        | gpt-oss:120b-cloud, deepseek-r1:14b      |
| **LM Studio**  | ❌ 否          | ✅ 是        | qwen3-8b                                 |
| **ModelScope** | ✅ 是          | ✅ 是        | Qwen/Qwen3-Coder-480B, ZhipuAI/GLM-4.6   |

#### 配置示例

**OpenAI API 配置：**

```yaml
提供商: OpenAI API
模型: gpt-4o-mini
API Key: sk-xxxxxxxxxxxxxxxxxxxxxxxx
基础 URL: https://api.openai.com/v1
```

**Ollama 本地配置：**

```yaml
提供商: Ollama
模型: qwen3-8b
基础 URL: http://localhost:11434/v1
```

### 3. 测试连接前配置高级参数

在模型选择行右侧、`测试连接` 按钮左侧，点击齿轮图标可打开高级设置对话框（与可用服务商编辑共用同一窗口），可配置：

- 超时、重试、Max Token、Temperature、Top-P / Top-K、Presence Penalty
- 是否启用 Think 模式

主设置页不再展示独立的「高级配置」分组；参数请在此处或可用服务商条目中修改。

### 4. 测试连接

配置完成后，点击 `测试连接` 按钮验证配置是否正确：

- ✅ **成功**: 显示"连接成功"及相关信息
- ❌ **失败**: 显示具体错误信息，请检查配置

测试成功后，当前配置会以「当前高级设置」为模板加入「可用服务商」列表（用于性能模式等多服务商负载）。

### 5. 编辑可用服务商参数

对已加入列表的条目，无需删除后重新测试即可改参：

1. 勾选「显示可用服务商」
2. 选中一行，点击工具栏齿轮「设置」，或直接双击该行
3. 在对话框中修改超时、Max Token、Temperature 等高级参数，以及是否启用 Think 模式
4. 点击确定后 Apply 设置页保存

说明：

- Think 模式开启时，OpenAI 兼容请求可能发送 `enable_thinking: true`（该字段为厂商扩展，非 OpenAI 官方规范）
- 未开启时默认不带该字段（避免部分模型拒绝 `false`）
- **测试连接成功后会并发探测**「不传 / true / false」三种传法，结论写入该可用服务商，并显示在成功结果中
- 某探针失败时摘要仅显示 HTTP 状态码（如 `HTTP 400`），完整错误写入日志
- 探测结论为「必须启用」或「不支持」时，设置对话框会锁定 Think 勾选

### 6. 开始使用

配置完成后，您的插件就可以通过 IntelliAI Engine 使用 AI 功能了。具体使用方法取决于您安装的功能插件。

## 第三方插件集成指南

### 核心概念

IntelliAI Engine 为第三方插件提供统一的 AI 服务接入能力，主要组件包括：

- **AIService**: 统一的服务入口
- **AIProviderConfig**: 提供商配置
- **AIChatRequest**: 聊天请求对象
- **AIResponseListener**: 响应监听器

### 基本集成步骤

#### 1. 添加依赖

在您的 `build.gradle.kts` 文件中添加 IntelliAI Engine 作为依赖：

```kotlin
// build.gradle.kts
dependencies {
    // 依赖 IntelliAI Engine 插件
    implementation(project(":intelli-ai-engine"))
}
```

#### 2. 获取 AIService 实例

```java
import dev.dong4j.zeka.stack.idea.plugin.common.ai.service.AIService;

// 获取 AIService 实例
AIService aiService = AIService.getInstance();
```

#### 3. 创建 AI 请求

```java
import dev.dong4j.zeka.stack.idea.plugin.common.ai.AIChatRequest;
import dev.dong4j.zeka.stack.idea.plugin.common.config.AIProviderConfig;

// 创建配置（使用默认设置）
AIProviderConfig config = new AIProviderConfig();

// 创建聊天请求
AIChatRequest request = new AIChatRequest(
    "你是一个专业的代码助手，请提供简洁准确的回答。",
    "请为以下Java方法生成JavaDoc注释：\npublic void calculateSum(int a, int b) { return a + b; }"
);
```

#### 4. 调用 AI 服务

```java
import com.intellij.openapi.project.Project;
import dev.dong4j.zeka.stack.idea.plugin.common.ai.AIServiceException;

try {
    Project project = getCurrentProject(); // 获取当前项目
    String response = aiService.generateContent(project, request, config, null);

    // 使用 AI 返回的结果
    System.out.println("AI Response: " + response);
} catch (AIServiceException e) {
    // 处理异常
    System.err.println("AI Service Error: " + e.getMessage());
}
```

### 完整集成示例

#### 示例：Javadoc 生成器

```java
import com.intellij.openapi.actionSystem.AnAction;
import com.intellij.openapi.actionSystem.AnActionEvent;
import com.intellij.openapi.actionSystem.CommonDataKeys;
import com.intellij.openapi.project.Project;
import dev.dong4j.zeka.stack.idea.plugin.common.ai.AIChatRequest;
import dev.dong4j.zeka.stack.idea.plugin.common.ai.AIService;
import dev.dong4j.zeka.stack.idea.plugin.common.ai.AIServiceException;
import dev.dong4j.zeka.stack.idea.plugin.common.ai.AIResponseListener;
import dev.dong4j.zeka.stack.idea.plugin.common.config.AIProviderConfig;
import org.jetbrains.annotations.NotNull;

public class GenerateJavaDocAction extends AnAction {

    @Override
    public void actionPerformed(@NotNull AnActionEvent e) {
        Project project = e.getRequiredData(CommonDataKeys.PROJECT);

        // 获取 AIService
        AIService aiService = AIService.getInstance();

        // 创建配置（使用默认提供商）
        AIProviderConfig config = new AIProviderConfig();

        // 创建请求
        String methodCode = "public int calculateSum(int a, int b) {\n    return a + b;\n}";
        String prompt = "为以下Java方法生成标准的JavaDoc注释：\n" + methodCode;

        AIChatRequest request = new AIChatRequest(
            "你是一个专业的Java开发者，擅长编写规范的JavaDoc注释。",
            prompt
        );

        // 添加响应监听器
        AIResponseListener listener = new AIResponseListener() {
            @Override
            public void onRequest(String provider, String model, String requestBody, boolean validation) {
                System.out.println("Request to " + provider + " using model " + model);
            }

            @Override
            public void onResponse(String provider, String model, String responseBody, boolean validation) {
                System.out.println("Response received from " + provider);
            }

            @Override
            public void onUsage(String provider, String model, int promptTokens, int completionTokens, int totalTokens) {
                System.out.printf("Token usage - Prompt: %d, Completion: %d, Total: %d%n",
                    promptTokens, completionTokens, totalTokens);
            }
        };

        try {
            // 调用 AI 服务
            String javadoc = aiService.generateContent(project, request, config, listener);

            // 在这里处理生成的 Javadoc
            showGeneratedJavaDoc(project, javadoc);

        } catch (AIServiceException ex) {
            showErrorDialog(project, "生成 Javadoc 失败", ex.getMessage());
        }
    }

    private void showGeneratedJavaDoc(Project project, String javadoc) {
        // 显示生成的 Javadoc
        com.intellij.openapi.ui.Messages.showInfoMessage(
            project,
            javadoc,
            "生成的 Javadoc"
        );
    }

    private void showErrorDialog(Project project, String title, String message) {
        com.intellij.openapi.ui.Messages.showErrorDialog(project, message, title);
    }
}
```

```java
import dev.dong4j.zeka.stack.idea.plugin.common.ai.AIConsoleLogger;
import dev.dong4j.zeka.stack.idea.plugin.common.ai.AIConsoleLoggerProvider;
import com.intellij.openapi.project.Project;
import org.jetbrains.annotations.NotNull;
import org.jetbrains.annotations.Nullable;

public class MyConsoleLoggerProvider implements AIConsoleLoggerProvider {

    @Nullable
    @Override
    public AIConsoleLogger getConsoleLogger(@NotNull Project project) {
        return new MyConsoleLogger();
    }

    private static class MyConsoleLogger implements AIConsoleLogger {
        @Override
        public void print(String message) {
            System.out.println("[AI LOG] " + message);
        }

        @Override
        public void printWithTimestamp(String message) {
            String timestamp = java.time.LocalTime.now().toString();
            System.out.println("[AI LOG " + timestamp + "] " + message);
        }

        @Override
        public void printSuccess(String message) {
            System.out.println("[AI SUCCESS] " + message);
        }

        @Override
        public void printWarning(String message) {
            System.out.println("[AI WARNING] " + message);
        }

        @Override
        public void printError(String message) {
            System.err.println("[AI ERROR] " + message);
        }
    }
}
```

### 错误处理

#### 异常类型

```java
try {
    String response = aiService.generateContent(project, request, config, listener);
} catch (AIServiceException e) {
    switch (e.getErrorCode()) {
        case INVALID_API_KEY:
            showError("API Key 无效");
            break;
        case RATE_LIMIT:
            showError("请求频率超限，请稍后重试");
            break;
        case NETWORK_ERROR:
            showError("网络连接错误");
            break;
        case SERVICE_UNAVAILABLE:
            showError("AI 服务暂时不可用");
            break;
        default:
            showError("AI 服务调用失败：" + e.getMessage());
    }
}
```

### 性能优化建议

#### 1. 缓存和批处理

```java
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

public class AICacheManager {
    private final Map<String, String> responseCache = new ConcurrentHashMap<>();

    public String getCachedResponse(String cacheKey) {
        return responseCache.get(cacheKey);
    }

    public void cacheResponse(String cacheKey, String response) {
        responseCache.put(cacheKey, response);
    }
}
```

#### 2. 异步处理

```java
import com.intellij.openapi.application.ApplicationManager;
import com.intellij.openapi.progress.ProgressManager;
import com.intellij.openapi.progress.Task;
import com.intellij.openapi.project.Project;

public class AIAsyncTask {

    public static void generateAsync(Project project, AIChatRequest request,
                                    AIProviderConfig config, AIResponseListener listener) {
        ProgressManager.getInstance().run(new Task.Backgroundable(project, "AI 生成中") {
            @Override
            public void run(@NotNull com.intellij.openapi.progress.ProgressIndicator indicator) {
                try {
                    indicator.setIndeterminate(false);
                    indicator.setText("正在调用 AI 服务...");

                    AIService aiService = AIService.getInstance();
                    String response = aiService.generateContent(project, request, config, listener);

                    ApplicationManager.getApplication().invokeLater(() -> {
                        showResult(project, response);
                    });

                } catch (AIServiceException e) {
                    ApplicationManager.getApplication().invokeLater(() -> {
                        showError(project, e.getMessage());
                    });
                }
            }
        });
    }
}
```

## 常见问题

### Q: 如何获取 API Key？

**A:** 根据不同的提供商：

- **OpenAI**: 访问 https://platform.openai.com/api-keys
- **通义千问**: 访问 https://dashscope.aliyun.com/
- **硅基流动**: 访问 https://siliconflow.cn/
- **ModelScope**: 访问 https://modelscope.cn/

### Q: 本地部署的 AI 模型如何配置？

**A:** 使用 Ollama 或 LM Studio 配置：

1. 启动本地服务（Ollama 默认端口 11434，LM Studio 默认端口 1234）
2. 在 IntelliAI Engine 中选择对应提供商
3. 基础 URL 使用默认值或根据实际情况调整

### Q: 如何调试 AI 服务调用？

**A:** 启用详细日志：

1. 在 AI 配置中启用 `详细日志` 选项
2. 或者实现自定义 `AIConsoleLoggerProvider`
3. 查看 IntelliJ IDEA 的日志输出（`Help` → `Show Log in Explorer`）

### Q: 支持哪些模型参数？

**A:** 支持以下参数：

- `temperature`: 控制随机性（0.0-2.0）
- `max_tokens`: 最大输出令牌数
- `top_p`: 核采样（0.0-1.0）
- `top_k`: 顶部 K 采样
- `presence_penalty`: 存在惩罚（-2.0 到 2.0）

### Q: 如何处理网络超时？

**A:** 调整运行时设置：

```java
AIRuntimeSettings runtimeSettings = new AIRuntimeSettings();
runtimeSettings.setTimeout(120); // 120秒超时
runtimeSettings.setMaxRetries(5);  // 最多重试5次
runtimeSettings.setWaitDuration(1000); // 重试等待1秒
config.setRuntimeSettings(runtimeSettings);
```
