# 插件更新功能集成说明

## 功能说明

IntelliAI Engine 提供统一的插件更新信息入口，通过 `PluginUpdateInfoProvider` 将插件 ID 注册到 Engine 的更新信息体系中，
便于在统一入口展示更新提示、版本信息与更新链接。

核心能力：

- 统一的更新信息提供入口
- 插件级别的更新信息聚合与展示
- 与 Engine 侧更新机制保持一致

## 集成说明

### 1. 新增更新信息提供类

在插件中新增实现类，返回当前插件的 `PluginId`：

```java
package dev.dong4j.zeka.stack.idea.plugin.example.update;

import com.intellij.openapi.extensions.PluginId;
import org.jetbrains.annotations.NotNull;

import dev.dong4j.zeka.stack.idea.plugin.common.update.PluginUpdateInfoProvider;
import dev.dong4j.zeka.stack.idea.plugin.example.PluginContents;

public class ExamplePluginUpdateInfoProvider implements PluginUpdateInfoProvider {
    private static final PluginId PLUGIN_ID = PluginId.getId(PluginContents.PLUGIN_ID);

    @Override
    public @NotNull PluginId getPluginId() {
        return PLUGIN_ID;
    }
}
```

### 2. 注册扩展点

在 `plugin.xml` 中注册扩展点，注意使用 Engine 的命名空间：

```xml
<extensions defaultExtensionNs="dev.dong4j.zeka.stack.idea.plugin.common.ai">
    <pluginUpdateInfoProvider implementation="dev.dong4j.zeka.stack.idea.plugin.example.update.ExamplePluginUpdateInfoProvider"/>
</extensions>
```

## 集成示例

以 IntelliAI Javadoc 插件为例：

- 实现类：`dev.dong4j.zeka.stack.idea.plugin.update.JavadocPluginUpdateInfoProvider`
- 插件注册：`intelli-ai-javadoc/src/main/resources/META-INF/plugin.xml`

示例片段：

```xml
<extensions defaultExtensionNs="dev.dong4j.zeka.stack.idea.plugin.common.ai">
    <pluginUpdateInfoProvider implementation="dev.dong4j.zeka.stack.idea.plugin.update.JavadocPluginUpdateInfoProvider"/>
</extensions>
```

```java
public class JavadocPluginUpdateInfoProvider implements PluginUpdateInfoProvider {
    private static final PluginId PLUGIN_ID = PluginId.getId(PluginContents.PLUGIN_ID);

    @Override
    public @NotNull PluginId getPluginId() {
        return PLUGIN_ID;
    }
}
```
