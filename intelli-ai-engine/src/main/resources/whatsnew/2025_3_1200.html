2025.3.1200

🎊 This is the last version before the 2026 Chinese New Year. Wishing everyone a happy Spring Festival and all the best! 🧧🎉

This update focuses on functionality and experience improvements, including:

  • ✨ Added: Added statistics feature, provides Web page to view statistics (similar to wakatime, disabled by default), webui: https://zekastack.dong4j.site
  • ✨ Added: Added model caching mechanism, supports persisting loaded models to local files, avoiding duplicate requests, improving configuration experience
  • ✨ Added: Implemented model filtering function, automatically excludes model names containing "vl" or "tts", improving available model list quality
  • ✨ Added: Added support for AI service providers including Claude, Nvidia, Codex, HuggingFace, completed Provider directory splitting, type enumeration extension, and factory integration
  • ✨ Added: Added issue feedback support, can create GitHub Issues directly when exceptions occur, also provided extension points for third-party plugins to implement problem reporting quickly
  • ✨ Added: Added registry dynamic display feature for testing actions (limited to new feature testing, does not affect user usage)
  • 🔧 Optimized: Refactored model loading flow, optimized initial loading and cache update logic, enhanced exception handling and path security
  • 🔧 Optimized: Model dropdown now supports fuzzy search for quick access to needed models
  • 🔧 Optimized: Optimized console log output logic, structured display of more debugging information
  • 🔧 Optimized: Hidden all internal plugin log output, can be enabled via "Debug Log Settings" when needed
  • 🐛 Fixed: Fixed the issue of timer being created repeatedly
  • 🐛 Fixed: Fixed the issue where donation panel QR code was not displaying, now I understand why there were no donations, turns out it was my issue
