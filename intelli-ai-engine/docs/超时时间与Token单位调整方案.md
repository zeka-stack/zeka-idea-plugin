## 功能概述

为提升配置的直观性，需要将 AI 服务设置中两个参数的单位调整为更符合用户认知的格式：

- **超时时间**：从现有的毫秒改为秒，展示与输入均使用秒；
- **Token 最大长度**：从当前的绝对数改为 K（千 token）为单位。

本次改动需确保 UI、配置存储、校验逻辑以及与后端交互的数值转换一致。

## 实现方案

1. **配置字段与序列化**
    - 检查 `SettingsState` 及相关持久化类，将超时与 token 字段的含义更新为“秒”和“K”；
    - 保持序列化字段名不变，仅改变存储值的含义，以避免数据迁移；
    - 对 List/Map 字段保持初始化，确保不会出现 `null`。

2. **UI 层（设置面板）**
    - 定位到超时时间与 token 长度的输入组件，将标签国际化文案更新为“秒 / K”；
    - 如为数值输入框，调整 placeholder 或 `JBLabel` 说明；
    - 若存在帮助提示或校验消息，同步更新文案。

3. **数据转换逻辑**
    - 在 UI 与服务调用之间新增/更新转换方法：
        - 用户输入：秒 → 存储（秒），对之后调用接口需要毫秒的场景，在使用前乘以 1000；
        - 用户输入：K → 存储（K），调用模型接口时换算成实际 token 数（`value * 1000`）。
    - 若已有校验逻辑（例如 >0，最大值限制），重新审视阈值是否需要同步调整。

4. **AI 服务适配**
    - 搜索所有使用超时时间/最大 token 的服务类和 provider，确保传参时使用正确单位；
    - 对第三方 SDK/HTTP 请求，确认其需要的单位，并在调用前进行换算。

5. **测试用例**
    - 单元测试：覆盖单位转换方法；
    - UI 测试/集成测试：验证设置保存与加载后的展示值；
    - 若有自动化测试，更新期望值。

## 涉及文件

- `intelli-ai-engine/src/main/java/.../settings/*`（状态、配置 UI）
- `intelli-ai-engine/src/main/java/.../service/*`（读取配置并对接 AI 服务的类）
- 国际化资源：`src/main/resources/messages/AIJBundle_*.properties`
- 可能受影响的测试文件 `src/test/java/...`

## 测试计划

1. 打开设置页面，修改超时与 token 值，点击应用后重新打开确认显示单位正确；
2. 在服务调用处打日志或使用断点，确认传递给后端的参数为毫秒/实际 token 数；
3. 运行相关单元测试与 `./gradlew test`，确保无回归。
