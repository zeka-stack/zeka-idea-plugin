在 IntelliJ IDEA Plugin SDK 里，“搜索下拉组件”并不是一个单一控件名，而是几类常用 UI 组件/模式的统称。下面我按官方 SDK 的真实用法 +
最佳实践，给你一个可直接选型的完整对照表（也是 JetBrains 自己插件常用的）。

⸻

一、最常用：SearchTextField（带下拉过滤 / 搜索框）

👉 90% 插件搜索场景的首选

适用场景
• ToolWindow 搜索
• 设置页过滤
• 列表 / 树内容过滤
• “输入即过滤”的下拉列表

SDK 类

com.intellij.ui.SearchTextField

特点
• 内置清除按钮 ❌
• 支持监听文本变化
• 不自带数据源（你自己过滤 list / tree）
• JetBrains 官方插件大量使用

示例

SearchTextField searchField = new SearchTextField();
searchField.addDocumentListener(new DocumentAdapter() {
@Override
protected void textChanged(@NotNull DocumentEvent e) {
String text = searchField.getText();
filter(text);
}
});

✅ 推荐指数：★★★★★

⸻

二、搜索 + 下拉候选：TextFieldWithAutoCompletion

👉 类似“搜索建议 / 补全”

SDK 类

com.intellij.ui.TextFieldWithAutoCompletion

适用场景
• 搜索 + 推荐候选
• Provider / Model / API Key 选择
• Command / Action 搜索

示例

TextFieldWithAutoCompletion<String> field =
new TextFieldWithAutoCompletion<>(
project,
new StringsCompletionProvider(values, null),
true,
""
);

特点
• 下拉补全 popup（IDE 原生样式）
• 支持模糊匹配
• 可异步提供候选

✅ 推荐指数：★★★★★

⸻

三、搜索型下拉选择：ComboBox + SpeedSearch

👉 官方推荐给“下拉 + 搜索”的组合方式

SDK 类

ComboBox<T>
SpeedSearchSupply

示例

ComboBox<String> comboBox = new ComboBox<>(items);
SpeedSearchSupply.installOn(comboBox);

特点
• 下拉时直接输入过滤
• 零成本集成
• IDEA 所有下拉列表默认体验

⚠️ 不适合大量数据（>1k）

✅ 推荐指数：★★★★☆

⸻

四、大数据搜索选择：JBList / JBTable + SpeedSearch

👉 专业级搜索下拉（ToolWindow / Popup）

SDK 类

JBList
JBTable
SpeedSearch
PopupChooserBuilder

示例（Action 弹窗）

JBList<String> list = new JBList<>(data);
new SpeedSearch(list);

PopupChooserBuilder<String> builder =
new PopupChooserBuilder<>(list);
builder.createPopup().showInFocusCenter();

特点
• 支持万级数据
• 键盘体验极佳
• Action 搜索 / AI 工具选择必用

✅ 推荐指数：★★★★★（高级）

⸻

五、Settings / ToolWindow 官方组合（强烈推荐）

JetBrains 官方 UI 模式：

SearchTextField
↓
JBList / Tree

+ SpeedSearch

为什么官方这么干？
• 搜索输入逻辑清晰

四、API 异步加载 + ComboBox 的正确姿势（非常重要）

List<String> models = apiClient.fetchModels();

    ApplicationManager.getApplication().invokeLater(() -> {
        modelComboBox.setModel(
            new DefaultComboBoxModel<>(models.toArray(new String[0]))
        );
    });

});

五、如果模型名很长 / 有层级（你一定会遇到）

比如：

qwen2.5-72b-instruct
qwen2.5-72b-instruct-int8
deepseek-r1
gpt-4o-mini

强烈建议：自定义 Renderer

modelComboBox.setRenderer(new ListCellRenderer<>() {
private final SimpleColoredComponent component = new SimpleColoredComponent();

    @Override
    public Component getListCellRendererComponent(
        JList<? extends String> list,
        String value,
        int index,
        boolean isSelected,
        boolean cellHasFocus
    ) {
        component.clear();
        component.append(value, SimpleTextAttributes.REGULAR_ATTRIBUTES);
        return component;
    }

});

👉 SpeedSearch 会自动基于 renderer 文本做匹配

六、SpeedSearch 的匹配规则（你关心的）

默认行为
• 忽略大小写
• 连续输入形成搜索串
• ESC 清空搜索
• 超时自动 reset

不能做的事（要提前知道）

❌ 不支持拼音 / 分词
❌ 不支持权重排序
❌ 不支持模糊评分（Levenshtein）

但对 100～300 条模型名，已经是最优解
