# IDEA 2026.3 兼容升级

## 结论

插件兼容上限从 `262.*` 调到 `263.*`，发布版本统一为 `2026.3.1000`。编译基线仍是 Java 21 和 `platformVersion=2024.2`，避免把 2026.3 才有的 API 写进主流产物。

## 必须改的 API

- Problems View 在 2026.3 拆成 bundled plugin `com.intellij.problemsView`。Engine 和 Repairer 增加 optional 依赖，扩展点同时保留在主 `plugin.xml`，供 2026.2 及更早使用。
- `intellij.platform.externalSystem` 使用独立 classloader。Javadoc 把 Gradle 版本读取拆到 `GradleExternalSystemVersionReader`，只通过 `Class.forName` 加载。Changelog 去掉对 `ProjectSystemId` 的直接链接。两个插件都声明该模块依赖。
- JCEF 和 DVCS 的版本判断从 `startsWith("2026.2")` 改为按主次版本比较，2026.3 会继续带上这些依赖。
- VCS、XML 继续使用已有别名 `com.intellij.modules.vcs`、`com.intellij.modules.xml`。

## 这次没有调用、因此没有迁移的删除项

Kotlin UI DSL 1、平台 OkHttp、JNA、`ApplicationLoadListener`、`LangDataKeys` 执行相关 DataKey、`StdModuleTypes`、实现 `Sdk`。

## 验证

默认 `compileJava` 仍对着 2024.2。把 `platformVersion` 改成 `2026.3` 后需要 JDK 25，并确认 `bundledPlugin("com.intellij.problemsView")` 与 `bundledModule("intellij.platform.externalSystem")` 能解析。Plugin Verifier 列表已加入 `IU 2026.3`。
