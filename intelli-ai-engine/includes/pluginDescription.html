IntelliAI Engine is a foundational IntelliJ extension that provides a unified AI Service API for plugin developers.

GitHub | Issues

Core Capabilities

  • 🤖 Multi-model access: preset endpoints and parameter templates for OpenAI, Qwen, Ollama, LM Studio, SiliconFlow
  • ⚙️ Unified configuration UI: one panel for credentials, models and rate limits with instant validation
  • 🔒 Secure credentials: Password Safe based key storage with unique service names to avoid overwrites
  • 🎨 Reusable UI widgets: inline generation buttons, status bar entries, progress dialogs ready for downstream plugins
  • ⚡ Task pipeline: handles request orchestration, streaming responses and error recovery off the EDT

How to Use

  1. 📦 Add dependency: Add IntelliAI Engine as a dependency in your custom plugin
  2. 🚀 Invoke API: Invoke AIService (or provider facades) to run chat/completion tasks
  3. 🎯 Optional integration: Reuse the provided UI components, notification utilities and settings entries for consistent UX

Plugins Powered by IntelliAI Engine

  • 📝 IntelliAI Javadoc: Automatically generate Javadoc comments using AI
  • 📋 IntelliAI Changelog: Generate changelogs, reports, and commit messages using AI
  • 🔍 IntelliAI Tracer: Trace and analyze code execution with AI assistance

With IntelliAI Engine you can focus on business logic and UX, while the engine centralizes provider integrations, credential management and UI scaffolding.

IntelliAI Engine 是一个面向插件开发者的基础引擎，提供统一的 AI Service API、配置与凭证管理能力。

核心能力

  • 🤖 多模型接入：内置 OpenAI、通义千问、Ollama、LM Studio、SiliconFlow 等服务商的 Endpoint 与参数模板
  • ⚙️ 统一配置面板：集中式设置页管理所有服务商的密钥、模型与速率限制，支持即时验证
  • 🔒 安全凭证存储：基于 IntelliJ Password Safe 的 API Key 管理策略，自动生成隔离的服务名，避免覆盖
  • 🎨 可复用 UI：提供生成按钮、状态栏入口、进度弹窗等 UI 组件，帮助下游插件快速搭建交互
  • ⚡ 任务执行管线：封装请求调度、流式输出和错误处理，确保在 IDE 中稳定运行

使用步骤

  1. 📦 添加依赖：在自定义插件的依赖中添加 IntelliAI Engine
  2. 🚀 调用 API：通过 AIService 或对应的 Provider Facade 发起推理请求
  3. 🎯 可选集成：复用提供的 UI 组件、通知工具类与设置项，保持一致的交互体验

基于 IntelliAI Engine 的插件

  • 📝 IntelliAI Javadoc：使用 AI 自动生成 Javadoc 注释
  • 📋 IntelliAI Changelog：使用 AI 生成变更日志、工作日报和提交记录
  • 🔍 IntelliAI Tracer：使用 AI 辅助追踪和分析代码执行

借助 IntelliAI Engine，可以把精力集中在业务逻辑与体验设计上，而不是在各个模型服务之间来回打补丁。
