IntelliAI Engine 是一个面向插件开发者的基础引擎，提供统一的 AI Service API、配置与凭证管理能力。 依赖本插件即可一次性获得多模型服务商支持、统一配置面板以及可复用的 UI 组件，无需在每个插件里重复实现相同逻辑。

核心能力

  • 多模型接入：内置 OpenAI、通义千问、Ollama、LM Studio、SiliconFlow 等服务商的 Endpoint 与参数模板
  • 统一配置面板：集中式设置页管理所有服务商的密钥、模型与速率限制，支持即时验证
  • 安全凭证存储：基于 IntelliJ Password Safe 的 API Key 管理策略，自动生成隔离的服务名，避免覆盖
  • 可复用 UI：提供生成按钮、状态栏入口、进度弹窗等 UI 组件，帮助下游插件快速搭建交互
  • 任务执行管线：封装请求调度、流式输出和错误处理，确保在 IDE 中稳定运行

使用步骤

  1. 在自定义插件的依赖中添加 IntelliAI Engine
  2. 通过 AIService 或对应的 Provider Facade 发起推理请求
  3. 可选：复用提供的 UI 组件、通知工具类与设置项，保持一致的交互体验

借助 IntelliAI Engine，可以把精力集中在业务逻辑与体验设计上，而不是在各个模型服务之间来回打补丁。

IntelliAI Engine is a foundational IntelliJ extension for plugin developers. It exposes a unified AI Service API, centralized configuration UI, secure credential management, reusable UI widgets, and a robust task pipeline so every plugin can talk to OpenAI, Qwen, Ollama, LM Studio, SiliconFlow, etc. without re‑implementing glue code.

Core Capabilities

  • Multi-model access: preset endpoints and parameter templates for OpenAI, Qwen, Ollama, LM Studio, SiliconFlow
  • Unified configuration UI: one panel for credentials, models and rate limits with instant validation
  • Secure credentials: Password Safe based key storage with unique service names to avoid overwrites
  • Reusable UI widgets: inline generation buttons, status bar entries, progress dialogs ready for downstream plugins
  • Task pipeline: handles request orchestration, streaming responses and error recovery off the EDT

How to Use

  1. Add IntelliAI Engine as a dependency in your custom plugin
  2. Invoke AIService (or provider facades) to run chat/completion tasks
  3. Optionally reuse the provided UI components, notification utilities and settings entries for consistent UX

With IntelliAI Engine you can focus on business logic and UX, while the engine centralizes provider integrations, credential management and UI scaffolding.
