1.1.0

  • 新增 ModelScope 模型服务商，设置页可直接选择并刷新模型列表
  • Base URL 默认指向 AI 问答接口（https://api-inference.modelscope.cn/v1）
  • 模型参数与运行时配置现在和每个服务商配置绑定，可独立调优并持久化到可用列表
  • AIServiceFactory 及相关调用链更新为读取提供商自身参数，Javadoc 执行器根据提供商开关日志
  • Ollama 与 LM Studio 配置页的 API Key 输入框改为可选项，不再强制禁用，便于使用自定义代理或本地认证
  • 优化设置页的超时输入，改为以秒为单位展示与保存
  • 将最大 Token 数以 K 为单位配置，提示文案同步更新，确保表述更直观

1.1.0

  • Added the ModelScope provider so it can be configured and refreshed from the settings UI
  • Base URL defaults to the AI inference endpoint (https://api-inference.modelscope.cn/v1)
  • Bound model parameters and runtime settings to each provider config so every entry keeps its own tuning
  • Updated AIServiceFactory and the JavaDoc executor to honor per-provider parameters and verbose logging switches
  • Made the API Key field optional for Ollama and LM Studio so users can enter keys when needed without being blocked
  • Switched the timeout control to seconds for clearer configuration
  • Updated the Max Tokens control to use K units with refreshed hints for clearer guidance
