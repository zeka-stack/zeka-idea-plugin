# IntelliAI Tracer 用户手册

## 部署脚本

### 功能说明

`deploy.sh` 自动化 `intelli-ai-tracer` 的版本更新、Gradle `publishPlugin`、ZIP 上传及 Landing/Docs 部署，覆盖完整上线流程。

### 使用方法

1. 进入项目目录执行：
   ```bash
   cd /Users/dong4j/Developer/0.Worker/opensource/zeka.stack/zeka-idea-plugin/intelli-ai-tracer
   bash deploy.sh -v 1.0.2
   ```
2. 参数说明：
    - `-v <version>`：同步版本号。
    - `-l`：仅部署 `landing.html`。
    - `-z`：仅上传 ZIP（重命名为 `tra.zip`）。
    - `-d`：仅部署 `docs/`。
3. 部署成功后可访问：
    - Landing：`https://tra.dong4j.site/`
    - ZIP：`https://tra.dong4j.site/tra.zip`
    - Docs：`https://tra.dong4j.site/docs`

### 注意事项

- 确保脚本具备执行权限并已正确配置 `REMOTE_HOST`（默认 `aliyun`）。
- ZIP 会从 `build/distributions` 中选取最新文件，执行前请先完成构建。
- `docs/` 同步采用 `rsync --delete`，避免误删请确认目录内容。

## Nginx 配置

### 功能说明

`tra.dong4j.site.conf` 管理 HTTPS、ZIP 下载类型和 Docsify 路由，提供统一访问入口。

### 部署步骤

1. 将配置拷贝至 `/etc/nginx/sites-available/tra.dong4j.site.conf`。
2. 链接到 `sites-enabled/` 并运行 `nginx -t`。
3. 执行 `sudo systemctl reload nginx` 使配置生效。

### 目录映射

- `/var/www/tra-landing`：包含 `landing.html` 及 `tra.zip`。
- `/var/www/tra-docs`：Docsify 文档根目录（默认 `guide/index.html`）。
