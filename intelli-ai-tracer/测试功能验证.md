# IntelliAI Tracer 多场景工作流功能测试

## 🎯 测试目标

验证扩展后的 IntelliAI Tracer 插件支持三种不同场景的工作流生成：

1. **方法调用工作流** - 在方法调用上生成执行流程
2. **方法调用链分析** - 在方法定义上生成调用链分析
3. **类关系分析** - 在类定义上生成类关系链

## 📋 测试步骤

### 准备工作

1. 确保 IntelliAI Engine 插件已安装并配置了 AI 提供商
2. 在 IntelliJ IDEA 中安装并启用 IntelliAI Tracer 插件
3. 准备一个 Java 项目用于测试

### 测试场景 1：方法调用工作流

**测试代码示例：**

```java
public class OrderService {
    public void processOrder(String orderId) {
        // 将光标放在下面的方法调用上
        paymentService.processPayment(orderId);  // <- 光标放这里
    }
}
```

**测试步骤：**

1. 将光标放在 `paymentService.processPayment(orderId)` 方法调用上
2. 使用以下任一方式触发：
    - 快捷键：`Cmd+Shift+D` (Mac) 或 `Ctrl+Shift+D` (Windows/Linux)
    - 右键菜单：选择 "Explain Workflow with AI"
    - Alt+Enter：选择 "Explain Workflow"

**预期结果：**

- 生成方法调用的执行工作流
- 包含调用时序图（过滤 getter/setter 和日志方法）
- 详细的技术说明

### 测试场景 2：方法调用链分析

**测试代码示例：**

```java
public class OrderService {
    // 将光标放在方法名上
    public void processOrder(String orderId) {  // <- 光标放在 processOrder 上
        validateOrder(orderId);
        paymentService.processPayment(orderId);
        notificationService.sendConfirmation(orderId);
    }
}
```

**测试步骤：**

1. 将光标放在方法名 `processOrder` 上（方法定义处）
2. 触发工作流分析

**预期结果：**

- 生成该方法的调用链分析
- 显示谁调用了这个方法
- 显示该方法调用了哪些其他方法
- 包含调用链路径图

### 测试场景 3：类关系分析

**测试代码示例：**

```java
// 将光标放在类名上
public class OrderService extends BaseService implements PaymentProcessor {  // <- 光标放在 OrderService 上
    private PaymentService paymentService;
    private NotificationService notificationService;
    
    // ... 方法实现
}
```

**测试步骤：**

1. 将光标放在类名 `OrderService` 上（类定义处）
2. 触发工作流分析

**预期结果：**

- 生成类关系分析报告
- 显示继承关系（父类、接口）
- 显示依赖关系（字段、方法参数等）
- 包含类关系图
- 设计模式识别和架构建议

## 🔍 验证要点

### 1. 智能场景检测

- [ ] 插件能正确识别光标位置的元素类型

- [ ] 生成的时序图不包含 getter/setter 方法

- [ ] 生成的内容符合预期格式

### 4. 用户体验验证

- [ ] 操作响应及时，不阻塞 UI
- [ ] 错误提示清晰友好
- [ ] 结果展示在工具窗口中
- [ ] 支持多种触发方式

## 🐛 常见问题排查

### 问题 1：无法触发工作流分析

**可能原因：**

- 光标位置不正确
- 不在 Java 文件中
- AI 提供商未配置

**解决方案：**

- 确保光标在方法调用、方法定义或类定义上
- 检查 IntelliAI Engine 的 AI 提供商配置

### 问题 2：生成的分析内容不符合预期

**可能原因：**

- AI 提示词需要调整
- 上下文信息不完整

**解决方案：**

- 在设置中调整提示词模板
- 确保代码结构清晰，依赖关系明确

### 问题 3：意图操作不显示

**可能原因：**

- 光标位置不支持
- 插件未正确安装

**解决方案：**

- 检查光标是否在支持的元素上
- 重启 IntelliJ IDEA
