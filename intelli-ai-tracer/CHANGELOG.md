# IntelliAI Tracer 更新记录

## [1.1.0] - 2024-11-21

### 🚀 新增功能

#### 多场景工作流生成支持

- **方法调用工作流** - 在方法调用上生成执行流程分析（原功能增强）
- **方法调用链分析** - 在方法定义上生成该方法的调用链分析
- **类关系分析** - 在类定义上生成类关系链和架构分析

#### 智能场景检测

- 自动识别光标位置的元素类型（方法调用、方法定义、类定义）
- 智能错误提示，引导用户正确使用

#### 多种触发方式

- **快捷键** - 现有快捷键自动适配不同场景
- **右键菜单** - "Explain Workflow with AI" 选项
- **意图操作** - Alt+Enter 快速触发（新增）

#### 智能过滤机制

- 自动过滤 getter/setter 方法（get*/set*/is* 开头）
- 过滤日志记录方法（包含 log/logger/debug/info/warn/error 关键词）
- 过滤工具方法（toString/equals/hashCode 等）
- 聚焦核心业务逻辑，生成更有价值的分析

### 🎯 功能增强

#### AI 提示词优化

- 针对不同场景使用专门的提示词模板
- **方法调用模板** - 聚焦执行流程和调用关系
- **方法调用链模板** - 关注调用者分析和业务流程
- **类关系模板** - 专注架构设计和设计模式识别
- 所有模板都包含过滤规则，确保分析质量

#### 上下文模型扩展

- `MethodCallerChainContext` - 专门用于方法调用链分析
- `ClassRelationshipContext` - 专门用于类关系分析
- 支持继承关系、依赖关系、设计模式识别

### 🛠️ 技术改进

#### 架构优化

- 扩展 `PSIUtil` 工具类，支持多种元素类型检测
- 增强 `CallGraphBuilder`，支持类关系分析
- 重构 `WorkflowExplainerService`，支持多场景分析

#### 线程安全

- 修复 PSI 操作的 ReadAction 问题
- 确保所有 PSI 访问都在正确的线程中执行
- 改进错误处理和异常安全

#### 国际化支持

- 完善国际化资源文件配置
- 新增多种场景的错误提示和用户消息
- 支持意图操作的本地化

### 🐛 问题修复

- 修复 PSI 操作必须在 ReadAction 中执行的线程安全问题
- 修复国际化资源文件配置错误
- 修复意图操作注册配置问题
- 改进 JSON 序列化支持，兼容新的上下文模型

### 📋 使用指南

#### 方法调用场景

```java
public void processOrder() {
    // 将光标放在方法调用上
    paymentService.processPayment(orderId);  // <- 光标这里
    // 触发：生成方法调用执行流程
}
```

#### 方法定义场景

```java
// 将光标放在方法名上
public void processOrder() {  // <- 光标在 processOrder 上
    // 触发：生成该方法的调用链分析
}
```

#### 类定义场景

```java
// 将光标放在类名上
public class OrderService {  // <- 光标在 OrderService 上
    // 触发：生成类关系链和架构分析
}
```

### 🎯 过滤机制说明

所有分析都会自动过滤以下方法，确保聚焦核心业务逻辑：

- **属性访问方法** - `getName()`, `setName()`, `isActive()` 等
- **日志记录方法** - `log.info()`, `logger.debug()`, `LOG.error()` 等
- **工具方法** - `toString()`, `equals()`, `hashCode()` 等

### 📊 兼容性

- **IntelliJ IDEA** - 2022.3 - 2025.2
- **Java 版本** - Java 17+
- **依赖插件** - IntelliAI Engine (必需)
