Analyzes and explains the workflow of Java code elements using AI.

This intention action supports three different scenarios:

  • Method Call - Generates execution flow analysis when cursor is on a method call
  • Method Definition - Generates caller chain analysis when cursor is on a method definition
  • Class Definition - Generates class relationship analysis when cursor is on a class definition

The analysis automatically filters out getter/setter methods, logging methods, and utility methods to focus on core business logic.

Results are displayed in the IntelliAI Tracer tool window with detailed technical explanations and Mermaid diagrams.
