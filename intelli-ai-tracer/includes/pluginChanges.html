1.0.0

  • 🎉 初始版本发布
  • ✨ 支持分析方法的调用链（上行和下行）
  • ✨ 支持提取方法的上下文信息（类、注解、注释等）
  • ✨ 支持通过 AI 生成调用时序图和业务逻辑说明
  • ✨ 集成 IntelliAI Engine 插件，支持多种 AI 提供商（通义千问、Ollama、OpenAI 等）
  • ✨ 在编辑器右键菜单中提供工作流解释功能
  • ✨ 完整的国际化支持（中英文）
  • 🔧 支持 IntelliJ IDEA 2022.3 及更高版本

主要功能

  • 调用链分析：自动分析方法的调用链，包括谁调用了该方法以及该方法调用了哪些方法
  • 上下文提取：提取方法的完整上下文信息，包括类信息、注解、注释等
  • AI 生成说明：使用 AI 生成 Mermaid 格式的调用时序图和业务逻辑说明
  • 智能定位：在代码编辑器中选中方法调用即可分析

系统要求

  • IntelliJ IDEA 2022.3 或更高版本
  • 需要安装 IntelliAI Engine 插件（dev.dong4j.zeka.stack.idea.plugin.common.ai）
  • Java 17+

1.0.0

  • 🎉 Initial release (MVP)
  • ✨ Support analyzing method call chains (upstream and downstream)
  • ✨ Support extracting method context information (class, annotations, comments, etc.)
  • ✨ Support generating call sequence diagrams and business logic explanations using AI
  • ✨ Integrated with IntelliAI Engine plugin, supporting multiple AI providers (Qwen, Ollama, OpenAI, etc.)
  • ✨ Workflow explanation feature available in editor context menu
  • ✨ Full internationalization support (Chinese and English)
  • 🔧 Support for IntelliJ IDEA 2022.3 and later

Main Features

  • Call Chain Analysis: Automatically analyze method call chains, including who calls the method and what methods the method calls
  • Context Extraction: Extract complete context information of methods, including class information, annotations, comments, etc.
  • AI-Generated Explanations: Use AI to generate Mermaid-format call sequence diagrams and business logic explanations
  • Smart Positioning: Select method calls in code editor to analyze

System Requirements

  • IntelliJ IDEA 2022.3 or later
  • IntelliAI Engine plugin (dev.dong4j.zeka.stack.idea.plugin.common.ai) must be installed
  • Java 17+
