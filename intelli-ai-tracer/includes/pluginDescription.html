IntelliTrace Analyzer

使用 AI 自动分析代码方法调用链和业务流程的 IntelliJ IDEA 插件。

功能特性

  • 🔍 调用链分析：自动分析方法的调用链（上行和下行）
  • 📊 上下文提取：提取方法的上下文信息（类、注解、注释等）
  • 🤖 AI 生成说明：通过 AI 生成可视化的调用时序图和业务逻辑说明
  • 🎯 智能定位：在代码编辑器中选中方法调用即可分析
  • 🤖 多种 AI 提供商支持：支持通义千问、Ollama、OpenAI 等多种 AI 服务
  • 🌍 国际化支持：完整的中英文多语言支持

使用场景

  • 代码理解：快速理解复杂方法的调用关系和业务逻辑
  • 代码审查：分析代码的调用链，发现潜在问题
  • 文档生成：自动生成方法的调用时序图和业务说明

快速开始

  1. 安装插件（需要先安装 IntelliAI Engine 插件）
  2. 在 Settings → Tools → IntelliAI Engine 中配置 AI 提供商和 API Key
  3. 在代码编辑器中选中方法调用，右键选择 "Explain Workflow with AI"

配置说明

  • AI 提供商配置：在 Settings → Tools → IntelliAI Engine 中配置和测试 AI 提供商

技术栈

  • 基于 IntelliJ Platform SDK 2.1.0
  • 依赖 IntelliAI Engine 插件提供统一的 AI 服务接口
  • 使用 PSI（Program Structure Interface）进行代码分析
  • 完整的国际化支持（中英文）

IntelliTrace Analyzer

An IntelliJ IDEA plugin that uses AI to automatically analyze code method call chains and business workflows.

Features

  • 🔍 Call Chain Analysis: Automatically analyze method call chains (upstream and downstream)
  • 📊 Context Extraction: Extract method context information (class, annotations, comments, etc.)
  • 🤖 AI-Generated Explanations: Generate visual call sequence diagrams and business logic explanations using AI
  • 🎯 Smart Positioning: Select method calls in code editor to analyze
  • 🤖 Multiple AI Provider Support: Support for various AI services including Qwen, Ollama, OpenAI, and more
  • 🌍 Internationalization Support: Full support for Chinese and English

Use Cases

  • Code Understanding: Quickly understand call relationships and business logic of complex methods
  • Code Review: Analyze code call chains to discover potential issues
  • Documentation Generation: Automatically generate call sequence diagrams and business explanations for methods

Quick Start

  1. Install the plugin (requires IntelliAI Engine plugin to be installed first)
  2. Configure AI providers and API keys in Settings → Tools → IntelliAI Engine
  3. Select method calls in code editor and right-click to choose "Explain Workflow with AI"

Configuration

  • AI Provider Configuration: Configure and test AI providers in Settings → Tools → IntelliAI Engine

Technology Stack

  • Based on IntelliJ Platform SDK 2.1.0
  • Depends on IntelliAI Engine plugin for unified AI service interface
  • Uses PSI (Program Structure Interface) for code analysis
  • Full internationalization support (Chinese and English)
