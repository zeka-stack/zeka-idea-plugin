# IntelliAI Tracer 版本兼容性说明

## 🎯 支持的版本

- **IntelliJ IDEA**: 2022.3 - 2025.2
- **Java**: 17+
- **依赖插件**: IntelliAI Engine (必需), Markdown (可选)

## 🔧 已知兼容性问题及解决方案

### 1. 意图操作描述文件问题 (IntelliJ 2025+)

#### 问题描述

```
PluginException: Intention Description Dir URL is null: Workflow Analysis; ExplainWorkflowIntentionAction; while looking for description.html
```

#### 解决方案 ✅

- 为意图操作创建了完整的描述文件
- 文件位置：`src/main/resources/intentionDescriptions/ExplainWorkflowIntentionAction/`
    - `description.html` - 功能描述
    - `before.java.template` - 使用前示例
    - `after.java.template` - 使用后示例

### 2. Markdown 链接处理器兼容性问题

#### 问题描述

- 在 IntelliJ 2022 版本中正常工作
- 在 IntelliJ 2025 版本中可能出现 API 兼容性问题

#### 解决方案 ✅

##### 方案 1：增强异常处理

- 在 `MarkdownLinkHandler` 中添加了完整的异常处理
- 如果 Markdown API 不兼容，会静默降级，不影响其他功能

##### 方案 2：备选链接处理工具

- 创建了 `LinkUtil` 工具类作为备选方案
- 提供统一的链接处理功能，不依赖 Markdown 插件

```java
// 使用备选方案处理链接
LinkUtil.handleLink(project, "java://path/to/file.java:10:5");
LinkUtil.handleLink(project, "scratch://temp-file.md");
```

### 3. PSI 操作线程安全问题

#### 问题描述

```
Read access is allowed from inside read-action (or EDT) only
```

#### 解决方案 ✅

- 将所有 PSI 操作移到 `ReadAction.compute()` 中
- 确保线程安全访问

### 4. 链接处理线程安全问题

#### 问题描述

```
Access is allowed from Event Dispatch Thread (EDT) only; If you access or modify model on EDT consider wrapping your code in WriteIntentReadAction or ReadAction
```

#### 解决方案 ✅

- 将所有文件操作包装在 `ApplicationManager.getApplication().invokeLater()` 中
- 确保 UI 操作在 EDT 线程中执行
- 修复了 `LinkUtil` 中的线程安全问题

### 5. 其他插件冲突问题

#### 问题描述

```
NullPointerException in ChangelogSettingsConfigurable.isModified
```

#### 分析

- 这是其他插件（changelog）的问题，不是 IntelliAI Tracer 的问题
- 可能是插件加载顺序或依赖关系导致的

#### 建议解决方案

1. 检查是否有插件冲突
2. 尝试禁用其他可能冲突的插件
3. 重启 IntelliJ IDEA

## 🛠️ 兼容性最佳实践

### 1. 异常处理策略

- 所有可能不兼容的 API 调用都包装在 try-catch 中
- 失败时静默降级，不影响核心功能
- 提供备选实现方案

### 2. API 使用原则

- 优先使用稳定的公开 API
- 避免使用内部 API 或反射
- 为不同版本提供条件分支

### 3. 功能降级策略

- 核心功能（工作流分析）在所有版本中都能正常工作
- 辅助功能（链接点击）在不兼容时优雅降级
- 用户体验不受影响

## 🔍 故障排除指南

### 1. 意图操作不显示

**可能原因：**

- 光标位置不正确
- 不在 Java 文件中
- 插件未正确安装

**解决方法：**

- 确保光标在方法调用、方法定义或类定义上
- 检查文件类型是否为 Java
- 重启 IntelliJ IDEA

### 2. 链接点击无响应

**可能原因：**

- Markdown 插件版本不兼容
- API 变更导致的兼容性问题

**解决方法：**

- 使用备选的 `LinkUtil` 工具类
- 手动复制链接地址进行导航
- 检查 Markdown 插件版本

### 3. 工作流分析失败

**可能原因：**

- AI 提供商未配置
- 网络连接问题
- PSI 访问权限问题

**解决方法：**

- 检查 IntelliAI Engine 的 AI 提供商配置
- 确保网络连接正常
- 重新触发分析
