## 概述

### 需求背景

当前 AI 工作流解释功能采用同步方式，等待完整响应返回后再显示结果。对于长文本生成场景，用户需要等待较长时间才能看到结果。流式输出可以：

- ✅ **实时反馈**：逐块显示 AI 生成的内容，提升用户体验
- ✅ **降低等待感**：用户可以看到生成进度，减少等待焦虑
- ✅ **更好的交互**：支持在生成过程中取消操作
- ✅ **Markdown 实时渲染**：内容实时追加到 Markdown 编辑器，预览自动刷新

### 技术挑战

1. **HTTP 流式响应处理**：需要处理 SSE (Server-Sent Events) 格式的流式数据
2. **Document 实时更新**：需要实时追加内容到 Document，编辑器自动刷新
3. **线程安全**：确保 Document 更新在 EDT 线程执行
4. **性能优化**：频繁更新 Document 时的性能考虑

### 2. 核心实现原理

#### 2.1 使用 LightVirtualFile + FileEditorManager

- **创建虚拟文件**：使用 `LightVirtualFile` 创建 Markdown 虚拟文件
- **打开编辑器**：使用 `FileEditorManager` 在 Tool Window 中打开文件
- **获取 Document**：通过 `FileDocumentManager` 获取 Document 对象
- **实时更新**：使用 `Document.insertString()` 实时追加内容

#### 2.2 流式响应处理流程

```
AI 流式响应 → onChunk() → Document.insertString() → 编辑器自动刷新 → Markdown 预览自动刷新
```

### 1. WorkflowResultToolWindow 扩展

```java
/**
 * 流式追加 Markdown 内容
 * <p>
 * 用于实时追加 AI 流式响应的增量内容到 Document，编辑器会自动刷新显示。
 * Markdown 预览也会自动刷新。
 *
 * @param chunk 增量内容块
 */
public void appendMarkdownStream(@NotNull String chunk) {
    ApplicationManager.getApplication().invokeLater(() -> {
        if (document != null) {
            // 在 WriteAction 中追加内容
            ApplicationManager.getApplication().runWriteAction(() -> {
                int endOffset = document.getTextLength();
                document.insertString(endOffset, chunk);
            });
        } else {
            // 如果 Document 还未创建，先初始化
            if (mainPanel == null) {
                getContent();
            }
            // 递归调用，等待 Document 创建完成
            if (document != null) {
                appendMarkdownStream(chunk);
            }
        }
    });
}

/**
 * 初始化流式响应
 * <p>
 * 在开始流式响应前调用，清空之前的内容并显示工具窗口。
 */
public void initStream() {
    ApplicationManager.getApplication().invokeLater(() -> {
        // 确保内容已初始化
        if (mainPanel == null) {
            getContent();
        }
        
        // 清空之前的内容
        if (document != null) {
            ApplicationManager.getApplication().runWriteAction(() -> {
                document.setText("");
            });
        }
        
        // 显示工具窗口
        showToolWindow();
    });
}

/**
 * 完成流式响应
 * <p>
 * 在流式响应完成后调用，可以执行一些清理操作。
 */
public void completeStream() {
    // 流式响应完成后的处理（如果需要）
    // 例如：滚动到底部、显示完成提示等
}
```

#### 1.2 性能优化：批量更新机制（可选）

如果频繁更新导致性能问题，可以实现批量更新机制：

```java
/** 缓冲区，用于批量更新 */
private final StringBuilder streamBuffer = new StringBuilder();

/** 批量更新阈值（字符数） */
private static final int BATCH_SIZE = 100;

/**
 * 流式追加 Markdown 内容（带批量更新优化）
 *
 * @param chunk 增量内容块
 */
public void appendMarkdownStream(@NotNull String chunk) {
    streamBuffer.append(chunk);
    
    // 达到批量更新阈值时，刷新缓冲区
    if (streamBuffer.length() >= BATCH_SIZE) {
        flushStreamBuffer();
    }
}

/**
 * 刷新流式缓冲区
 */
private void flushStreamBuffer() {
    if (streamBuffer.length() == 0) {
        return;
    }
    
    ApplicationManager.getApplication().invokeLater(() -> {
        if (document != null) {
            ApplicationManager.getApplication().runWriteAction(() -> {
                int endOffset = document.getTextLength();
                document.insertString(endOffset, streamBuffer.toString());
                streamBuffer.setLength(0);
            });
        }
    });
}

/**
 * 完成流式响应（刷新剩余缓冲区）
 */
public void completeStream() {
    // 刷新剩余的缓冲区内容
    flushStreamBuffer();
}
```

### 2. WorkflowExplainerService 扩展

**文件**: `intelli-ai-tracer/src/main/java/dev/dong4j/zeka/stack/idea/plugin/workflow/service/WorkflowExplainerService.java`

#### 2.1 添加流式响应方法

```java
/**
 * 流式分析工作流并生成说明
 * <p>
 * 使用流式方式调用 AI 生成说明，实时显示生成的内容。
 *
 * @param psiFile PSI 文件
 * @param caretOffset 光标位置偏移量
 * @param listener 流式响应监听器（可选，如果为 null 则使用默认监听器）
 * @throws Exception 当分析或 AI 调用失败时抛出
 */
public void explainWorkflowStream(@NotNull PsiFile psiFile, 
                                   int caretOffset,
                                   @Nullable AIStreamResponseListener listener) throws Exception {
    // PSI 操作必须在 ReadAction 中执行
    String json = com.intellij.openapi.application.ReadAction.compute(() -> {
        try {
            // 1. 获取光标位置的方法调用
            PsiMethodCallExpression methodCall = PSIUtil.getMethodCallAtOffset(psiFile, caretOffset);
            if (methodCall == null) {
                throw new RuntimeException(WorkflowBundle.message("error.no.method.call"));
            }

            // 2. 解析被调用的方法
            PsiMethod targetMethod = methodCall.resolveMethod();
            if (targetMethod == null) {
                throw new RuntimeException(WorkflowBundle.message("error.cannot.resolve.method"));
            }

            // 3. 获取当前上下文
            PsiMethod currentMethod = PSIUtil.getMethodAtOffset(psiFile, caretOffset);
            PsiClass currentClass = PSIUtil.getClassAtOffset(psiFile, caretOffset);

            // 4. 构建工作流上下文
            WorkflowContext context = buildWorkflowContext(targetMethod, currentMethod, currentClass);

            // 5. 生成 JSON
            return JSONSerializer.toJson(context);
        } catch (RuntimeException e) {
            throw e;
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    });
    
    // 6. 调用 AI 流式生成说明（在 ReadAction 外部执行）
    callAIStream(json, listener);
}

/**
 * 调用 AI 流式生成说明
 *
 * @param json 上下文 JSON
 * @param listener 流式响应监听器（可选）
 * @throws Exception 当 AI 调用失败时抛出
 */
private void callAIStream(@NotNull String json, 
                          @Nullable AIStreamResponseListener listener) throws Exception {
    // 获取 AI 配置
    AIProviderSettings settings = AIProviderSettings.getInstance();
    java.util.List<AIProviderConfig> verifiedProviders = settings.getVerifiedProviders();
    
    if (verifiedProviders.isEmpty()) {
        throw new Exception(WorkflowBundle.message("error.ai.provider.not.configured"));
    }

    // 使用第一个已验证的提供商
    AIProviderConfig config = verifiedProviders.get(0);

    // 构建 Prompt
    String systemPrompt = buildSystemPrompt();
    String userPrompt = buildUserPrompt(json);

    // 创建 AI 请求
    AIChatRequest request = new AIChatRequest(systemPrompt, userPrompt);

    // 创建默认监听器（如果未提供）
    if (listener == null) {
        listener = createDefaultStreamListener();
    }

    // 调用 AI 服务（流式）
    AIService aiService = AIServiceImpl.getInstance();
    try {
        aiService.generateContentStream(project, request, config, listener);
    } catch (AIServiceException e) {
        throw new Exception(WorkflowBundle.message("error.ai.service.failed", e.getMessage()));
    }
}

/**
 * 创建默认的流式响应监听器
 * <p>
 * 将流式响应实时追加到 Tool Window 的 Markdown 编辑器中。
 *
 * @return 流式响应监听器
 */
@NotNull
private AIStreamResponseListener createDefaultStreamListener() {
    WorkflowResultToolWindow toolWindow = WorkflowResultToolWindow.getInstance(project);
    
    return new AIStreamResponseListener() {
        @Override
        public void onStart() {
            // 初始化流式响应
            toolWindow.initStream();
        }

        @Override
        public void onChunk(@NotNull String chunk) {
            // 追加增量内容
            toolWindow.appendMarkdownStream(chunk);
        }

        @Override
        public void onComplete(@NotNull String fullText) {
            // 完成流式响应
            toolWindow.completeStream();
        }

        @Override
        public void onError(@NotNull Exception error) {
            // 错误处理
            ApplicationManager.getApplication().invokeLater(() -> {
                NotificationUtil.showError(project, 
                    WorkflowBundle.message("error.stream.failed", error.getMessage()));
            });
        }
    };
}
```

/**
 * 显示结果（流式方式）
 *
 * @param project 项目对象
 * @param psiFile PSI 文件
 * @param caretOffset 光标位置偏移量
 */
private void showResultStream(@NotNull Project project, 
                               @NotNull com.intellij.psi.PsiFile psiFile, 
                               int caretOffset) {
    // 异步执行，避免阻塞 UI
    ProgressManager.getInstance().run(new Task.Backgroundable(project, 
        WorkflowBundle.message("progress.analyzing"), true) {
        @Override
        public void run(@NotNull ProgressIndicator indicator) {
            indicator.setIndeterminate(true);
            indicator.setText(WorkflowBundle.message("progress.analyzing.call.chain"));

            try {
                // 创建服务实例
                WorkflowExplainerService service = new WorkflowExplainerService(project);

                // 流式分析工作流（传递 PSI 文件和光标位置）
                indicator.setText(WorkflowBundle.message("progress.calling.ai"));
                service.explainWorkflowStream(psiFile, caretOffset, null);
            } catch (Exception ex) {
                // 在 EDT 中显示错误
                ApplicationManager.getApplication().invokeLater(() -> {
                    NotificationUtil.showError(project, 
                        WorkflowBundle.message("error.analysis.failed", ex.getMessage()));
                });
            }
        }
    });
}

## 代码示例

### 完整使用示例

```java
// 在 Action 中调用流式响应
public class ExplainWorkflowAction extends AnAction {
    @Override
    public void actionPerformed(@NotNull AnActionEvent e) {
        Project project = e.getProject();
        if (project == null) {
            return;
        }

        Editor editor = e.getData(CommonDataKeys.EDITOR);
        PsiFile psiFile = e.getData(CommonDataKeys.PSI_FILE);
        if (editor == null || psiFile == null) {
            NotificationUtil.showError(project, WorkflowBundle.message("error.no.editor"));
            return;
        }

        int caretOffset = editor.getCaretModel().getOffset();

        // 使用流式响应
        WorkflowExplainerService service = new WorkflowExplainerService(project);
        try {
            service.explainWorkflowStream(psiFile, caretOffset, null);
        } catch (Exception ex) {
            NotificationUtil.showError(project, 
                WorkflowBundle.message("error.analysis.failed", ex.getMessage()));
        }
    }
}
```

// 创建自定义监听器

## 注意事项

### 1. 线程安全

- ⚠️ **流式响应在后台线程接收**：`onChunk()` 可能在后台线程调用
- ✅ **Document 更新必须在 EDT**：使用 `ApplicationManager.getApplication().invokeLater()` 更新 Document
- ✅ **WriteAction 保护**：Document 修改必须在 `runWriteAction()` 中执行

### 2. 性能考虑

- ⚠️ **频繁更新**：每个 chunk 都更新 Document 可能影响性能
- ✅ **批量更新**：可以实现批量更新机制，累积多个 chunk 后一次性插入
- ⚠️ **内存使用**：长时间流式响应可能占用较多内存

### 3. 用户体验

- ✅ **实时反馈**：内容实时显示，提升用户体验
- ✅ **自动刷新**：编辑器自动刷新，Markdown 预览自动更新
- ⚠️ **光标位置**：频繁更新时，光标位置可能被推到末尾（这是预期行为）

### 4. 错误处理

- ⚠️ **网络中断**：流式响应过程中网络中断会触发 `onError()`
- ⚠️ **解析错误**：单个块的解析错误不应中断整个流，应记录并继续
- ✅ **异常传播**：严重错误应通过 `onError()` 通知监听器

### 5. 向后兼容

- ✅ **同步接口保留**：保留 `explainWorkflow()` 同步方法
- ✅ **可选功能**：流式响应作为可选功能，不影响现有功能
- ✅ **配置支持**：可以使用配置控制是否启用流式响应
