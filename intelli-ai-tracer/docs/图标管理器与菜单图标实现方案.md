# 图标管理器与菜单图标实现方案

## 功能概述

- 参考 `intelli-ai-javadoc` 中的 `AIJicons` 机制，在 IntelliAI Tracer 中引入统一的图标管理工具类，集中管理 `/icons` 目录下的 SVG 资源。
- 将统一管理的图标应用到右键上下文菜单的动作上（`ExplainWorkflowAction`），使其在菜单、工具栏中展示一致的视觉元素。

## 实现方案

### 1. 图标资源管理

1. 在 `src/main/java/icons` 下新增 `TracerIcons`：
    - 使用 `IconLoader.getIcon` 读取 `/icons/*` 资源。
    - 暴露 `public static final Icon` 常量（先提供 `WORKFLOW_ACTION`，后续可扩展）。
    - JavaDoc 中说明可用尺寸、存放路径，保持与 `AIJicons` 一致的注释规范。
2. 复用现有的 `pluginIcon_16.svg` 作为默认动作图标，路径 `/icons/pluginIcon_16.svg`。
3. 若后续需要更多尺寸，可在同一类中继续添加常量，避免分散加载逻辑。

### 2. 右键菜单动作图标

1. 在 `ExplainWorkflowAction` 构造方法里，将 `super(..., null)` 替换为 `super(..., TracerIcons.WORKFLOW_ACTION)`。
2. 保持 Internationalization（`WorkflowBundle.messagePointer`）逻辑不变，只新增图标引用。
3. 检查 `plugin.xml` 中注册的 action group（如 EditorPopupMenu、ProjectViewPopup 等），确认展示时会使用 `AnAction` 的 `Presentation.icon`
   ，无需额外配置。

## 涉及文件

| 文件                                                 | 修改类型 | 说明               |
|----------------------------------------------------|------|------------------|
| `src/main/java/icons/TracerIcons.java`             | 新增   | 统一图标管理           |
| `src/main/java/dev/.../ExplainWorkflowAction.java` | 修改   | 为 action 提供 icon |
| `src/main/resources/icons/pluginIcon_16.svg`       | 复用   | 作为动作图标资源，若需可补充注释 |

## 测试计划

1. **编译校验**：`./gradlew :intelli-ai-tracer:build`，确保新增类和引用正常。
2. **IDE 手动验证**：通过 `./gradlew :intelli-ai-tracer:runIde` 启动沙箱 IDE，右键编辑器空白处或代码行，检查“Explain Workflow”菜单项是否显示新图标。
3. **多语言检查**：切换 IDE 语言或资源包，确保仅增加图标，不影响现有文案。
4. **资源校验**：在 IDE 中使用“Analyze > Inspect Code”确认不存在未使用的资源或缺失引用。

如需扩展更多动作或视图图标，可在 `TracerIcons` 中追加常量并在对应 `AnAction`、ToolWindow、通知等位置调用，保持统一入口。
