Archiver Man

Archiver Man 让你无需离开 IntelliJ IDEA 就能直接浏览、比较并编辑 ZIP/JAR 等压缩包中的文本文件。它面向需要频繁调整打包资源、部署脚本或第三方 SDK 的开发者，提供顺畅的“所见即所得”编辑体验。

核心能力

  • 📂 即时展开：在 Project View 中直接展开压缩包，支持模糊搜索与导航
  • ✏️ 内联编辑：用 IDE 原生编辑器修改压缩条目，享受语法高亮、代码提示与 Diff
  • 💾 安全保存：保存时自动备份原 ZIP，支持批量写入与冲突检查，避免包体损坏
  • 🔄 实时刷新：检测外部修改并提示合并，确保团队协作时的可预期性
  • ⚙️ 自定义策略：可配置最大可编辑文件大小、备份数量、批量写入间隔与性能模式

使用场景

  • 快速修补部署包中的配置、脚本或资源文件
  • 验证第三方 SDK/示例压缩包内的代码片段
  • 在发布/回滚过程中批量更新 ZIP/JAR 中的多份配置

最低要求

  • IntelliJ IDEA 2022.3+
  • Java 17+
  • Gradle 8+

Roadmap：当前版本提供基础架构、通知体系与上下文入口，后续迭代将逐步开放缓存、批量保存、冲突解决以及多格式支持。
