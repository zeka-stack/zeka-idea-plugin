# Archive Man P1 任务清单（多格式拓展）

## 1. Tar / Gz / Tgz 支持

| 任务          | 描述                                                  | 状态    |
|-------------|-----------------------------------------------------|-------|
| `P1-TAR-01` | 引入 Apache Commons Compress 依赖                       | DONE  |
| `P1-TAR-02` | 实现 `TarArchiveFormatProvider`（解析 `.tar`）            | DONE  |
| `P1-GZ-01`  | 实现 `GzArchiveFormatProvider`（支持 `.gz` 单文件 + `.tgz`） | DONE  |
| `P1-TAR-03` | 共用 `ArchiveHandler` 抽象，对接 `EntryInfo` 构建            | DOING |
| `P1-TAR-04` | 针对 tar/gz/tgz 的单元测试                                 | TODO  |
