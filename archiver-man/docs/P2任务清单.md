# Archive Man P2 任务清单（可编辑能力）

聚焦版本 `v0.5.x`，目标是让 Project View 展开的归档条目支持“可编辑副本 → 安全写回”全链路，并补齐批量保存、冲突检测、设置与测试。

## 1. Editable VFS & Service

| 任务         | 描述                                                | 状态   |
|------------|---------------------------------------------------|------|
| `P2-EV-01` | 将 `EditableArchiveService` 拆分只读/写回逻辑，支持多格式归档      | DONE |
| `P2-EV-02` | 在 Project View 节点上新增“打开可编辑副本”动作（Zip/Tar/Gz/7z 通用） | DONE |
| `P2-EV-03` | 针对非 Zip（提取目录）条目，支持映射回原始归档并写回                      | DONE |
| `P2-EV-04` | 统一可编辑 VirtualFile 的元数据（新增格式字段、CRC 记录、备份策略）        | DONE |

## 2. 保存与批处理

| 任务         | 描述                      | 状态   |
|------------|-------------------------|------|
| `P2-SV-01` | 实现“多条目批量写回”队列，降低频繁 IO   | DONE |
| `P2-SV-02` | 提供后台任务进度通知，按条目/归档展示写入状态 | DONE |
| `P2-SV-03` | 引入“快速保存”与“延迟写回”策略（可配置）  | DONE |
| `P2-SV-04` | 保存失败后的自动回滚与 `.bak` 清理   | DONE |

## 3. 冲突检测 & 备份

| 任务         | 描述                                   | 状态   |
|------------|--------------------------------------|------|
| `P2-CF-01` | 支持对 Tar/Gz/7z 的 CRC / timestamp 冲突检测 | DONE |
| `P2-CF-02` | 保存前可选生成 `.bak`，并新增“恢复上一版本”操作         | DONE |
| `P2-CF-03` | 记录冲突日志并在 Notification/StatusBar 中提示  | DONE |

## 4. 设置与 UI

| 任务         | 描述                                                     | 状态   |
|------------|--------------------------------------------------------|------|
| `P2-UI-01` | 在 Settings → Tools → Archiver Man 中新增：启用可编辑、最大文件、备份策略等 | DONE |
| `P2-UI-02` | 设置变更后触发同步（刷新开关、更新 Feature Toggles）                     | DONE |
| `P2-UI-03` | 编辑器状态栏 / Project View 节点展示“只读/可写”标识                    | DONE |

## 5. 测试 & 文档

| 任务         | 描述                                        | 状态   |
|------------|-------------------------------------------|------|
| `P2-QA-01` | 针对写回流程编写单元 / 集成测试（包含冲突、rollback、批量保存）     | DONE |
| `P2-QA-02` | 更新 `docs/用户手册.md` 可编辑章节 & 截图              | DONE |
| `P2-QA-03` | 更新 `includes/pluginChanges.html` 记录 P2 功能 | DONE |

> 完成 `Editable VFS + 批量保存 + 冲突检测 + 设置 + 测试文档` 五大模块后，即可宣布 P2 交付。
