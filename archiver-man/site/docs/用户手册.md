# Archiver Man 用户手册

## 1. 插件简介

Archiver Man 是一款让开发者能够在 IntelliJ IDEA 内直接浏览、编辑并回写 ZIP/JAR 等压缩包中文件的工具。插件聚焦“无线解压编辑”场景，致力于减少频繁解压或切换外部工具所带来的低效体验。

## 2. 功能特性

- 📂 **即时展开**：在 Project View 中直接展开压缩包，配合 IDE 原生搜索与跳转。
- ✏️ **内联编辑**：使用 IDE 编辑器修改条目（语法高亮、格式化、Diff 均可用）。
- 💾 **安全写回**：保存时自动备份原压缩包，逐条或批量写回并校验 CRC。
- 🔄 **冲突保护**：检测外部修改，提示用户执行合并或放弃当前更改。
- ⚙️ **策略可调**：限制最大可编辑文件大小、控制批量写入间隔、选择是否启用备份。
- 🗂️ **多格式支持**：当前版本支持 `ZIP`、`JAR`、`TAR`、`GZ`/`TGZ`、`7Z`，后续还会扩展更多归档格式。

> 当前版本提供入口与基础设施，后续迭代将逐步开放缓存、批量保存与冲突解决等能力。

## 3. 快速上手

1. 在 IDE 中安装 Archiver Man（或通过 `./gradlew runIde` 进入沙箱调试）。
2. 在 Project View 中定位至 `.zip`/`.jar`/`.tar`/`.gz`/`.7z` 文件并展开。
3. 选中条目并右键 `Archiver Man / Inspect Entry`，插件会创建可写副本并自动打开编辑器。
4. 像普通文件一样修改并保存（`Cmd/Ctrl + S`），内容会写回原压缩包并保留 `.bak` 备份。

## 4. 设置说明

预计设置入口：`Settings / Preferences → Tools → Archiver Man`

| 选项                     | 说明                               |
|------------------------|----------------------------------|
| Enable archive browser | 控制是否在 Project View 中展开压缩包        |
| Enable editable mode   | 启用/关闭可编辑副本以及写回能力                 |
| Enable backups (.bak)  | 保存前是否自动生成 `.bak` 备份文件            |
| Max editable file size | 单个文件的可编辑大小上限（MB），避免大文件占用过多内存     |
| Batch save delay (ms)  | 多文件连续保存时的合并写回间隔，0 表示实时写回         |
| Show editable badge    | 是否在 Project View 节点上显示“可编辑/只读”提示 |

> 设置入口：`Settings / Preferences → Tools → Archiver Man`

## 5. 常见操作

- **展开压缩包**：Project View 中直接展开即可。
- **触发上下文动作**：在压缩条目上右键 → `Archiver Man / Inspect Entry`。
- **保存写回**：在可编辑副本中按 `Cmd/Ctrl + S`，状态栏会提示写入进度和结果。
- **冲突提示**：若压缩包在 IDE 外被修改，Archiver Man 会拒绝写入并提示重新打开条目。
- **查看通知**：所有提示统一由 `Archiver Man Notifications` 组下发，可在 Event Log 查看历史记录。

## 6. 构建与调试

```bash
# 启动沙箱 IDE
./gradlew runIde

# 运行测试
./gradlew test

# 构建 Marketplace 可用的 ZIP
./gradlew buildPlugin
```

构建产物位于 `build/distributions/`。发布前需设置环境变量 `PUBLISH_TOKEN` 与证书信息。
