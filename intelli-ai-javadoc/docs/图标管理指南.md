## 概述

在 IntelliJ IDEA 插件开发中，图标管理是一个重要的环节。插件中的各种操作（Action、ToolWindow、Toolbar、TreeNode、Notification 等）都可能需要使用图标。本文档介绍如何按照
IntelliJ 官方推荐的方式管理插件图标。

---

## 图标存放位置

### 推荐目录结构

IDEA 官方建议把图标资源放在插件的 `resources` 目录下，推荐使用 `icons` 子目录：

```
my-plugin/
 ├─ src/
 │   └─ main/
 │       ├─ java/
 │       └─ resources/
 │           └─ icons/
 │               ├─ icon_action_16.svg
 │               ├─ icon_notification_24.svg
 │               └─ icon_dialog_32.svg
```

### 文件命名规范

- **语义化命名**：使用有意义的文件名，如 `icon_run.svg`、`icon_settings.svg`
- **尺寸标识**：建议在文件名中包含尺寸信息，如 `icon_16.svg`、`icon_24.svg`、`icon_32.svg`
- **用途标识**：可以包含用途信息，如 `icon_action_16.svg`、`icon_notification_24.svg`

**示例：**

```
icons/
 ├─ aij_16.svg      # 16x16 主图标
 ├─ aij_24.svg      # 24x24 通知图标
 └─ aij_32.svg      # 32x32 对话框图标
```

## 图标格式选择

### SVG（推荐）

**优点：**

- ✅ 矢量图形，可无损缩放
- ✅ 支持高 DPI 显示
- ✅ 文件体积小
- ✅ 支持主题适配（深色/浅色模式）
- ✅ 官方推荐格式

**适用场景：** 所有场景，特别是需要适配不同分辨率和主题的场景

### PNG

**优点：**

- ✅ 兼容性好
- ✅ 支持透明度

**缺点：**

- ❌ 位图，缩放会失真
- ❌ 需要为不同尺寸准备多个文件
- ❌ 文件体积较大

**适用场景：** 复杂图标、需要特殊效果的图标、启动画面大图标

### 推荐策略

- **优先使用 SVG**：对于大多数图标，使用 SVG 格式
- **PNG 作为备选**：仅在 SVG 无法满足需求时使用 PNG

## 图标尺寸规范

IntelliJ 官方对插件中常用图标尺寸有明确建议，主要按**用途类型**来分类：

### 尺寸对照表

| 图标类型                            | 常用尺寸（px）      | 格式建议      | 用途/位置           | 示例         |
|---------------------------------|---------------|-----------|-----------------|------------|
| **Toolbar / Action**            | 16×16         | SVG / PNG | 工具栏按钮、动作图标      | 菜单项、工具栏按钮  |
| **Tool Window / Tab**           | 13×13 或 16×16 | SVG       | 工具窗口标签页、导航栏     | 底部工具窗口标签   |
| **Menu / Context Menu**         | 16×16         | SVG / PNG | 菜单项图标           | 右键菜单、主菜单   |
| **Tree / List Nodes**           | 16×16         | SVG / PNG | 项目树、结构树节点       | 项目视图树节点    |
| **Notifications / Balloon**     | 24×24 或 32×32 | SVG       | 弹出通知图标          | 通知弹窗、气球提示  |
| **Editor Gutter / Line Marker** | 12×12         | SVG       | 代码标记栏、断点、标记提示   | 编辑器行号旁标记   |
| **Dialog / Settings**           | 32×32 / 48×48 | SVG       | 配置面板、弹窗大图标      | 设置对话框、配置面板 |
| **Splash / Welcome Screen**     | 128×128 或更大   | PNG / SVG | 插件启动页或欢迎界面      | 欢迎页面、启动画面  |
| **Action Toolbar Large**        | 24×24         | SVG       | 工具栏大按钮，常见于可折叠面板 | 大型工具栏按钮    |

### 尺寸选择原则

1. **不要拉伸小图标到大尺寸**：保持清晰度，为不同尺寸准备对应的图标文件
2. **遵循官方建议**：按照使用场景选择对应的尺寸
3. **统一管理**：使用统一的命名规范和图标管理类

## 在代码中加载图标

### 使用 IconLoader

IntelliJ 提供了 `com.intellij.openapi.util.IconLoader` 工具类来加载图标：

```java
import com.intellij.openapi.util.IconLoader;
import javax.swing.Icon;

// 加载单个图标
Icon myIcon = IconLoader.getIcon("/icons/my_icon.svg", MyClass.class);
```

### 参数说明

- **第一个参数**：图标文件路径，以 `/resources` 为根目录
- **第二个参数**：类加载器的参照类，通常传入当前类或图标管理类

### 完整示例

```java
import com.intellij.openapi.util.IconLoader;
import javax.swing.Icon;

public class MyAction extends AnAction {
    private static final Icon ACTION_ICON = 
        IconLoader.getIcon("/icons/icon_action_16.svg", MyAction.class);
    
    @Override
    public void actionPerformed(@NotNull AnActionEvent e) {
        // 使用图标
        e.getPresentation().setIcon(ACTION_ICON);
    }
}
```

## 在 plugin.xml 中引用图标

### Action 元素

在 `plugin.xml` 中定义 Action 时，可以直接引用资源路径：

```xml
<actions>
    <action id="MyPlugin.MyAction"
            class="com.myplugin.MyAction"
            text="Do Something"
            description="Performs an action"
            icon="/icons/icon_action_16.svg"/>
</actions>
```

### ToolWindow 元素

```xml
<toolWindow id="My Tool Window"
            factoryClass="com.myplugin.MyToolWindowFactory"
            anchor="bottom"
            icon="/icons/icon_toolwindow_16.svg"/>
```

### Intention Action

对于 Intention Action，可以在类上使用 `@Presentation` 注解：

```java
@Presentation(icon = "/icons/icon_intention_16.svg")
public class MyIntentionAction extends PsiElementBaseIntentionAction {
    // ...
}
```

### 注意事项

- ✅ 路径以 `/resources` 为根目录
- ✅ 支持 `.png` 和 `.svg`，但官方推荐 SVG
- ✅ 路径必须以 `/icons/` 开头（如果图标在 icons 目录下）

## 支持深色主题

### 自动适配机制

IDEA 会自动尝试查找深色主题版本的图标：

**命名规则：**

- `<name>@2x_dark.svg` - 高分辨率深色版本
- `<name>@dark.svg` - 标准深色版本

**示例：**

```
icons/
 ├─ icon_16.svg          # 浅色主题版本
 ├─ icon_16@dark.svg     # 深色主题版本
 └─ icon_16@2x_dark.svg  # 高分辨率深色版本
```

### 使用方式

使用 `IconLoader` 加载时，IDEA 会根据当前主题自动选择对应的图标：

```java
// 自动根据主题选择 icon_16.svg 或 icon_16@dark.svg
Icon icon = IconLoader.getIcon("/icons/icon_16.svg", MyClass.class);
```

### 深色主题设计建议

- **对比度**：确保图标在深色背景下清晰可见
- **颜色调整**：可能需要调整颜色以适配深色主题
- **测试**：在浅色和深色主题下都进行测试

## 统一图标管理类

### 推荐做法

将所有插件图标集中在一个类里统一管理，便于维护和修改：

```java
package icons;

import com.intellij.openapi.util.IconLoader;
import org.jetbrains.annotations.NotNull;
import javax.swing.Icon;

/**
 * 插件图标管理类
 * <p>
 * 用于集中管理插件中使用的所有图标资源。
 * 图标文件应放置在 {@code src/main/resources/icons/} 目录下。
 * <p>
 * 图标尺寸说明：
 * <ul>
 *   <li>16x16 - Toolbar/Action/Menu/ToolWindow（工具栏、动作、菜单、工具窗口）</li>
 *   <li>24x24 - Notifications（通知图标）</li>
 *   <li>32x32 - Dialog/Settings（对话框、设置面板）</li>
 * </ul>
 */
public class MyIcons {
    /**
     * 加载图标
     * <p>
     * 用于加载位于 {@code /icons/} 目录下的图标文件。
     * 路径必须以 {@code /icons/} 开头。
     *
     * @param iconPath 图标文件路径，相对于 resources 根目录（例如："/icons/icon.svg"）
     * @return 加载的图标
     */
    @NotNull
    private static Icon load(@NotNull String iconPath) {
        return IconLoader.getIcon(iconPath, MyIcons.class);
    }

    // ========== 16x16 图标 - 用于 Toolbar/Action/Menu/ToolWindow ==========
    
    /**
     * 主图标 (16x16)
     * <p>
     * 用于：工具栏按钮、动作图标、菜单项、工具窗口标签
     */
    public static final Icon MAIN_16 = load("/icons/icon_main_16.svg");

    /**
     * 运行图标 (16x16)
     */
    public static final Icon RUN_16 = load("/icons/icon_run_16.svg");

    /**
     * 设置图标 (16x16)
     */
    public static final Icon SETTINGS_16 = load("/icons/icon_settings_16.svg");

    // ========== 24x24 图标 - 用于 Notifications ==========
    
    /**
     * 通知图标 (24x24)
     * <p>
     * 用于：通知弹窗、气球提示
     */
    public static final Icon NOTIFICATION_24 = load("/icons/icon_notification_24.svg");

    // ========== 32x32 图标 - 用于 Dialog/Settings ==========
    
    /**
     * 对话框图标 (32x32)
     * <p>
     * 用于：设置面板、对话框、大图标显示
     */
    public static final Icon DIALOG_32 = load("/icons/icon_dialog_32.svg");
}
```

### 使用示例

```java
import icons.MyIcons;

// 在 Action 中使用
public class MyAction extends AnAction {
    @Override
    public void actionPerformed(@NotNull AnActionEvent e) {
        e.getPresentation().setIcon(MyIcons.MAIN_16);
    }
}

// 在按钮中使用
JButton button = new JButton("Run");
button.setIcon(MyIcons.RUN_16);

// 在通知中使用
Notification notification = new Notification(
    "group",
    "Title",
    "Content",
    NotificationType.INFORMATION
);
// 注意：Notification 通常使用 NotificationType 自动提供图标
```

### 优势

- ✅ **集中管理**：所有图标路径集中在一处，修改方便
- ✅ **代码可读性高**：使用有意义的常量名
- ✅ **类型安全**：编译时检查，避免路径错误
- ✅ **便于维护**：统一修改图标路径或替换图标
- ✅ **方便主题适配**：可以统一处理深色主题

## 最佳实践

### 1. 图标文件组织

```
resources/
 └─ icons/
     ├─ action_16.svg          # 动作图标
     ├─ action_16@dark.svg     # 深色主题版本
     ├─ notification_24.svg    # 通知图标
     ├─ dialog_32.svg          # 对话框图标
     └─ splash_128.svg         # 启动画面图标
```

### 2. 命名规范

- ✅ 使用有意义的名称：`icon_run.svg` 而不是 `icon1.svg`
- ✅ 包含尺寸信息：`icon_16.svg`、`icon_24.svg`
- ✅ 包含用途信息：`icon_action_16.svg`、`icon_notification_24.svg`
- ✅ 使用小写字母和下划线：`icon_main_action.svg`

### 3. 尺寸适配

- ✅ 为不同尺寸准备对应的图标文件
- ✅ 不要拉伸小图标到大尺寸
- ✅ 遵循官方推荐的尺寸规范

### 4. 主题适配

- ✅ 为深色主题准备对应的图标版本
- ✅ 使用 `@dark` 或 `@2x_dark` 后缀
- ✅ 在两种主题下都进行测试

### 5. 性能优化

- ✅ 使用 SVG 格式减少文件体积
- ✅ 图标常量使用 `static final`，避免重复加载
- ✅ 在图标管理类中统一加载，利用类加载机制缓存

### 6. 代码组织

- ✅ 创建统一的图标管理类
- ✅ 按尺寸分类组织常量
- ✅ 添加清晰的注释说明用途

## 常见问题

### Q1: 图标不显示怎么办？

**可能原因：**

1. 路径错误：检查路径是否以 `/icons/` 开头
2. 文件不存在：确认文件在 `resources/icons/` 目录下
3. 格式不支持：确认使用 SVG 或 PNG 格式

**解决方法：**

```java
// 检查路径是否正确
Icon icon = IconLoader.getIcon("/icons/icon_16.svg", MyClass.class);
// 确保文件存在于 src/main/resources/icons/icon_16.svg
```

### Q2: 如何在不同分辨率下显示清晰？

**解决方法：**

- 使用 SVG 格式（矢量图，自动适配）
- 或提供 `@2x` 版本：`icon_16.svg` 和 `icon_16@2x.svg`

### Q3: 深色主题下图标不清晰？

**解决方法：**

- 提供深色主题版本：`icon_16@dark.svg`
- 调整图标颜色以适配深色背景
- 在深色主题下测试显示效果

### Q4: 图标在 plugin.xml 中无法解析？

**可能原因：**

- 路径格式错误
- 文件不存在

**解决方法：**

```xml
<!-- ✅ 正确：使用 icon 属性 -->
<action icon="/icons/icon_16.svg">

<!-- ❌ 错误：不要使用 <icon> 子元素（仅适用于某些元素） -->
<action>
    <icon path="/icons/icon_16.svg"/>
</action>
```

### Q5: 如何为不同尺寸创建图标？

**建议：**

1. 从最大尺寸开始设计（如 32×32）
2. 使用矢量工具（如 Inkscape、Illustrator）导出不同尺寸
3. 确保小尺寸下图标仍然清晰可辨
4. 使用统一的命名规范

### Q6: 图标加载性能问题？

**优化建议：**

```java
// ✅ 推荐：使用 static final 常量
public class MyIcons {
    public static final Icon ICON = IconLoader.getIcon("/icons/icon.svg", MyIcons.class);
}

// ❌ 不推荐：每次调用都加载
public Icon getIcon() {
    return IconLoader.getIcon("/icons/icon.svg", this.getClass()); // 会重复加载
}
```
