# IntelliAI Javadoc 用户手册

## 概述

IntelliAI Javadoc 是一个基于人工智能的 IntelliJ IDEA 插件，能够自动为 Java 代码生成高质量的 Javadoc 注释。该插件集成了 IntelliAI Engine，支持多个主流
AI 服务提供商，提供智能化的文档生成体验。

## 核心特性

- **智能生成**: 基于 AI 理解代码逻辑，生成准确的 Javadoc 注释
- **多入口支持**: 支持意图操作、快捷键、右键菜单等多种触发方式
- **批量处理**: 支持文件级别和项目级别的批量文档生成
- **性能模式**: 支持多 AI 提供商并行处理，大幅提升批量处理效率
- **高度可定制**: 提供丰富的配置选项和自定义模板支持
- **格式化优化**: 自动处理中英文混排和标点符号格式

## 快速开始

### 1. 安装插件

#### 系统要求

- **IntelliJ IDEA**: 2022.3 - 2025.2
- **Java 版本**: 17 或更高版本
- **操作系统**: Windows / macOS / Linux

#### 安装步骤

1. **从市场安装（推荐）**:
    - 打开 IntelliJ IDEA
    - `File` → `Settings` → `Plugins`
   - 搜索 `IntelliAI Javadoc`
    - 点击 `Install` 并重启 IDE

2. **手动安装**:
    - 下载最新版本的插件包文件
    - `File` → `Settings` → `Plugins`
    - 点击 `⚙️` → `Install Plugin from Disk...`
    - 选择下载的插件包并安装

### 2. 配置 AI 提供商

在开始使用之前，需要先配置 AI 服务提供商：

1. **打开 IntelliAI Engine 配置**:
    - `File` → `Settings` → `Tools` → `IntelliAI Engine`

2. **添加 AI 提供商**:
    - 点击 `+` 按钮添加新的配置
    - 选择提供商类型（如通义千问、OpenAI 等）
    - 填写必要信息（API Key、模型选择等）

3. **测试连接**:
    - 配置完成后点击 `测试连接`
    - 确保显示"连接成功"的提示

#### 推荐的 AI 提供商

| 提供商            | 优势           | 适用场景       |
|----------------|--------------|------------|
| **通义千问**       | 中文理解优秀，国内访问快 | 中文项目，国内用户  |
| **硅基流动**       | 模型丰富，性价比高    | 各类 Java 项目 |
| **OpenAI API** | 模型能力强，通用性强   | 英文项目，复杂代码  |
| **ModelScope** | 阿里云官方，稳定性好   | 企业级项目      |
| **Ollama**     | 本地部署，隐私保护好   | 敏感代码，离线环境  |

### 3. 基本使用

#### 方式一：意图操作（推荐）

1. 将光标放在需要生成 Javadoc 的代码上（类名、方法名、字段名）
2. 按下 `Alt + Enter`
3. 选择 `生成 Javadoc 注释`
4. 等待 AI 生成并自动插入

#### 方式二：快捷键

1. 定位到需要生成文档的代码位置
2. 按下 `Cmd + Shift + D`（Mac）/ `Ctrl + Shift + D`（Windows/Linux）
3. 自动为当前元素生成 Javadoc

#### 方式三：右键菜单

1. 在编辑器中右键点击
2. 选择 `生成 Javadoc`
3. 根据上下文生成相应文档

#### 方式四：Generate 菜单

1. 按 `Cmd + N`（Mac）/ `Ctrl + Insert`（Windows/Linux）
2. 选择 `Javadoc`
3. 生成当前元素的 Javadoc

### 架构概览

IntelliAI Javadoc 通过 IntelliAI Engine 获得 AI 能力，采用分层架构设计：

```

│      IntelliAI Javadoc 插件        │
├─────────────────────────────────────┤
│  用户界面层  │  Action / UI        │
│  业务逻辑层  │  Service / Task     │
│  AI 调用层  │  AI Integration     │
├─────────────────────────────────────┤
│      IntelliAI Engine 插件         │
│  AI 统一接口  │  AIService         │
│  提供商管理  │  Provider Config   │
│  服务抽象层  │  Common Components │
└─────────────────────────────────────┘
```

```java
// 调用 AI 服务
```

#### 2. AIRequestComposer

负责构建 AI 请求的组件，根据任务类型和用户设置生成合适的提示词：

```java
// 根据任务类型构建不同的提示词模板
public static AIChatRequest compose(SettingsState settings, DocumentationTask task) {
    String systemPrompt = resolveSystemPrompt(settings);
    String userPrompt = buildUserPrompt(settings, task);
    int tokenEstimate = estimateTokens(systemPrompt, userPrompt);
    return new AIChatRequest(systemPrompt, userPrompt, tokenEstimate);
}
```

#### 3. TaskExecutor

核心的任务执行器，负责协调 AI 调用和文档插入：

```java
public class TaskExecutor {
    // 处理单个任务
    private void processTask(DocumentationTask task, AIProviderConfig provider) {
        // 1. 构建请求
        AIChatRequest request = AIRequestComposer.compose(settings, task);

        // 2. 调用 AI 服务
        AIResponseListener listener = createResponseListener();
        String documentation = aiService.generateContent(project, request, provider, listener);

        // 3. 插入文档
        insertDocumentation(task, documentation);
    }
```

### 性能模式实现

#### 多提供商并行处理

当启用性能模式时，插件会使用多个已验证的 AI 提供商并行处理任务：

```java
public class ParallelProcessor {
    public void processTasks(List<DocumentationTask> tasks) {
        // 获取已验证的提供商
        List<AIProviderConfig> providers = getVerifiedProviders();

        // 创建线程池
        ExecutorService executor = Executors.newFixedThreadPool(
            calculateOptimalThreadCount(tasks.size(), providers.size())
        );

        // 分配任务给不同提供商
        List<CompletableFuture<Void>> futures = new ArrayList<>();
        for (AIProviderConfig provider : providers) {
            CompletableFuture<Void> future = CompletableFuture.runAsync(
                () -> processTasksWithProvider(tasks, provider),
                executor
            );
            futures.add(future);
        }

        // 等待所有任务完成
        CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();
    }
}
```

#### 动态线程分配

根据任务数量和提供商数量动态分配线程资源：

```java
private int calculateOptimalThreadCount(int taskCount, int providerCount) {
    if (taskCount <= 10) {
        return providerCount; // 每个提供商1个线程
    } else if (taskCount <= 50) {
        return providerCount * 2; // 每个提供商2个线程
    } else {
        return Math.min(providerCount * 4, taskCount);
    }
}
```

### 错误处理和重试机制

#### 智能重试

插件实现了多层级的错误处理和重试机制：

```java
public class RetryHandler {
    public String executeWithRetry(Supplier<String> task) {
        int attempts = 0;
        while (attempts < MAX_RETRIES) {
            try {
                return task.get();
            } catch (AIServiceException e) {
                attempts++;
                if (shouldRetry(e) && attempts < MAX_RETRIES) {
                    long waitTime = calculateBackoffTime(attempts);
                    Thread.sleep(waitTime);
                    continue;
                }
                throw e;
            }
        }
        throw new RuntimeException("Max retries exceeded");
    }

    private boolean shouldRetry(AIServiceException e) {
        return switch (e.getErrorCode()) {
            case NETWORK_ERROR, SERVICE_UNAVAILABLE, RATE_LIMIT -> true;
            default -> false;
        };
    }
}
```

## 常见问题

### Q: 为什么生成的 Javadoc 质量不高？

**A:** 可能的原因和解决方案：

1. **AI 提供商选择**:
    - 推荐使用通义千问或硅基流动处理中文代码
    - 确保选择的模型适合代码生成任务

2. **提示词优化**:
    - 在高级设置中自定义提示词
    - 针对项目特点调整提示词内容

3. **代码质量**:
    - 确保代码结构清晰，命名规范
    - 复杂的代码可能需要分步处理

### Q: 如何处理大型项目？

**A:** 针对大型项目的建议：

1. **分批处理**:
