# 统计信息弹窗测试说明

## 概述

为了直观地查看和调整 `TaskExecutor#showProviderStatistics` 方法生成的 HTML 样式，我创建了一个专门的 UI 测试。

## 测试文件

- `src/test/java/dev/dong4j/zeka/stack/idea/plugin/task/TaskExecutorProviderStatisticsUITest.java`

## 测试内容

该测试会：

1. 创建模拟的多提供商统计数据
2. 使用反射调用 `showProviderStatistics` 私有方法
3. 显示包含统计信息的 HTML 对话框
4. 让你可以看到实际的渲染效果

## 模拟数据

测试创建了三种场景：

- **QianWen 千问**: 5个完成，1个失败
- **Ollama (本地模型)**: 2个完成，1个跳过
- **Custom Provider**: 1个完成，2个失败，2个跳过

## 运行方式

### 方法 1: 使用 IntelliJ IDEA

1. 打开 IntelliJ IDEA
2. 在项目中找到测试文件：`TaskExecutorProviderStatisticsUITest.java`
3. 右键点击 `testShowProviderStatisticsDialog()` 方法
4. 选择 "Run 'testShowProviderStatisticsDialog()'"
5. 对话框将会弹出，你可以查看 HTML 渲染效果

### 方法 2: 使用 Gradle

```bash
cd intelli-ai-javadoc
./gradlew test --tests TaskExecutorProviderStatisticsUITest.testShowProviderStatisticsDialog
```

## 查看效果

运行测试后，你会看到一个模态对话框，显示：

- 标题："性能模式处理完成"
- 表格包含：
    - 服务商名称
    - 完成数量
    - 失败数量
    - 跳过数量
    - 耗时
- 总体统计行（深色背景）

关闭对话框后，测试会自动完成。

## 注意事项

- 测试使用反射调用私有方法
- 对话框是模态的，必须手动关闭
- 运行测试需要在 IntelliJ Platform 环境中
