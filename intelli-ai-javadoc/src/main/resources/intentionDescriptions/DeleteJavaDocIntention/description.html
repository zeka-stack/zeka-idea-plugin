Removes Javadoc or KDoc comments from Java or Kotlin code elements.

This intention action allows you to quickly delete Javadoc/KDoc comments from classes, methods, fields, and other code elements. It helps clean up code by removing documentation comments when they are no longer needed.

The intention is available when the cursor is positioned on a code element that has a Javadoc or KDoc comment. It works with both Java and Kotlin files.

You can enable or disable this feature in the plugin settings.
