# IntelliAI Nacos 用户手册

## 简介

这是一个用于在 IntelliJ IDEA 中直接管理和操作 Nacos 配置中心的插件。插件提供了可视化的配置管理界面，支持配置的拉取、发布、对比、删除等操作，极大提升了开发效率。

## 功能特性

- 📍 **Nacos 连接管理**：配置和管理 Nacos 服务器连接
- 📁 **配置树视图**：按 Namespace → Group → DataId 三级分组展示配置
- 📝 **配置编辑器**：支持多 Tab 编辑，支持 YAML、JSON、XML 等格式
- 🔄 **配置操作**：拉取、发布、对比配置
- ⚙️ **实时连接检测**：设置页一键测试 Nacos 连接并识别管理员权限
- 🔍 **配置搜索**：在配置树中搜索 Namespace、Group、DataId
- 🗑️ **配置删除**：支持单个或批量删除配置
- 🤖 **AI 集成**：集成 IntelliAI Engine，支持智能配置生成

## 快速开始

### 1. 安装插件

1. 在 IntelliJ IDEA 中打开 Settings → Plugins
2. 搜索 "IntelliAI Nacos" 并安装
3. 重启 IntelliJ IDEA

### 2. 配置 Nacos 连接

1. 打开 Settings → Tools → IntelliAI Nacos
2. 输入 Nacos 服务器地址、用户名和密码
3. 点击 "测试连接" 按钮验证连接
4. 如果是全局管理员，勾选相应选项

### 3. 启动本地 Nacos 注册中心

1. 打开 Settings → Tools → IntelliAI Nacos
2. 勾选“使用本地 Nacos 注册中心”
3. 点击“启动”按钮，插件会自动下载并启动内置 Nacos
4. 启动成功后会收到通知，访问地址为 `http://127.0.0.1:8848/nacos/index.html`
5. 如需停止服务，点击“停止”按钮即可
6. 面板下方会实时显示本地 Nacos 状态：
    - 🟢 绿色文本表示服务已启动，并展示“打开 Nacos 控制台”的超链接，可一键在浏览器中打开
    - 🔴 红色文本表示服务未启动，超链接隐藏
    - 状态在面板打开、启动、停止时自动刷新，重复点击“启动”会提示“本地 Nacos 已在运行”

> 提示：
> - 勾选本地注册中心后仍可在“自建 Nacos 注册中心”区域配置地址/用户名/密码，例如填写刚启动的本地实例
> - 取消勾选会自动停止本地 Nacos 服务，确保不会有遗留进程
> - 关闭或重启 IDE 时也会自动停止本地 Nacos，避免僵尸进程
> - 如服务无需账号密码，可将用户名/密码留空
> - 点击“打开本地 Nacos 目录”按钮可直接在系统文件管理器中定位本地实例目录
> - 同一个 IDE 仅需下载一次，后续启动会直接复用
> - 如果端口被占用或用户取消下载，会通过通知提示原因

### 4. 使用工具窗口

### 4. 使用工具窗口

1. 打开 View → Tool Windows → Nacos
2. 在左侧配置树中浏览配置
3. 双击 DataId 节点加载配置到编辑器
4. 使用 Pull、Push、Compare 按钮进行配置操作

## 工具窗口功能

### 工具栏

- 🔄 **Refresh**：重新加载命名空间与配置树，同时刷新状态面板
- ➕ **Add Tab**：创建新的空白配置页，默认以 `new-config-x.yaml` 命名
- ❌ **Close Tab**：关闭当前标签页，若存在未保存内容会弹窗确认
- ⚙️ **Settings**：直接跳转到插件设置页
- ❓ **Help**：打开官方 Nacos OpenAPI 文档

### 配置树

- 按 Namespace → Group → DataId 三级分组展示配置
- 支持展开/收拢所有节点
- 支持搜索过滤
- 双击 DataId 节点可加载配置到编辑器

### 配置编辑器

- 支持多 Tab 编辑
- 支持 YAML、JSON、XML、HTML、Text 格式
- 提供语法高亮和代码折叠
- 支持自动格式化

### 配置操作

#### Pull（拉取配置）

- 从 Nacos 拉取指定配置并在右侧创建/激活对应标签页
- 状态栏实时显示 “正在拉取”“拉取成功/失败” 等反馈

#### Push（发布配置）

- 将编辑器中的配置发布到 Nacos，成功后清空修改标记
- 根据 DataId 后缀自动识别配置类型并设置语法高亮

#### Compare（对比配置）

- 对比编辑器中的配置和 Nacos 中的配置
- 使用 IntelliJ 的 Diff 工具显示差异并保留原始内容

## 右键菜单功能

### 项目视图右键菜单

1. 在项目目录或配置文件上右键
2. 选择 "发布到 Nacos"
3. 在弹框中填写 Namespace / Group / DataId（默认值由文件名推断）
4. 自动读取文件内容并发布，成功后收到通知提示

### 配置树右键菜单

1. 在配置树节点上右键
2. 支持删除配置操作
3. 管理员可以批量删除 Group 或 Namespace 下的所有配置

## 意图操作

### 发布配置意图

1. 在 YAML 文件中按 `Alt+Enter`（Mac: `Option+Enter`）
2. 选择 "发布到 Nacos"
3. 在弹框中填写 Namespace / Group / DataId，确认后立即发布

### 对比配置意图

1. 在配置编辑器中按 `Alt+Enter`（Mac: `Option+Enter`）
2. 选择 "对比配置"
3. 输入 Namespace / Group / DataId
4. 自动拉取 Nacos 中的配置并弹出差异对比窗口

## 使用说明

### Nacos 客户端

插件使用 Nacos Client 2.2.0 与 Nacos 服务器通信：

```java
import dev.dong4j.zeka.stack.idea.plugin.nacos.client.NacosClient;

// 获取 Nacos 客户端实例
NacosClient client = NacosClient.getInstance(serverAddr, username, password);
```

### 配置管理

插件支持多种配置格式的自动识别：

- `.yml` / `.yaml` - YAML 格式
- `.json` - JSON 格式
- `.xml` - XML 格式
- `.html` - HTML 格式
- `.txt` - 文本格式

### 权限管理

- 非管理员用户只能删除自己创建的配置
- 管理员用户可以删除任何配置
- 删除操作前会进行权限验证

## 开发指南

### 添加新的 Action

1. 在 `action` 包下创建新的 Action 类
2. 在 `plugin.xml` 中注册 Action
3. 添加到相应的菜单组

### 添加新的 UI 组件

1. 在 `ui` 包下创建新的 UI 组件类
2. 使用 IntelliJ Platform UI 组件（JBLabel、JBTextField 等）
3. 遵循 IntelliJ UI 设计规范

### 添加国际化消息

1. 在 `messages.properties` 中添加英文消息
2. 在 `messages_zh_CN.properties` 中添加中文消息
3. 使用 `NacosBundle.message()` 获取消息

## 构建和发布

### 构建插件

```bash
./gradlew buildPlugin
```

构建产物位于 `build/distributions/` 目录。

### 发布插件

```bash
./gradlew publishPlugin
```

需要配置以下环境变量：

- `PUBLISH_TOKEN`：JetBrains Marketplace 发布令牌
- `CERTIFICATE_CHAIN`：证书链（可选）
- `PRIVATE_KEY`：私钥（可选）
- `PRIVATE_KEY_PASSWORD`：私钥密码（可选）

## 系统要求

- IntelliJ IDEA 2022.3 或更高版本
- Java 17+
- Gradle 8.0+
- IntelliAI Engine 插件
- Nacos 2.x 服务器
