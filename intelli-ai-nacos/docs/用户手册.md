# IntelliAI Nacos 用户手册

## 简介

这是一个用于在 IntelliJ IDEA 中直接管理和操作 Nacos 配置中心的插件。插件提供了可视化的配置管理界面，支持配置的拉取、发布、对比、删除等操作，极大提升了开发效率。

## 功能特性

- 📍 **Nacos 连接管理**：配置和管理 Nacos 服务器连接
- 📁 **配置树视图**：按 Namespace → Group → DataId 三级分组展示配置
- 📝 **配置编辑器**：支持多 Tab 编辑，支持 YAML、JSON、XML 等格式
- 🔄 **配置操作**：拉取、发布、对比配置
- 🔍 **配置搜索**：在配置树中搜索 Namespace、Group、DataId
- 🗑️ **配置删除**：支持单个或批量删除配置
- 🤖 **AI 集成**：集成 IntelliAI Engine，支持智能配置生成

## 快速开始

### 1. 安装插件

1. 在 IntelliJ IDEA 中打开 Settings → Plugins
2. 搜索 "IntelliAI Nacos" 并安装
3. 重启 IntelliJ IDEA

### 2. 配置 Nacos 连接

1. 打开 Settings → Tools → IntelliAI Nacos
2. 输入 Nacos 服务器地址、用户名和密码
3. 点击 "测试连接" 按钮验证连接
4. 如果是全局管理员，勾选相应选项

### 3. 使用工具窗口

1. 打开 View → Tool Windows → Nacos
2. 在左侧配置树中浏览配置
3. 双击 DataId 节点加载配置到编辑器
4. 使用 Pull、Push、Compare 按钮进行配置操作

## 工具窗口功能

### 配置树

- 按 Namespace → Group → DataId 三级分组展示配置
- 支持展开/收拢所有节点
- 支持搜索过滤
- 双击 DataId 节点可加载配置到编辑器

### 配置编辑器

- 支持多 Tab 编辑
- 支持 YAML、JSON、XML、HTML、Text 格式
- 提供语法高亮和代码折叠
- 支持自动格式化

### 配置操作

#### Pull（拉取配置）

- 从 Nacos 拉取指定配置
- 显示加载状态和结果

#### Push（发布配置）

- 将编辑器中的配置发布到 Nacos
- 根据 DataId 后缀自动识别配置类型

#### Compare（对比配置）

- 对比编辑器中的配置和 Nacos 中的配置
- 使用 IntelliJ 的 Diff 工具显示差异

## 右键菜单功能

### 项目视图右键菜单

1. 在项目目录或配置文件上右键
2. 选择 "发布到 Nacos"
3. 选择要发布到的 Namespace
4. 自动识别项目中的配置文件并发布

### 配置树右键菜单

1. 在配置树节点上右键
2. 支持删除配置操作
3. 管理员可以批量删除 Group 或 Namespace 下的所有配置

## 意图操作

### 发布配置意图

1. 在 YAML 文件中按 `Alt+Enter`（Mac: `Option+Enter`）
2. 选择 "发布到 Nacos"
3. 选择要发布到的 Namespace

### 对比配置意图

1. 在配置编辑器中按 `Alt+Enter`（Mac: `Option+Enter`）
2. 选择 "对比配置"
3. 拉取 Nacos 中的配置并显示差异

## 使用说明

### Nacos 客户端

插件使用 Nacos Client 2.2.0 与 Nacos 服务器通信：

```java
import dev.dong4j.zeka.stack.idea.plugin.nacos.client.NacosClient;

// 获取 Nacos 客户端实例
NacosClient client = NacosClient.getInstance(serverAddr, username, password);
```

### 配置管理

插件支持多种配置格式的自动识别：

- `.yml` / `.yaml` - YAML 格式
- `.json` - JSON 格式
- `.xml` - XML 格式
- `.html` - HTML 格式
- `.txt` - 文本格式

### 权限管理

- 非管理员用户只能删除自己创建的配置
- 管理员用户可以删除任何配置
- 删除操作前会进行权限验证

## 开发指南

### 添加新的 Action

1. 在 `action` 包下创建新的 Action 类
2. 在 `plugin.xml` 中注册 Action
3. 添加到相应的菜单组

### 添加新的 UI 组件

1. 在 `ui` 包下创建新的 UI 组件类
2. 使用 IntelliJ Platform UI 组件（JBLabel、JBTextField 等）
3. 遵循 IntelliJ UI 设计规范

### 添加国际化消息

1. 在 `messages.properties` 中添加英文消息
2. 在 `messages_zh_CN.properties` 中添加中文消息
3. 使用 `NacosBundle.message()` 获取消息

## 构建和发布

### 构建插件

```bash
./gradlew buildPlugin
```

构建产物位于 `build/distributions/` 目录。

### 发布插件

```bash
./gradlew publishPlugin
```

需要配置以下环境变量：

- `PUBLISH_TOKEN`：JetBrains Marketplace 发布令牌
- `CERTIFICATE_CHAIN`：证书链（可选）
- `PRIVATE_KEY`：私钥（可选）
- `PRIVATE_KEY_PASSWORD`：私钥密码（可选）

## 系统要求

- IntelliJ IDEA 2022.3 或更高版本
- Java 17+
- Gradle 8.0+
- IntelliAI Engine 插件
- Nacos 2.x 服务器
