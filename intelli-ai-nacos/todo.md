# Nacos 插件功能扩展计划

基于 Nacos OpenAPI v2 文档，以下是插件可以添加的功能列表。

## 配置管理功能

### 已完成 ✅

- [x] 获取配置 (`GET /nacos/v2/cs/config`)
- [x] 发布配置 (`POST /nacos/v2/cs/config`)
- [x] 删除配置 (`DELETE /nacos/v2/cs/config`)
- [x] 查询配置列表（通过命名空间和分组）


1. 设置页面添加下拉列表选择不同的 nacos 版本

### 待实现 🔲

#### 1. 配置历史管理

- [ ] **查询配置历史列表** (`GET /nacos/v2/cs/history/list`)
    - 在配置树中右键菜单添加"查看历史版本"
    - 显示历史版本列表对话框
    - 支持按时间排序和筛选

- [ ] **查询具体版本的历史配置** (`GET /nacos/v2/cs/history`)
    - 在历史版本列表中双击查看具体版本内容
    - 支持与当前版本对比
    - 支持回滚到指定版本

- [ ] **查询配置上一版本信息** (`GET /nacos/v2/cs/history/previous`)
    - 在编辑器工具栏添加"上一版本"按钮
    - 快速查看和对比上一版本

#### 2. 配置标签管理

- [ ] **配置标签功能**
    - 在发布配置时支持添加标签 (`configTags` 参数)
    - 在配置树中按标签筛选配置
    - 显示配置的标签信息

#### 3. 配置搜索和筛选增强

- [ ] **高级搜索功能**
    - 支持按 dataId、group、namespace、标签搜索
    - 支持正则表达式搜索
    - 保存搜索历史

## 服务发现功能

### 待实现 🔲

#### 1. 服务管理

- [ ] **创建服务** (`POST /nacos/v2/ns/service`)
    - 在工具窗口添加"服务发现"标签页
    - 支持创建新服务
    - 设置服务元数据、保护阈值、访问策略

- [ ] **查询服务列表** (`GET /nacos/v2/ns/service/list`)
    - 显示命名空间下的所有服务
    - 支持分页和筛选
    - 显示服务基本信息（实例数、健康实例数等）

- [ ] **查询服务详情** (`GET /nacos/v2/ns/service`)
    - 显示服务的详细信息
    - 包括元数据、保护阈值、访问策略等

- [ ] **修改服务** (`POST /nacos/v2/ns/service`)
    - 支持修改服务元数据
    - 支持修改保护阈值和访问策略

- [ ] **删除服务** (`DELETE /nacos/v2/ns/service`)
    - 支持删除服务（需确认）
    - 检查服务下是否有实例

#### 2. 实例管理

- [ ] **注册实例** (`POST /nacos/v2/ns/instance`)
    - 在服务详情页面支持注册新实例
    - 设置实例 IP、端口、权重、元数据等

- [ ] **查询实例列表** (`GET /nacos/v2/ns/instance/list`)
    - 在服务详情页面显示所有实例
    - 支持按健康状态筛选
    - 显示实例详细信息（IP、端口、权重、元数据等）

- [ ] **查询实例详情** (`GET /nacos/v2/ns/instance`)
    - 显示单个实例的详细信息

- [ ] **更新实例** (`PUT /nacos/v2/ns/instance`)
    - 支持修改实例信息（权重、元数据等）
    - 支持启用/禁用实例

- [ ] **注销实例** (`DELETE /nacos/v2/ns/instance`)
    - 支持注销实例
    - 支持批量注销

- [ ] **更新实例健康状态** (`PUT /nacos/v2/ns/health/instance`)
    - 手动设置实例健康状态
    - 用于测试和调试

#### 3. 实例元数据管理

- [ ] **批量更新实例元数据** (`PUT /nacos/v2/ns/instance/metadata/batch`)
    - 支持批量更新多个实例的元数据
    - 支持按服务、集群筛选

- [ ] **批量删除实例元数据** (`DELETE /nacos/v2/ns/instance/metadata/batch`)
    - 支持批量删除实例元数据

#### 4. 客户端管理（新功能）

- [ ] **查询客户端列表** (`GET /nacos/v2/ns/client/list`)
    - 显示所有连接到 Nacos 的客户端
    - 区分 1.x 和 2.x 版本的客户端

- [ ] **查询客户端信息** (`GET /nacos/v2/ns/client`)
    - 显示客户端的详细信息
    - 包括客户端类型、连接类型、应用名、版本等

- [ ] **查询客户端的注册信息** (`GET /nacos/v2/ns/client/publish/list`)
    - 显示客户端注册的所有服务实例

- [ ] **查询客户端的订阅信息** (`GET /nacos/v2/ns/client/subscribe/list`)
    - 显示客户端订阅的所有服务

- [ ] **查询注册指定服务的客户端信息** (`GET /nacos/v2/ns/client/service/publisher/list`)
    - 显示注册了指定服务的所有客户端

- [ ] **查询订阅指定服务的客户端信息** (`GET /nacos/v2/ns/client/service/subscriber/list`)
    - 显示订阅了指定服务的所有客户端

## 优先级建议

### 高优先级 🔴

1. 配置历史管理（查看历史版本、回滚）
2. 服务发现基础功能（服务列表、实例列表）
3. 配置树右键菜单
4. 批量操作（批量发布、批量删除）

### 中优先级 🟡

1. 客户端管理功能
2. 命名空间管理（创建、编辑、删除）
3. 配置同步功能
4. 配置模板功能

### 低优先级 🟢

1. 配置监控
2. 日志查看
3. 高级搜索功能
4. 性能优化
