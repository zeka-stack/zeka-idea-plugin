IntelliAI Nacos (English)

A plugin for managing and operating Nacos configuration center directly within IntelliJ IDEA. It provides a visual configuration management interface, supporting operations such as pulling, publishing, comparing, and deleting configurations, greatly improving development efficiency.

Core Features

  • 📍 Nacos Connection Management: Configure and manage Nacos server connections
  • 📁 Configuration Tree View: Display configurations in a three-level hierarchy: Namespace → Group → DataId
  • 📝 Configuration Editor: Support multi-tab editing with formats like YAML, JSON, XML, etc.
  • 🔄 Configuration Operations: Pull, publish, and compare configurations
  • 🔍 Configuration Search: Search for Namespace, Group, and DataId in the configuration tree
  • 🗑️ Configuration Deletion: Support single or batch deletion of configurations
  • 🤖 AI Integration: Integrated with IntelliAI Engine for intelligent configuration generation

Development Environment

  • JDK 17+
  • Gradle 8.0+
  • IntelliJ IDEA 2022.3+
  • IntelliAI Engine Plugin (automatically installed during local development)
  • Nacos Client 2.2.0

Quick Start

  1. Configure Nacos server connection in Settings → Tools → IntelliAI Nacos
  2. Test connection and verify permissions
  3. Open Nacos tool window to start managing configurations

Features

  • Nacos server connection configuration and testing
  • Configuration tree structure display
  • Multi-format configuration editor
  • Configuration pull, publish, and compare functionality
  • Context menu operations
  • Intention actions
  • Publish configuration from project view context menu

Technology Stack

  • Based on IntelliJ Platform SDK 2.1.0
  • Integrated with IntelliAI Engine Plugin
  • Uses Nacos Client 2.2.0
  • Configured with Kotlin DSL
  • Integrated with JUnit 5 testing framework

IntelliAI Nacos

这是一个用于在 IntelliJ IDEA 中直接管理和操作 Nacos 配置中心的插件。插件提供了可视化的配置管理界面，支持配置的拉取、发布、对比、删除等操作，极大提升了开发效率。

核心功能

  • 📍 Nacos 连接管理：配置和管理 Nacos 服务器连接
  • 📁 配置树视图：按 Namespace → Group → DataId 三级分组展示配置
  • 📝 配置编辑器：支持多 Tab 编辑，支持 YAML、JSON、XML 等格式
  • 🔄 配置操作：拉取、发布、对比配置
  • 🔍 配置搜索：在配置树中搜索 Namespace、Group、DataId
  • 🗑️ 配置删除：支持单个或批量删除配置
  • 🤖 AI 集成：集成 IntelliAI Engine，支持智能配置生成

开发环境

  • JDK 17+
  • Gradle 8.0+
  • IntelliJ IDEA 2022.3+
  • IntelliAI Engine 插件（本地开发时自动安装）
  • Nacos Client 2.2.0

快速开始

  1. 在 Settings → Tools → IntelliAI Nacos 中配置 Nacos 服务器连接
  2. 测试连接并验证权限
  3. 打开 Nacos 工具窗口开始管理配置

包含功能

  • Nacos 服务器连接配置和测试
  • 配置树形结构展示
  • 多格式配置编辑器
  • 配置拉取、发布、对比功能
  • 右键菜单操作
  • 意图操作（Intention Action）
  • 项目视图右键发布配置

技术栈

  • 基于 IntelliJ Platform SDK 2.1.0
  • 集成 IntelliAI Engine 插件
  • 使用 Nacos Client 2.2.0
  • 使用 Kotlin DSL 配置构建
  • 集成 JUnit 5 测试框架
