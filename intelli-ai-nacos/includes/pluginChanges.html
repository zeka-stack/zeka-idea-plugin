v1.0.0

  • 🎉 初始版本发布
  • ✨ 提供完整的 Nacos 配置管理功能
  • ✨ 集成 IntelliAI Engine 插件，支持 AI 功能
  • ✨ 提供可视化的 Nacos 配置管理界面
  • ✨ 支持配置的拉取、发布、对比、删除操作
  • ✨ 提供配置树形结构展示
  • ✨ 支持多 Tab 配置编辑
  • ✨ 集成 Nacos Client 2.2.0
  • 🔧 支持多版本 IntelliJ IDEA

核心功能

  • Nacos 连接管理：服务器连接配置和测试
  • 配置树视图：按 Namespace → Group → DataId 三级分组展示
  • 配置编辑器：支持多 Tab 编辑，支持多种格式
  • 配置操作：拉取、发布、对比配置
  • 权限管理：基于 Nacos 权限的配置删除控制
  • 右键菜单：项目视图右键发布配置
  • 意图操作：快速发布和对比配置

技术特性

  • 基于 IntelliJ Platform SDK 2.1.0
  • 集成 Nacos Client 2.2.0
  • 集成 IntelliAI Engine 插件
  • 使用 Kotlin DSL 配置构建
  • JUnit 5 单元测试框架
  • Lombok 简化 Java 代码

系统要求

  • IntelliJ IDEA 2022.3 或更高版本
  • Java 17+
  • Gradle 8.0+
  • IntelliAI Engine 插件
  • Nacos 2.x 服务器
