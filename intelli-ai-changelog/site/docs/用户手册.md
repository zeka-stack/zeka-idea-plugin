# IntelliAI Changelog 用户手册

## 概述

IntelliAI Changelog 是一个基于人工智能的 IntelliJ IDEA 插件，能够从 Git 提交记录自动生成高质量的变更日志、工作日报、工作周报，并支持智能生成提交信息。该插件集成了
IntelliAI Engine，提供智能化的版本控制和文档管理体验。

## 核心特性

- **智能生成**: 基于 AI 理解 Git 提交记录，生成结构化的变更日志
- **多种格式**: 支持变更日志、日报、周报、提交信息等多种生成模式
- **Git 集成**: 深度集成 Git Log 工具窗口，支持直接从提交记录生成文档
- **高度可定制**: 提供丰富的模板配置，支持自定义提示词
- **智能分析**: 自动分类和整理提交记录，过滤无意义内容
- **实时预览**: 支持编辑和实时预览生成内容

## 快速开始

### 1. 安装插件

#### 系统要求

- **IntelliJ IDEA**: 2022.3 - 2025.2
- **Git**: 项目必须使用 Git 进行版本控制
- **Java 版本**: 17 或更高版本
- **操作系统**: Windows / macOS / Linux

#### 安装步骤

1. **从市场安装（推荐）**:
    - 打开 IntelliJ IDEA
    - `File` → `Settings` → `Plugins`
    - 搜索 `IntelliAI Changelog`
    - 点击 `Install` 并重启 IDE

2. **手动安装**:
    - 下载最新版本的插件包文件
    - `File` → `Settings` → `Plugins`
    - 点击 `⚙️` → `Install Plugin from Disk...`
    - 选择下载的插件包并安装

### 2. 配置 AI 提供商

在开始使用之前，需要先配置 AI 服务提供商：

1. **打开 IntelliAI Engine 配置**:
    - `File` → `Settings` → `Tools` → `IntelliAI Engine`

2. **添加 AI 提供商**:
    - 点击 `+` 按钮添加新的配置
    - 选择提供商类型（如通义千问、OpenAI 等）
    - 填写必要信息（API Key、模型选择等）

3. **测试连接**:
    - 配置完成后点击 `测试连接`
    - 确保显示"连接成功"的提示

#### 推荐的 AI 提供商

| 提供商            | 优势            | 适用场景        |
|----------------|---------------|-------------|
| **通义千问**       | 中文理解优秀，生成内容自然 | 中文项目，变更日志生成 |
| **硅基流动**       | 模型丰富，性价比高     | 各类项目，中文处理   |
| **OpenAI API** | 模型能力强，逻辑清晰    | 英文项目，复杂变更分析 |
| **ModelScope** | 阿里云官方，稳定性好    | 企业级项目，正式发布  |
| **Ollama**     | 本地部署，隐私保护好    | 敏感项目，离线环境   |

### 3. 基本使用

#### 方式一：生成变更日志（推荐）

1. **打开 Git Log 工具窗口**:
    - `Git` → `Show Git Log` 或 `Alt + 9`

2. **选择提交记录**:
    - 在 Git Log 中选择一个或多个提交记录
    - 可以使用 `Ctrl/Cmd + Click` 多选

3. **生成变更日志**:
    - 右键点击选中的提交记录
    - 选择 `生成变更日志`
    - 等待 AI 生成并显示结果

#### 方式二：生成工作日报

1. **选择提交记录**:
    - 在 Git Log 中选择需要生成日报的提交记录
    - 通常选择一天内的所有提交

2. **生成日报**:
    - 右键点击 → `生成工作日报`
    - AI 将根据提交记录生成结构化的日报

#### 方式三：生成工作周报

1. **选择提交记录**:
    - 在 Git Log 中选择一周内的提交记录
    - 可以使用日期范围筛选功能

2. **生成周报**:
    - 右键点击 → `生成工作周报`
    - AI 将按工作周组织内容并生成周报

#### 方式四：生成提交信息

1. **使用 Commit 窗口**:
    - 在 Git 提交窗口中，点击 `生成提交信息`
    - AI 将分析代码变更并生成合适的提交信息

2. **从 Git Log 生成**:
    - 在 Git Log 中右键点击提交记录
    - 选择 `生成提交信息`
    - AI 将重新生成更规范的提交信息

### 自定义模板

#### 修改提示词模板

在设置界面启用"显示高级设置"，然后可以自定义各种模板：


#### 模板变量说明

| 变量名           | 描述     | 适用模板 |
|---------------|--------|------|
| `{version}`   | 版本号    | 变更日志 |
| `{date}`      | 日期     | 日报   |
| `{dateRange}` | 日期范围   | 周报   |
| `{commits}`   | 提交记录列表 | 所有模板 |
| `{codeDiffs}` | 代码变更信息 | 提交信息 |

## 常见问题

### Q: 为什么生成的变更日志质量不高？

**A:** 可能的原因和解决方案：

1. **AI 提供商选择**:
    - 推荐使用通义千问处理中文项目
    - 确保选择的模型适合文本生成任务

2. **提交记录质量**:
    - 确保提交信息清晰、准确
    - 避免含糊不清的提交描述
    - 使用规范的提交信息格式

3. **模板优化**:
    - 在高级设置中自定义提示词
    - 调整模板格式和内容要求

### Q: 如何处理大量提交记录？

**A:** 针对大量提交的建议：

1. **分批处理**:
    - 按时间分批选择提交记录
    - 每次处理 10-20 个提交效果最佳

2. **筛选优化**:
    - 使用 Git Log 的筛选功能
    - 只选择有价值的提交记录
    - 排除"合并分支"、"格式化"等无意义提交

3. **分段生成**:
    - 先生成摘要，再生成详细内容
    - 最后合并和编辑成完整文档

### Q: 支持哪些版本控制系统？

**A:** 目前主要支持 Git：

- ✅ **Git**: 完全支持，包括本地和远程仓库
- 🔄 **SVN**: 计划中
- 🔄 **Mercurial**: 计划中

### Q: 如何处理中文和英文混合内容？

**A:** 中文处理建议：

1. **选择合适的模型**:
    - 通义千问、硅基流动对中文处理更好
    - 避免使用纯英文模型处理中文内容

2. **调整提示词**:
    - 明确要求使用中文输出
    - 在模板中指定语言要求

### Q: 生成的内容可以保存吗？

**A:** 保存方式：

1. **手动保存**:
    - 在结果对话框中编辑后复制
    - 保存到项目文档文件中

2. **自动保存**:
    - 插件暂不提供自动保存功能
    - 建议手动管理重要文档

### Q: 如何集成到 CI/CD 流程？

**A:** 集成建议：

1. **命令行工具**:
    - 可以通过 IntelliJ IDEA 的命令行模式调用
    - 生成变更日志后自动保存到文件

2. **脚本集成**:
   ```bash
   # 使用 IntelliJ IDEA 命令行模式
   idea.exe generate-changelog --output CHANGELOG.md
   ```

3. **构建集成**:
    - 在构建脚本中添加变更日志生成步骤
    - 自动更新项目文档
