## 3 Engine 流式输出实现（提供者）

### 3.1 核心接口：AIStreamResponseListener

Engine 模块定义了流式响应的标准接口，所有需要流式输出的功能都基于此接口实现。

**接口定义**：`dev.dong4j.zeka.stack.idea.plugin.common.ai.AIStreamResponseListener`

```java
public interface AIStreamResponseListener {
    // 流式响应开始
    default void onStart() {}

    // 接收增量内容块
    default void onChunk(@NotNull String chunk) {}

    // 流式响应完成，提供完整文本
    default void onComplete(@NotNull String fullText) {}

    // 流式响应错误处理
    default void onError(@NotNull String error, @Nullable Throwable exception) {}
}
```

**设计特点**：

- 所有方法都是默认方法，实现类只需重写需要的方法
- 支持生命周期管理：开始 → 增量数据 → 完成/错误
- 线程安全：回调在适当的线程上下文中执行

### 3.2 流式请求构建：AICompatibleProvider

`AICompatibleProvider` 负责构建支持流式传输的 HTTP 请求。

**关键方法**：`buildRequestBody(AIChatRequest request, boolean stream, boolean enableThinking)`

```java
protected JsonObject buildRequestBody(AIChatRequest request, boolean stream, boolean enableThinking) {
    // ... 构建消息数组 ...
    body.addProperty("stream", stream);  // 关键：启用流式传输
    body.add("messages", messagesArray);
    // ... 其他参数 ...
    return body;
}
```

**流式请求特点**：

- 在请求体中设置 `"stream": true` 标志
- 支持思考模式（thinking mode）的流式输出
- 兼容多种 AI 提供商的流式协议

### 3.3 流式响应解析：parseStreamChunk

Engine 需要解析 AI 服务返回的流式数据块（Server-Sent Events 或类似格式）。

**解析流程**：

```java
private StreamChunk parseStreamChunk(String jsonData) {
    JsonObject json = JsonParser.parseString(jsonData).getAsJsonObject();
    JsonArray choices = json.getAsJsonArray("choices");
    JsonObject choice = choices.get(0).getAsJsonObject();
    JsonObject delta = choice.getAsJsonObject("delta");

    String content = readStringValue(delta, "content");
    String thinking = readStringValue(delta, "reasoning_content");

    return new StreamChunk(content, thinking);
}
```

**StreamChunk 结构**：

- `content`: 主要的文本内容块
- `thinking`: 思考过程内容（如果启用思考模式）

### 3.4 流式响应处理：chatStream 方法

`AICompatibleProvider.chatStream()` 方法实现了完整的流式响应处理流程。

**处理流程**：

1. **构建流式请求**：调用 `buildRequestBody(request, true, enableThinking)`
2. **发送 HTTP 请求**：建立流式连接
3. **逐行读取响应**：按行解析 SSE 格式数据
4. **解析数据块**：调用 `parseStreamChunk()` 提取内容
5. **回调监听器**：
    - 调用 `listener.onChunk(chunk.content)` 传递增量内容
    - 调用 `AIConsoleLoggerUtil.printStreamPlain()` 输出到控制台
6. **完成处理**：调用 `listener.onComplete(fullText.toString())`

**关键代码逻辑**：

```java
public void chatStream(@NotNull Project project,
                      @NotNull AIChatRequest request,
                      @NotNull AIStreamResponseListener listener) throws IOException {
    // 1. 构建请求
    JsonObject body = buildRequestBody(request, true, enableThinking);

    // 2. 发送请求并获取流式响应
    HttpURLConnection connection = createConnection(url);
    // ... 设置请求头 ...

    // 3. 读取流式响应
    try (BufferedReader reader = new BufferedReader(...)) {
        StringBuilder fullText = new StringBuilder();
        String line;

        while ((line = reader.readLine()) != null) {
            if (line.startsWith("data: ")) {
                String data = line.substring(6);
                if ("[DONE]".equals(data)) {
                    break;
                }

                // 4. 解析数据块
                StreamChunk chunk = parseStreamChunk(data);
                if (chunk != null && chunk.content != null) {
                    // 5. 累积完整文本
                    fullText.append(chunk.content);

                    // 6. 输出到控制台（Engine 统一控制台）
                    AIConsoleLoggerUtil.printStreamPlain(project, chunk.content);

                    // 7. 回调监听器
                    listener.onChunk(chunk.content);
                }
            }
        }

        // 8. 完成回调
        listener.onComplete(fullText.toString());
    }
}
```

### 3.5 统一控制台输出：AIConsoleView

Engine 提供了统一的控制台视图服务，用于展示所有 AI 相关的流式输出。

**服务类**：`dev.dong4j.zeka.stack.idea.plugin.common.console.AIConsoleView`

**核心方法**：

```java
@Service(Service.Level.PROJECT)
public final class AIConsoleView implements Disposable, AIConsoleLogger {

    private final StringBuilder streamBuffer = new StringBuilder();

    /**
     * 流式输出文本块
     */
    public void appendStream(@NotNull String chunk) {
        streamBuffer.append(chunk);
        ApplicationManager.getApplication().invokeLater(() -> {
            ConsoleView console = getConsoleView();
            if (console != null) {
                console.print(chunk, ConsoleViewContentType.NORMAL_OUTPUT);
                showToolWindow();
            }
        });
    }

    /**
     * 完成流式输出
     */
    public void completeStream() {
        streamBuffer.setLength(0);
        ApplicationManager.getApplication().invokeLater(() -> {
            ConsoleView console = getConsoleView();
            if (console != null) {
                console.print("\n", ConsoleViewContentType.NORMAL_OUTPUT);
            }
        });
    }
}
```

**线程安全保证**：

- 使用 `ApplicationManager.getApplication().invokeLater()` 确保 UI 更新在 EDT 线程执行
- 使用 `StringBuilder` 作为缓冲区，避免频繁的字符串拼接

**工具方法**：`AIConsoleLoggerUtil`

Engine 提供了便捷的工具类，简化控制台输出：

```java
public class AIConsoleLoggerUtil {
    public static void printStreamPlain(@NotNull Project project, @NotNull String chunk) {
        AIConsoleView.getInstance(project).appendStream(chunk);
    }

    public static void completeStreamPlain(@NotNull Project project) {
        AIConsoleView.getInstance(project).completeStream();
    }
}
```

## 4 Changelog 插件集成（使用者）

### 4.1 服务层：ChangelogService

Changelog 插件在 `ChangelogService` 中封装了流式生成方法。

**流式方法示例**：

```java
public String generateReleaseLogByAiStream(@NotNull Path gitRoot,
                                          @Nullable String range,
                                          @NotNull AIStreamResponseListener listener) throws Exception {
    // 1. 读取 Git 提交记录
    List<CommitInfo> commits = readCommitsFromRange(gitRoot, range);

    // 2. 构建提示词
    String prompt = buildReleaseLogPrompt(commits);

    // 3. 调用流式 AI 服务
    return callAIServiceStreamForChangelog(prompt, listener);
}
```

**内部实现**：`callAIServiceStreamForChangelog`

```java
private String callAIServiceStreamForChangelog(@NotNull String userPrompt,
                                               @NotNull AIStreamResponseListener listener) throws Exception {
    // 1. 获取配置
    SettingsState settings = SettingsState.getInstance();
    AIProviderConfig config = settings.providerConfig;

    // 2. 构建请求
    AIChatRequest request = buildChangelogRequest(userPrompt);

    // 3. 获取 AI 服务实例
    AIService aiService = AIServiceImpl.getInstance();

    // 4. 调用流式服务
    return callAIServiceStreamWithListener(aiService, request, config, listener);
}
```

**支持的流式方法**：

- `generateReleaseLogByAiStream()` - 生成发布日志（流式）
- `generateChangelogFromDiffStream()` - 基于 Git diff 生成变更日志（流式）
- `generateDailyReportStream()` - 生成工作日报（流式）
- `generateWeeklyReportStream()` - 生成工作周报（流式）

### 4.2 监听器实现：ChangelogAIStreamResponseListener

Changelog 插件实现了自定义的流式响应监听器，用于处理特定的业务逻辑。

**实现类**：`dev.dong4j.zeka.stack.idea.plugin.changelog.ai.ChangelogAIStreamResponseListener`

```java
public class ChangelogAIStreamResponseListener implements AIStreamResponseListener {
    private final Project project;
    private final StringBuilder buffer;  // 累积完整内容
    private final CountDownLatch latch;  // 同步计数器
    private final AtomicReference<Exception> errorRef;  // 错误引用

    @Override
    public void onChunk(@NotNull String chunk) {
        if (chunk.isEmpty()) {
            return;
        }
        buffer.append(chunk);  // 累积到缓冲区
    }

    @Override
    public void onComplete(@NotNull String fullText) {
        latch.countDown();  // 通知完成
    }

    @Override
    public void onError(@NotNull String error, @Nullable Throwable exception) {
        AIConsoleLoggerUtil.printError(project, "流式生成错误: " + error);
        if (exception != null) {
            errorRef.set(new Exception(error, exception));
        } else {
            errorRef.set(new Exception(error));
        }
        latch.countDown();
    }
}
```

**设计特点**：

- 使用 `StringBuilder` 累积完整内容
- 使用 `CountDownLatch` 实现同步等待
- 使用 `AtomicReference` 安全传递异常信息
- 错误信息输出到 Engine 统一控制台

### 4.3 Action 层集成：AbstractReleaseLogAction

Action 层负责用户交互，将流式输出集成到用户界面。

**使用示例**：

```java
protected void generate(@NotNull Project project, ...) {
    // 1. 创建输出会话（ToolWindow 中的 Tab）
    OutputSession outputSession = createOutputSession(project, "生成发布日志");

    // 2. 创建流式监听器
    AIStreamResponseListener listener = new AIStreamResponseListener() {
        @Override
        public void onStart() {
            outputSession.setText("");  // 清空内容
        }

        @Override
        public void onChunk(@NotNull String chunk) {
            outputSession.append(chunk);  // 实时追加到 UI
        }

        @Override
        public void onComplete(@NotNull String fullText) {
            // 格式化并设置最终内容
            String formattedText = CommitMessageFormatter.format(fullText);
            outputSession.setText(formattedText);
        }
    };

    // 3. 调用流式生成服务
    service.generateReleaseLogByAiStream(gitRoot, range, listener);
}
```

**关键点**：

- `onStart()`: 初始化输出区域
- `onChunk()`: 实时追加内容，提供流畅的用户体验
- `onComplete()`: 处理最终结果，可进行格式化、保存等操作

### 4.4 UI 展示层：ChangelogToolWindowService

Changelog 插件使用 ToolWindow 来展示流式输出内容。

**服务类**：`dev.dong4j.zeka.stack.idea.plugin.changelog.ui.ChangelogToolWindowService`

**输出会话接口**：

```java
public interface OutputSession {
    void setText(@NotNull String text);
    void append(@NotNull String text);
    String getText();
}
```

**实现方式**：

```java
private static class OutputSessionImpl implements OutputSession {
    private final JTextArea textArea;

    @Override
    public void append(@NotNull String text) {
        ApplicationManager.getApplication().invokeLater(() -> {
            textArea.append(text);  // 追加文本
            // 自动滚动到底部
            textArea.setCaretPosition(textArea.getDocument().getLength());
        });
    }

    @Override
    public void setText(@NotNull String text) {
        ApplicationManager.getApplication().invokeLater(() -> {
            textArea.setText(text);
        });
    }
}
```

**线程安全**：

- 所有 UI 更新都通过 `invokeLater()` 在 EDT 线程执行
- 确保流式输出不会阻塞 UI 线程

## 5 完整流程示例

### 5.1 用户触发流程

```
用户操作
  │
  ├─> AbstractReleaseLogAction.actionPerformed()
  │     │
  │     ├─> 创建 OutputSession（ToolWindow Tab）
  │     │
  │     ├─> 创建 AIStreamResponseListener
  │     │     ├─> onStart() → 清空输出区域
  │     │     ├─> onChunk() → 追加到 UI
  │     │     └─> onComplete() → 格式化最终结果
  │     │
  │     └─> ChangelogService.generateReleaseLogByAiStream()
  │           │
  │           └─> AIService.chatStream()
  │                 │
  │                 └─> AICompatibleProvider.chatStream()
  │                       │
  │                       ├─> 构建流式请求（stream: true）
  │                       ├─> 发送 HTTP 请求
  │                       ├─> 逐行读取响应
  │                       ├─> 解析 StreamChunk
  │                       ├─> AIConsoleLoggerUtil.printStreamPlain() → Engine 控制台
  │                       └─> listener.onChunk() → Changelog UI
```

### 5.2 数据流向

```
AI 服务响应 (SSE 格式)
  │
  ├─> AICompatibleProvider.parseStreamChunk()
  │     └─> 提取 content 和 thinking
  │
  ├─> AIConsoleLoggerUtil.printStreamPlain()
  │     └─> AIConsoleView.appendStream()
  │           └─> ConsoleView.print() → Engine 统一控制台
  │
  └─> listener.onChunk()
        └─> ChangelogAIStreamResponseListener.onChunk()
              ├─> buffer.append() → 累积内容
              └─> outputSession.append() → Changelog ToolWindow
```

### 5.3 线程模型

```
后台线程 (BGT)
  │
  ├─> AICompatibleProvider.chatStream() 读取流式响应
  │     │

  │     │
```

## 6 技术要点总结

### 6.1 Engine 模块职责

1. **接口定义**：提供 `AIStreamResponseListener` 标准接口
2. **请求构建**：支持流式请求参数构建
3. **响应解析**：解析 SSE 格式的流式响应
4. **控制台输出**：提供统一的控制台视图服务
5. **服务封装**：通过 `AIService` 提供统一调用接口

### 6.2 Changelog 插件职责

1. **业务封装**：在 `ChangelogService` 中封装流式生成方法
2. **监听实现**：实现 `AIStreamResponseListener` 处理业务逻辑
3. **UI 集成**：在 Action 中创建监听器并连接 UI
4. **界面展示**：使用 ToolWindow 展示流式输出内容

### 6.3 线程安全保证

- **EDT 线程**：所有 UI 操作通过 `invokeLater()` 在 EDT 执行
- **后台线程**：流式读取和解析在后台线程执行
- **同步机制**：使用 `CountDownLatch` 实现异步等待

### 6.4 错误处理

- **异常捕获**：在流式处理过程中捕获所有异常
- **错误回调**：通过 `onError()` 方法通知上层
- **日志记录**：错误信息输出到 Engine 统一控制台

## 7 扩展和优化

### 7.1 性能优化建议

1. **缓冲区管理**：合理设置缓冲区大小，避免内存占用过大
2. **UI 更新频率**：可以批量合并多个 chunk 再更新 UI，减少刷新次数
3. **异步处理**：确保所有耗时操作在后台线程执行

### 7.2 功能扩展

1. **取消操作**：支持用户取消正在进行的流式生成
2. **暂停/恢复**：支持暂停和恢复流式输出
3. **历史记录**：保存历史生成结果，支持查看和对比

### 7.3 兼容性

- **IntelliJ 版本**：兼容 2022.3 及以上版本
- **AI 提供商**：支持所有实现了 `AICompatibleProvider` 的提供商
- **线程模型**：严格遵循 IntelliJ Platform 线程模型规范
