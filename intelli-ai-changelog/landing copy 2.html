🚀 智能变更日志生成器

基于 AI 技术，自动生成专业的 Changelog、工作日报和周报

立即安装 查看源码

✨ 核心功能

强大的 AI 能力，让文档编写变得简单高效

智能 Changelog 生成

基于 Git 提交历史，自动生成结构化的变更日志，支持多种格式和风格定制。

AI 提交信息优化

根据代码变更内容，自动生成规范的 Git 提交信息，符合团队编码规范。

工作日报生成

一键生成每日工作总结，汇总当天的代码提交和工作成果，提升团队协作效率。

周报自动汇总

自动统计一周的开发工作，生成专业的周报文档，节省报告编写时间。

灵活的配置选项

支持多种 AI 服务提供商，自定义提示词模板，满足不同团队的个性化需求。

快捷操作体验

深度集成 Git 工具窗口和提交面板，右键即可快速生成各类文档，提升工作效率。

📖 如何使用

三步即可开始使用，简单高效

1

安装插件

在 IntelliJ IDEA 插件市场搜索并安装 IntelliAI Changelog

2

配置 AI 服务

在设置中配置您喜欢的 AI 服务提供商（OpenAI、Claude 等）

3

开始使用

在 Git 日志或提交面板右键选择对应功能，AI 将自动生成文档
