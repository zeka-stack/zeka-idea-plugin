2025.3.1

本次更新主要聚焦于功能性和易用性的升级, 包括:

  • 🔧 版本统一：版本号与 Engine 保持一致，统一为 2025.3.1，便于维护与版本管理
  • ✨ 新增：集成 Engine 状态栏扩展，可通过状态栏快速修改配置，提升操作便捷性
  • ✨ 新增：集成 Engine 版本更新检查功能，及时获取最新版本信息
  • ✨ 新增：新增 Release Log 生成功能，提供 AI 和 GitCliff 两种生成方式，支持项目树右键和 Git Log 面板右键入口，生成后自动记录最后一次的 hash 或 tag，便于重复生成
  • ✨ 新增：Release Log 配置支持项目级隔离，优先使用项目中的 release.prompt 或 cliff.toml 配置文件（需至少存在一条提交记录），设置页面配置作为备选方案
  • ✨ 新增：GitCliff 自动安装功能，首次使用时自动从 GitHub 下载并保存到 ~/.zeka-stack/plugin/changelog，支持 Windows、macOS 和 Linux 多平台，如无法正常下载可通过其他途径下载后将压缩包保存到 ~/.zeka-stack/plugin/changelog/dists
  • ✨ 新增：集成 Engine 的 SSE 功能，所有输出均为流式输出并支持中断操作，提升响应速度
  • ✨ 新增：新增基于 Code Diff 生成变更日志功能，适用于 Git Log 不规范的项目场景（相比基于 Git Log 生成会消耗更多 Token）
  • 🔄 重构：重写 Toolwindow 面板，新增变更日志和 Release 日志历史记录功能，以 Markdown 文件形式保存在 IDEA 临时文件中，方便查看和管理
  • ✨ 新增：所有输出完成后自动进行格式化处理，包括中文标点转英文标点、中英文数字间添加空格，提升内容规范性
  • 🔧 优化：合并设置菜单到 Engine 一级菜单下，统一管理配置入口
  • 🔧 优化：优化提示词以支持多语言输出，由 Engine 统一控制输出语言，所有子插件共享此配置
  • 🔧 优化：优化 Git Commit Message 生成功能，推荐使用非思考模型以快速响应
  • 📝 提示：基于 Tag 生成 Release Log 时，请确保存在合规的 Tag 标签名称（如 v1.1.0、v2025.3.1）

2025.3.1

  • 🔧 Version Unification: Version number unified to 2025.3.1, consistent with Engine, for easier maintenance and version management
  • ✨ Added: Integrated Engine status bar extension, can quickly modify configuration via status bar, improving operation convenience
  • ✨ Added: Integrated Engine version update check feature, timely access to latest version information
  • ✨ Added: New Release Log generation feature, providing both AI and GitCliff generation methods, supporting project tree right-click and Git Log panel right-click entry, automatically records the last hash or tag after generation for easy regeneration
  • ✨ Added: Release Log configuration supports project-level isolation, prioritizes using project-level release.prompt or cliff.toml configuration files (requires at least one commit record), settings page configuration as fallback
  • ✨ Added: GitCliff automatic installation feature, automatically downloads from GitHub and saves to ~/.zeka-stack/plugin/changelog on first use, supports Windows, macOS, and Linux platforms. If download fails, can download through other means and save the zip package to ~/.zeka-stack/plugin/changelog/dists
  • ✨ Added: Integrated Engine's SSE feature, all outputs are streamed and support interrupt operations, improving response speed
  • ✨ Added: New Code Diff-based changelog generation feature, suitable for projects with non-standard Git Log (consumes more Tokens compared to Git Log-based generation)
  • 🔄 Refactored: Refactored Toolwindow panel, added changelog and Release log history record feature, saved as Markdown files in IDEA temporary files, convenient for viewing and management
  • ✨ Added: Automatic formatting after all outputs complete, including converting Chinese punctuation to English punctuation, adding spaces between Chinese and English numbers, improving content standardization
  • 🔧 Optimized: Merged settings menu under Engine first-level menu, unified configuration entry management
  • 🔧 Optimized: Optimized prompts to support multi-language output, controlled uniformly by Engine, all sub-plugins share this configuration
  • 🔧 Optimized: Optimized Git Commit Message generation feature, recommends using non-thinking models for fast response
  • 📝 Note: When generating Release Log based on Tag, please ensure compliant Tag label names exist (e.g., v1.1.0, v2025.3.1)

1.0.0

  • 🎉 Initial release
  • ✨ Support generating changelogs based on Git commit history
  • ✨ Support generating daily and weekly reports
  • ✨ Support generating commit messages based on code changes (diff)
  • ✨ Integrated with IntelliAI Engine plugin, supporting multiple AI providers (Qwen, Ollama, OpenAI, etc.)
  • ✨ Complete settings panel with customizable prompt templates
  • ✨ Full internationalization support (Chinese and English)
  • ✨ Generation features available in Git Log tool window context menu
  • ✨ Commit message generation available in Git commit panel
  • 🔧 Support for IntelliJ IDEA 2022.3 and later

Main Features

  • Changelog Generation: Select commits in Git Log tool window and right-click to generate changelog
  • Daily/Weekly Reports: Generate daily and weekly reports based on selected commits
  • Commit Message Generation: Automatically generate commit messages in Git commit panel based on code changes
  • Custom Templates: Support customizing system prompts, changelog templates, daily report templates, and weekly report templates
  • AI Provider Selection: Support selecting default provider from IntelliAI Engine plugin configured providers

System Requirements

  • IntelliJ IDEA 2022.3 or later
  • IntelliAI Engine plugin (dev.dong4j.zeka.stack.idea.plugin.common.ai) must be installed
  • Java 17+

主要功能

  • 变更日志生成：在 Git Log 工具窗口中选择提交记录，右键生成变更日志
  • 工作日报/周报：根据选中的提交记录生成工作日报和周报
  • 提交记录生成：在 Git 提交面板中，根据代码变更自动生成提交记录
  • 自定义模板：支持自定义系统提示词、变更日志模板、日报模板、周报模板
  • AI 提供商选择：支持从 IntelliAI Engine 插件配置的提供商中选择默认提供商
