IntelliAI Changelog

An IntelliJ IDEA plugin that uses AI to automatically generate project changelogs, daily reports, weekly reports, and commit messages.

Features

  • 🚀 AI-Generated Changelogs: Automatically generate changelogs based on Git commit history
  • 📅 Daily/Weekly Reports: Generate daily and weekly reports based on Git commits
  • 💬 Smart Commit Messages: Automatically generate commit messages based on code changes (diff)
  • 🤖 Multiple AI Provider Support: Support for various AI services including Qwen, Ollama, OpenAI, and more
  • ⌨️ Flexible Trigger Methods: Trigger via Git Log context menu, Git commit panel, and more
  • 📝 Customizable Templates: Customize prompt templates for changelogs, daily reports, weekly reports, and commit messages
  • 🌍 Internationalization Support: Full support for Chinese and English

Use Cases

  • Changelog Generation: Select commits in Git Log tool window and right-click to generate changelog
  • Daily/Weekly Reports: Quickly generate daily and weekly reports based on Git commits
  • Commit Message Generation: Automatically generate commit messages in Git commit panel based on code changes

Quick Start

  1. Install the plugin (requires IntelliAI Engine plugin to be installed first)
  2. Configure AI providers and API keys in Settings → Tools → IntelliAI Engine
  3. Select default AI provider in Settings → Tools → IntelliAI Changelog
  4. Use the features in Git Log tool window or Git commit panel

Configuration

  • AI Provider Configuration: Configure and test AI providers in Settings → Tools → IntelliAI Engine
  • Plugin Settings: Select default AI provider and customize prompt templates in Settings → Tools → IntelliAI Changelog
  • Prompt Templates: Customize system prompts, changelog templates, daily report templates, weekly report templates, etc.

Technology Stack

  • Based on IntelliJ Platform SDK 2.1.0
  • Depends on IntelliAI Engine plugin for unified AI service interface
  • Uses JGit for Git operations
  • Full internationalization support (Chinese and English)

IntelliAI Changelog

使用 AI 自动生成项目变更日志、工作日报、周报和提交记录的 IntelliJ IDEA 插件。

功能特性

  • 🚀 AI 生成变更日志：基于 Git 提交记录自动生成变更日志
  • 📅 工作日报/周报生成：根据 Git 提交记录自动生成工作日报和周报
  • 💬 智能提交记录：根据代码变更（diff）自动生成提交记录
  • 🤖 多种 AI 提供商支持：支持通义千问、Ollama、OpenAI 等多种 AI 服务
  • ⌨️ 灵活的触发方式：可通过 Git Log 右键菜单、Git 提交面板等多种方式触发
  • 📝 自定义模板：支持自定义变更日志、日报、周报和提交记录的提示词模板
  • 🌍 国际化支持：完整的中英文多语言支持

使用场景

  • 变更日志生成：在 Git Log 工具窗口中选择提交记录，右键生成变更日志
  • 工作日报/周报：快速生成基于 Git 提交的工作日报和周报
  • 提交记录生成：在 Git 提交面板中，根据代码变更自动生成提交记录

快速开始

  1. 安装插件（需要先安装 IntelliAI Engine 插件）
  2. 在 Settings → Tools → IntelliAI Engine 中配置 AI 提供商和 API Key
  3. 在 Settings → Tools → IntelliAI Changelog 中选择默认 AI 提供商
  4. 在 Git Log 工具窗口或 Git 提交面板中使用相应功能

配置说明

  • AI 提供商配置：在 Settings → Tools → IntelliAI Engine 中配置和测试 AI 提供商
  • 插件设置：在 Settings → Tools → IntelliAI Changelog 中选择默认 AI 提供商和自定义提示词模板
  • 提示词模板：支持自定义系统提示词、变更日志模板、日报模板、周报模板等

技术栈

  • 基于 IntelliJ Platform SDK 2.1.0
  • 依赖 IntelliAI Engine 插件提供统一的 AI 服务接口
  • 使用 JGit 进行 Git 操作
  • 完整的国际化支持（中英文）
