🚀 快速开始

1

打开设置

在 IntelliJ IDEA 中，打开 Settings → Tools → AI Javadoc，配置您的 AI 服务提供商和 API Key

2

选择触发方式

使用快捷键 Ctrl+Shift+D（Windows/Linux）或 Cmd+Shift+D（macOS），或通过右键菜单选择

3

生成文档

将光标放在要生成文档的方法、字段或类上，插件会智能识别并生成相应的 JavaDoc 注释

💡 示例代码

// 生成前
public class UserService {
    public void createUser(String username) {
        // 业务逻辑
    }
}

// 生成后
/**
 * 用户服务类
 * 提供用户相关的业务操作
 */
public class UserService {
    /**
     * 创建用户
     *
     * @param username 用户名
    */
    public void createUser(String username) {
        // 业务逻辑
    }
}
