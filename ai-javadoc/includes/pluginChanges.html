1.3.0

The service provider needs to be reconfigured due to the addition of the system-level encrypted storage API Key.
  • Security Enhancement: API Key encryption using system-level storage (macOS Keychain / Linux Keyring / Windows Credential Manager) for secure sensitive data handling
  • Snapshot Performance Mode Optimization: Can configure different models and different apiKey for the same service provider, increasing parallel processing speed.
  • Added code compression control feature to effectively reduce token usage
  • Added token statistics and optional statistics sending functionality
  • Added console log output, mainly for prompt optimization
  • Changed "Skip existing comments" to "Override existing comments" (more logical)
  • Other logic improvements and bug fixes
