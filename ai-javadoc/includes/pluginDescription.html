AI Javadoc: You Know, for Javaer, Fun

Automatically generate high-quality JavaDoc comments for Java projects using AI services. This plugin supports multiple AI providers including QianWen (Alibaba Cloud) and Ollama local models.

Core Features

  • Multiple AI Providers: Support for QianWen, Ollama and other AI services
  • Flexible Triggering: Available via shortcuts, right-click menus, Generate menu and more
  • Batch Processing: Generate documentation for entire files or directories
  • Smart Recognition: Automatically identify classes, methods, test methods and other elements
  • Asynchronous Processing: Background processing without blocking the IDE
  • Progress Display: Real-time progress and result statistics

Usage

  • Shortcut: Ctrl+Shift+D (Windows/Linux) or Cmd+Shift+D (Mac)
  • Editor right-click menu → Generate Javadoc with AI
  • File/Directory right-click menu → Generate Javadoc with AI
  • Generate menu: Cmd+N / Alt+Insert → JavaDoc with AI
  • Quick fix: Option+Enter / Alt+Enter → Generate Javadoc with AI

Configuration

Configuration path: Settings → Tools → AI Javadoc

  • Select AI provider (QianWen/Ollama)
  • Configure model and API Key
  • Customize generation options
