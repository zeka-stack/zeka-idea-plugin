IntelliJ IDEA Plugin Template (With AI)

A development template that integrates IntelliAI Engine for creating AI-powered IntelliJ IDEA plugins with best practices and complete foundation.

Template Features

  • 🚀 Quick Start: Complete project structure and configuration, ready to use out of the box
  • 🤖 AI Integration: Integrated with IntelliAI Engine, supporting multiple AI service providers
  • ⚙️ Settings Management: Complete settings page supporting AI provider selection and prompt template management
  • 📦 Dependency Management: Pre-configured common dependencies including Lombok, JUnit, Mockito, etc.
  • 🔧 Development Tools: Integrated Google Java Format, testing framework and plugin verification tools
  • 🌍 Internationalization: Built-in multi-language support with Chinese and English resource files
  • 📝 Documentation: Detailed usage documentation and development guide
  • 🎨 Icon Management: Icon management class for unified plugin icon resource management

Development Environment

  • JDK 17+
  • Gradle 8.0+
  • IntelliJ IDEA 2022.3+
  • IntelliAI Engine plugin (automatically installed during local development)

Quick Start

  1. 📥 Clone Template: Clone the template project to local
  2. ⚙️ Configure Info: Modify plugin information in gradle.properties
  3. ▶️ Start Development: Run ./gradlew runIde to start sandbox environment (IntelliAI Engine plugin will be automatically installed)
  4. 🔧 Configure AI: Configure AI providers in Settings → Tools → IntelliAI Engine
  5. 💻 Start Development: Start developing your plugin features

Included Features

  • 🎯 Action Example: Right-click menu triggered action example
  • ⚙️ Settings Page: AI provider selection and prompt template management
  • 🎨 Icon Management: Tool class for unified icon resource management
  • 🔔 Notification Utility: Unified notification utility class
  • 🌍 Internationalization Support: Multi-language resource file support

Technology Stack

  • Based on IntelliJ Platform SDK 2.1.0
  • Integrated with IntelliAI Engine plugin
  • Using Kotlin DSL for build configuration
  • Integrated JUnit 5 testing framework
  • Support Mockito for unit testing

IntelliJ IDEA Plugin Template (With AI)

这是一个集成 IntelliAI Engine 的 IntelliJ IDEA 插件开发模板，提供了快速创建 AI 功能插件的基础框架和最佳实践。

模板特性

  • 🚀 快速开始：提供完整的项目结构和配置，开箱即用
  • 🤖 AI 集成：集成 IntelliAI Engine，支持多种 AI 服务提供商
  • ⚙️ 设置管理：提供完整的设置页面，支持 AI 提供商选择和提示词模板管理
  • 📦 依赖管理：预配置常用依赖，包括 Lombok、JUnit、Mockito 等
  • 🔧 开发工具：集成 Google Java Format、测试框架和插件验证工具
  • 🌍 国际化：内置多语言支持，提供中文和英文资源文件
  • 📝 文档完善：提供详细的使用文档和开发指南
  • 🎨 图标管理：提供图标管理类，统一管理插件图标资源

开发环境

  • JDK 17+
  • Gradle 8.0+
  • IntelliJ IDEA 2022.3+
  • IntelliAI Engine 插件（本地开发时自动安装）

快速开始

  1. 📥 克隆模板：克隆模板项目到本地

  3. ▶️ 启动开发：运行 ./gradlew runIde 启动沙箱环境（会自动安装 IntelliAI Engine 插件）
